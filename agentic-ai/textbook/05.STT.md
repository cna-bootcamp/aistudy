## 2. 개요

### 2.1 STT (Speech-to-Text)

음성 신호를 텍스트 데이터로 변환하는 기술. **ASR(Automatic Speech Recognition)**이라고도 함.   
단순 소리→글자 변환을 넘어 주변 소음 제거, 맥락에 맞는 단어 선택 등 복합적인 처리 과정 포함.

### 2.2 화자분할 (Speaker Diarization)

"누가 언제 말했는가(Who spoke when)"를 식별하는 기술. 다수 참여 회의나 인터뷰에서 발화자 구분 후 대화록 형식으로 정리 시 필수.

### 2.3 주요 활용 사례

| 분야 | 설명 |
|------|------|
| **스마트 회의록** | 회의 내용 실시간 기록 및 발화자별 정리 |
| **콘텐츠 자막** | 영상 음성 분석 후 자동 자막 생성 및 번역 |
| **콜센터 분석** | 상담원-고객 대화 분리, 서비스 품질 분석 및 감정 인식 |

## 3. 모델 정보

### 3.1 LLM 기반 STT + 화자분할

LLM(거대언어모델)이 오디오를 직접 이해하거나(Multi-modal), 음성 인식 결과 분석으로 화자를 분리하는 방식.  
복잡한 로컬 설치 없이 API 호출만으로 높은 수준의 결과물 획득 가능.

#### 3.1.1 OpenAI Whisper API (Simple STT)

OpenAI Whisper 모델을 API 형태로 사용하는 가장 간단한 방식.

**특징**
- 매우 간단한 설치, API 키만으로 즉시 사용 가능
- 다양한 오디오 포맷 지원 및 강력한 다국어 인식 능력
- 음성→영어 즉시 번역 기능 제공

**제한사항**
- 화자 분리(Diarization) 기능 미포함

**핵심 코드**

```python
# 음성 → 한글 텍스트 (Transcription)
transcription = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file,
    language="ko"
)

# 음성 → 영어 번역 (Translation)
translation = client.audio.translations.create(
    model="whisper-1",
    file=audio_file
)
```

#### 3.1.2 LLM Diarization (Multi-modal)

Claude, Gemini, OpenAI GPT-4o 등 멀티모달 LLM을 사용하여 화자 분리까지 한 번에 처리하는 방식.

**특징**
- **오디오 직접 처리**: LLM이 음성의 톤, 억양, 맥락 분석으로 화자 구분
- **유연한 처리**: Claude(Whisper+Claude), Gemini(자체모델로 처리), OpenAI(자체모델로 처리) 등 모델 선택 가능
- **추가 분석 가능**: 대화록 작성과 동시에 요약, 감정 분석 병행 가능

**처리 흐름**

```
오디오 입력 → LLM(프롬프트와 함께 오디오 분석) → 화자 분리된 대화록 출력
```

**핵심 코드 (Gemini 예시)**

```python
# Gemini API를 사용한 오디오 직접 분석 및 화자 분리
response = model.generate_content(
    [audio_file, "화자를 [MM:SS] 화자A: 내용 형식으로 구분해줘"],
    generation_config=genai.GenerationConfig(temperature=0.1)
)
```

### 3.2 음성 AI 모델 기반 STT + 화자분할

전문적인 음성 AI 모델 조합으로 로컬(GPU) 환경에서 실행하는 방식. 대용량 데이터 처리 또는 보안 중요 프로젝트에 적합.

#### 3.2.1 Whisper + Pyannote (Hybrid)

업계 표준인 **Whisper(인식)**와 **Pyannote(화자분할)** 연결 처리 방식.

**특징**
- **높은 정확도**: 각 분야 전문 모델 사용으로 신뢰도 높은 결과 도출
- **로컬 실행**: 데이터 보안 유지 및 API 비용 절감 (초기 GPU 구축 비용 발생)

**처리 흐름**

```
                    audio.wav
                        │
            ┌───────────┴───────────┐
            │                       │
            ▼                       ▼
    ┌───────────────┐       ┌──────────────┐
    │   Pyannote    │       │   Whisper    │
    │  화자 분리     │       │   음성 인식   │
    └───────┬───────┘       └──────┬───────┘
            │                       │
            │ [0-3s: 화자A]         │ [0-2s: "안녕하세요"]
            │ [3-7s: 화자B]         │ [3-5s: "반갑습니다"]
            │ [7-10s: 화자A]        │ [7-9s: "감사합니다"]
            │                       │
            └───────────┬───────────┘
                        ▼
            ┌───────────────────────┐
            │  시간 기반 Alignment   │
            │   (Overlap 계산)      │
            └───────────┬───────────┘
                        ▼
            ┌───────────────────────┐
            │ [0-2s] 화자A: 안녕하세요  │
            │ [3-5s] 화자B: 반갑습니다  │
            │ [7-9s] 화자A: 감사합니다  │
            └───────────────────────┘
```

**단계별 설명**

1. **Pyannote**: 화자 전환 시간 구간(Timestamp) 추출
2. **Whisper**: 전체 음성 텍스트 변환 및 타임스탬프 부여
3. **Alignment**: 두 결과의 시간 기반 매칭으로 화자 이름 할당

**핵심 코드**

```python
# 1. Pyannote 화자 분리
diarization = diarization_pipeline("audio.wav")

# 2. Whisper 음성 인식
whisper_result = asr_pipeline("audio.wav", return_timestamps=True)

# 3. 시간 기반 정렬 (Overlap 계산)
# Whisper 청크와 Pyannote 구간의 겹침 정도 계산으로 화자 결정
```

#### 3.2.2 WhisperX (Integrated Solution)

`faster-whisper` + `wav2vec2(웨이브 투 벡 투)` + `pyannote` 통합으로 성능과 속도를 극대화한 솔루션.

**특징**
- **압도적 속도**: CTranslate2 기반 엔진으로 기존 대비 4~10배 빠른 처리
- **단어 수준 타임스탬프**: wav2vec2 정렬 모델로 단어별 발화 시간 정확 측정
- **올인원**: 복잡한 파이프라인 연결 코드 생략, 통합 API 제공

**처리 흐름**

```
                        audio.wav
                            │
                            ▼
                ┌───────────────────────┐
                │   faster-whisper      │
                │   (고속 음성 인식)      │
                └───────────┬───────────┘
                            │
                            │ [0-6s: "안녕하세요 반갑습니다 만나서 기쁩니다"]
                            │ [7-10s: "감사합니다"]
                            │ (segment-level: 문장/구 단위)
                            ▼
                ┌───────────────────────┐
                │     wav2vec2          │
                │   (단어 수준 정렬)      │
                └───────────┬───────────┘
                            │
                            │ "안녕하세요" [0.0-1.2s]
                            │ "반갑습니다" [1.5-2.8s]
                            │ "만나서" [3.0-3.8s]
                            │ "기쁩니다" [4.0-5.5s]
                            │ "감사합니다" [7.0-8.8s]
                            │ (word-level: 각 어절별 세분화)
            ┌───────────────┴───────────────┐
            │                               │
            ▼                               ▼
    ┌──────────────┐              ┌─────────────────┐
    │   pyannote   │              │  aligned words  │
    │  (화자 분리)  │              │                 │
    └──────┬───────┘              └────────┬────────┘
            │                               │
            │ [0-3s: SPEAKER_00]           │
            │ [3-7s: SPEAKER_01]           │
            │ [7-10s: SPEAKER_00]          │
            │                               │
            └───────────────┬───────────────┘
                            ▼
                ┌───────────────────────────┐
                │  assign_word_speakers     │
                │    (화자-단어 매칭)        │
                └───────────┬───────────────┘
                            ▼
                ┌───────────────────────────────────┐
                │ SPEAKER_00: 안녕하세요          │
                │ SPEAKER_00: 반갑습니다          │
                │ SPEAKER_00: 만나서              │
                │ SPEAKER_00: 기쁩니다            │
                │ SPEAKER_01: 감사합니다          │
                │ (word-level diarization)      │
                └───────────────────────────────────┘
```

**단계별 설명**

1. **faster-whisper**: 고속 음성 인식
   - 출력: 문장/구 단위 타임스탬프 (segment-level)
   - 예: `[0-6s: "안녕하세요 반갑습니다 만나서 기쁩니다"]`

2. **wav2vec2**: 단어 수준 정렬 (alignment)
   - segment를 어절별로 세분화하여 각각의 정확한 시간 계산 (word-level)
   - 예: `"안녕하세요" [0.0-1.2s]`, `"반갑습니다" [1.5-2.8s]`, `"만나서" [3.0-3.8s]` ...

3. **pyannote**: 화자 분리
   - 출력: 화자 구간 (누가 언제 말했는지)
   - 예: `[0-3s: SPEAKER_00]`, `[3-7s: SPEAKER_01]`

4. **assign_word_speakers**: 최종 매칭
   - 단어별 타임스탬프와 화자 구간을 결합
   - 출력: 단어 수준 화자 분리 결과

**핵심 코드**

```python
# WhisperX 통합 파이프라인
result = model.transcribe(audio, batch_size=16) # 인식
result = whisperx.align(result["segments"], model_a, metadata, audio) # 정렬
diarize_segments = diarize_model(audio) # 화자분할
result = whisperx.assign_word_speakers(diarize_segments, result) # 최종 매칭
```
