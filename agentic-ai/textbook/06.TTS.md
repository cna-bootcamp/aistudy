## 2. 개요

### 2.1 TTS (Text-to-Speech)

텍스트 데이터를 자연스러운 음성으로 변환하는 기술. **음성 합성(Speech Synthesis)**이라고도 함.
단순 문자→소리 변환을 넘어 억양, 감정, 속도 조절 등 다양한 표현 가능.

### 2.2 주요 활용 사례

| 분야 | 설명 |
|------|------|
| **오디오북 제작** | 텍스트 콘텐츠를 음성으로 변환하여 청취형 콘텐츠 생성 |
| **음성 안내 시스템** | 네비게이션, 키오스크, ARS 등 음성 안내 자동화 |
| **접근성 향상** | 시각 장애인을 위한 화면 읽기 기능 |
| **다국어 콘텐츠** | 텍스트 번역 후 해당 언어 음성으로 변환 |
| **가상 어시스턴트** | AI 챗봇, 스마트 스피커의 음성 응답 |
| **교육 콘텐츠** | 언어 학습 교재의 발음 예시 제공 |

### 2.3 TTS 기술의 발전

| 세대 | 기술 | 특징 |
|:----:|------|------|
| 1세대 | Concatenative | 녹음된 음성 조각 연결, 부자연스러운 이음 |
| 2세대 | Parametric | 통계 모델 기반, 기계적인 음색 |
| 3세대 | Neural TTS | 딥러닝 기반, 자연스러운 음성 |
| 4세대 | Zero-shot TTS | 적은 샘플로 새 화자 음성 복제 가능 |

## 3. 모델 정보

### 3.1 Cloud API 기반 TTS

클라우드 서비스에서 제공하는 TTS API를 호출하여 음성 생성. 설치 불필요, 즉시 사용 가능.

#### 3.1.1 OpenAI TTS API

OpenAI에서 제공하는 고품질 음성 합성 API. 6가지 음성 스타일 제공.

**특징**
- 간단한 API 호출로 고품질 음성 생성
- 다양한 언어 자동 인식 및 발음
- 실시간 스트리밍 지원
- GPU 불필요 (클라우드 처리)

**지원 음성**

| 음성 | 성별 | 특징 |
|------|:----:|------|
| alloy | 여성 | 중립적, 균형 잡힌 음성 |
| echo | 남성 | 따뜻하고 친근한 음성 |
| fable | 남성 | 표현력 있는 스토리텔링 음성 |
| onyx | 남성 | 깊고 권위 있는 음성 |
| nova | 여성 | 밝고 쾌활한 음성 |
| shimmer | 여성 | 맑고 선명한 음성 |

**핵심 코드**

```python
from openai import OpenAI

client = OpenAI(api_key=api_key)

# 텍스트 → 음성 변환
response = client.audio.speech.create(
    model="tts-1",           # 모델: tts-1 (표준) 또는 tts-1-hd (고품질)
    voice="nova",            # 음성 선택
    input="안녕하세요",      # 변환할 텍스트
    response_format="wav"    # 출력 형식
)

# 바이트 데이터로 저장
with open("output.wav", "wb") as f:
    f.write(response.content)
```

**API 모델 비교**

| 모델 | 특징 | 용도 |
|------|------|------|
| tts-1 | 빠른 생성, 표준 품질 | 실시간 응답, 대량 처리 |
| tts-1-hd | 고품질, 느린 생성 | 프로덕션 콘텐츠 제작 |

### 3.2 로컬 모델 기반 TTS

GPU 환경에서 직접 TTS 모델 실행. API 비용 없음, 데이터 보안 유지.

#### 3.2.1 Bark (Suno AI)

다국어 음성 합성 및 감정 표현이 가능한 오픈소스 TTS 모델.

**특징**
- **다국어 지원**: 13개 언어 지원 (한국어 포함)
- **감정 표현**: 웃음, 한숨 등 비언어적 표현 생성 가능
- **화자 프리셋**: 언어별 10개 음성 제공 (남/여)
- **오픈소스**: MIT 라이선스, 상업적 사용 가능

**Voice Preset 형식**

```
v2/{lang_code}_speaker_{number}

예시:
- v2/ko_speaker_0  → 한국어 화자 0 (남성)
- v2/ko_speaker_5  → 한국어 화자 5 (여성)
- v2/en_speaker_3  → 영어 화자 3 (남성)
```

| 번호 | 대략적 성별 |
|:----:|:----------:|
| 0-4 | 남성 |
| 5-9 | 여성 |

**핵심 코드**

```python
from transformers import AutoProcessor, BarkModel
import torch

# 모델 로드
processor = AutoProcessor.from_pretrained("suno/bark")
model = BarkModel.from_pretrained("suno/bark").to("cuda")

# 음성 생성
inputs = processor("안녕하세요", voice_preset="v2/ko_speaker_0", return_tensors="pt")  #return_tensors: 텍스트 처리 결과의 반환 형식(PyTorch텐서로 반환해야 GPU 사용 가능)

# 위 CPU에 있는 inputs 데이터를 GPU로 이동 
inputs = {k: v.to("cuda") for k, v in inputs.items()}

with torch.no_grad():  # no_grad: 경사하강법(gradient descent) 적용 안함. 학습이 아닌 추론만 하도록 하게함

    # 오디어 생성. sampling 파라미터(4개)로 뽑은 후보 중 무작위로 선택하여 생성
    audio_array = model.generate(
        **inputs,
        do_sample=True,        # 확률적 샘플링 사용 (매번 다른 억양/톤 생성으로 자연스러움)
        temperature=0.8,       # 창의성 조절 (0.1~2.0): 높을수록 다양하고 무작위, 낮을수록 안정적
        top_k=50,             # 상위 k개 후보만 고려 (50~100 권장): 너무 낮은 확률의 선택지 제거
        top_p=0.9             # 누적 확률 p까지만 고려 (0.9~0.95 권장): 확률 상위권만 샘플링
    )

# GPU 텐서를 CPU로 이동 → NumPy 배열로 변환 → 불필요한 차원 제거
audio_array = audio_array.cpu().numpy().squeeze()
# .cpu(): GPU 메모리 → CPU 메모리 (일반 Python에서 사용 가능하도록)
# .numpy(): PyTorch 텐서 → NumPy 배열 (범용 데이터 형식으로 변환)
# .squeeze(): [1, N] → [N] 형태로 변환 (크기 1인 배치 차원 제거)
```

**샘플링 과정 (do_sample=True 시)**

```
        전체 음성 후보 (1000개)
                │
                ▼
    ┌───────────────────────────┐
    │   temperature=0.8 적용     │
    │  (확률 분포 약간 날카롭게)  │
    └───────────┬───────────────┘
                │
                │ 0.8 < 1.0 → 상위권 확률 ↑
                │ (안정성과 창의성 균형)
                ▼
    ┌───────────────────────────┐
    │    top_k=50 필터링         │
    │   (상위 50개만 남김)        │
    └───────────┬───────────────┘
                │
                │ 1위(20%), 2위(15%), 3위(12%), ...
                │ 50위(0.1%)
                ▼
    ┌───────────────────────────┐
    │    top_p=0.9 필터링        │
    │  (누적 90%까지만 남김)      │
    └───────────┬───────────────┘
                │
                │ 1위(20%), 2위(15%), ...
                │ 25위(1%) ← 누적 90% 도달
                │ (약 25개 남음)
                ▼
    ┌───────────────────────────┐
    │   확률적 무작위 샘플링      │
    │ (25개 중 확률에 따라 선택)  │
    └───────────┬───────────────┘
                │
                ▼
        최종 선택된 음성 데이터
        (매번 다른 결과)
```

**Temperature 효과 비교**

```
확률 분포 변화 (Temperature 값에 따른 영향)

T = 2.0 (매우 부드럽게 - 창의적)
확률
 │     ___________________
 │    /                   \
 │___/                     \___
 └──────────────────────────────→ 후보
     모든 후보가 비슷한 확률
     (매우 무작위, 예측 불가)


T = 1.0 (기본 - 균형)
확률
 │        ___
 │      /     \
 │    /         \
 │___/           \___________
 └──────────────────────────────→ 후보
     원래 모델의 확률 분포 유지


T = 0.8 (약간 날카롭게 - 현재 예제)
확률
 │         /\
 │        /  \
 │      /      \
 │_____/        \____________
 └──────────────────────────────→ 후보
     상위권 확률 증가
     (안정성 ↑, 적당한 다양성)


T = 0.5 (매우 날카롭게 - 안정적)
확률
 │          /\
 │         /  \
 │        /    \
 │_______/      \____________
 └──────────────────────────────→ 후보
     거의 1위만 선택
     (매우 안정적, 반복적)
```

#### 3.2.2 VITS (Kakao Enterprise)

VCTK 데이터셋 기반 109명의 영어 화자를 지원하는 고품질 TTS 모델.

**특징**
- **다중 화자**: 109명의 다양한 억양 화자 지원
- **고품질 음성**: End-to-End 학습으로 자연스러운 발음
- **다양한 억양**: 영국, 스코틀랜드, 아일랜드, 미국 등 다양한 지역 억양
- **espeak-ng 필요**: 텍스트→음소 변환을 위해 espeak-ng 설치 필수

**지원 억양**

| 억양 | 설명 |
|------|------|
| English | 영국 영어 (London, Manchester 등) |
| Scottish | 스코틀랜드 영어 (Edinburgh, Glasgow 등) |
| Irish | 아일랜드 영어 (Dublin, Cork 등) |
| American | 미국 영어 |
| Canadian | 캐나다 영어 |
| Indian | 인도 영어 |
| Welsh | 웨일스 영어 |

**핵심 코드**

```python
from transformers import VitsModel, AutoTokenizer
import torch

# 모델 로드
model = VitsModel.from_pretrained("kakao-enterprise/vits-vctk").to("cuda")
tokenizer = AutoTokenizer.from_pretrained("kakao-enterprise/vits-vctk")

# 음성 생성 (화자 ID 지정)
inputs = tokenizer("Hello, how are you?", return_tensors="pt").to("cuda")

with torch.no_grad():
    output = model(
        **inputs,
        speaker_id=torch.tensor([0]).to("cuda")  # 화자 번호 (0-108)
    )

waveform = output.waveform.squeeze().cpu().numpy()
```

**모델 정보**

| 항목 | 내용 |

| 모델명 | kakao-enterprise/vits-vctk |
| 개발사 | Kakao Enterprise |
| 화자 수 | 109명 |
| 샘플레이트 | 22,050 Hz |
| 지원 언어 | 영어 (다른 언어는 번역 필요) |

### 3.4 번역 + TTS 파이프라인

TTS 예제에서는 텍스트 번역과 음성 합성을 결합한 파이프라인 구현.

**처리 흐름**

```
[1] 입력 텍스트 로드 (CSV)
     ↓
[2] 대상 언어 선택
     ↓
[3] 번역 캐시 확인
     ├─ 캐시 있음 → 캐시 사용
     └─ 캐시 없음 → API로 번역 → 캐시 저장
     ↓
[4] 화자별 음성 선택
     ↓
[5] TTS 모델로 음성 생성
     ↓
[6] 오디오 세그먼트 연결
     ↓
[7] WAV 파일 저장
```

**번역 캐싱 장점**
- 동일 텍스트 재번역 방지로 API 비용 절감
- 오프라인 재실행 가능
- 번역 결과 수정 가능

## 5. 심화 학습

### 5.1 음성 복제 (Voice Cloning)

짧은 음성 샘플로 특정 화자의 목소리를 복제하는 기술.

| 모델 | 특징 | 링크 |
|------|------|------|
| Chatterbox | Resemble AI, 감정 태그·다국어(23개) 지원 | [GitHub](https://github.com/resemble-ai/chatterbox) |
| OpenVoice | Zero-shot 음성 복제 | [GitHub](https://github.com/myshell-ai/OpenVoice) |
| XTTS | Coqui 개발, 다국어 지원 | [GitHub](https://github.com/coqui-ai/TTS) |

**모델 비교 (Chatterbox / OpenVoice V2 / XTTS):**

| 항목 | **Chatterbox** | OpenVoice V2 | XTTS |
|------|------------|--------------|------|
| 테스트결과 | 품질 상 | 품질 중(목소리 복제 안됨) | 품질 하(쓰기 어려운 수준) |
| 모델 크기 | ~500MB | ~200MB | ~1.8GB |
| 지원 언어 | 23개 | 6개 (EN/ES/FR/ZH/JA/KO) | 16개 |
| 파이프라인 | 단일 | 2단계 (MeloTTS → ToneColorConverter) | 단일 |
| 참조 음성 길이 | ~10초 | 제한 없음 | 6~30초 |
| 감정 태그 | [laugh], [cough] 등 | 없음 | 없음 |
| 워터마크 | Perth 자동 삽입 | @MyShell 삽입 | 없음 |
| 설치 복잡도 | 낮음 | 높음 (MeloTTS + unidic 별도) | 낮음 |
| 라이선스 | Apache 2.0 | MIT | CPML (비상업) |

[처리]
- 사전 설치툴 체크:
  - Python 3.12 실행 여부를 체크
  - PyTorch / torchaudio 설치를 체크

  - voices/ 디렉토리의 오디오 파일을 스캔
  - WAV 파일이면 그대로 사용

  - 변환된 WAV 파일은 재실행 시 재사용
  - 참조 음성 파일이 여러 개면 사용자에게 사용할 음성을 선택하도록 함
- 예제 개발
  - {AI모델}: Chatterbox Multilingual (500M, 23개 언어 지원)
  - {프로젝트}: chatterbox-single
  - 설치할 라이브러리는 requirements.txt에 작성
  - 실행 시 합성할 텍스트를 사용자에게 입력 받음

    - `EOD`가 단독으로 입력되면 입력 종료
    - 첫 입력이 `EOD`이거나 본문이 비어 있으면 종료

  - 실행 시 톤앤매너 추가 프롬프트를 사용자에게 선택 입력 받음
    - 예시: "차분하고 다정하게", "밝고 활기차게", "뉴스 앵커처럼 또렷하게"
    - 빈 입력이면 기본 톤으로 생성
  - Groq LPU 전처리
    - Groq Python SDK로 `openai/gpt-oss-120b` 모델 호출
    - 긴 입력은 약 450자 단위 청크로 분할하여 출력 잘림 방지
    - JSON 강제 출력 대신 순수 텍스트 희곡식 스크립트로 응답 받음

    - 각 대사는 다음 형식을 따름
      - `(emotion_label|exaggeration=0.35|cfg_weight=0.60) 대사`
    - 사용자 입력 텍스트의 의미, 사실, 날짜, 금액, 고유명사, 인용문을 임의로 변경하지 않음

      - 예: `27일` → `이십칠일`

      - 예: `5조원` → `오조원`
    - 영어 대문자 약자를 한국어 발음 형태로 변환
      - 예: `AI` → `에이아이`
      - 예: `AM` → `에이엠`
      - 예: `SDLC` → `에스디엘시`
    - 전처리 결과를 scripts/ 디렉토리에 저장
      - `hands-on/06.tts/chatterbox-single/scripts/script_{YYYYMMDD}_{HHMMSS}.txt`
      - 타임스탬프는 한국시간(`Asia/Seoul`) 기준

    - Chatterbox Multilingual은 한국어 포함 23개 언어 네이티브 지원 (번역 불필요)
    - Groq가 생성한 희곡식 스크립트를 사용자의 참조 음성으로 복제하여 생성
    - 괄호 안 감정 지시문은 음성으로 읽지 않고 파싱하여 생성 파라미터로만 사용
    - 톤앤매너 추가 프롬프트를 기반으로 대사별 `exaggeration`, `cfg_weight` 결정
    - Chatterbox Multilingual은 자연어 감정 지시문보다 `exaggeration`, `cfg_weight` 값에 의존함
    - 필요한 경우에만 `[laugh]`, `[cough]`, `[chuckle]` 등 Chatterbox 지원 비언어 태그를 대사에 삽입
    - 장문은 문장/문단 단위로 분할 생성 후 연결
    - 너무 짧은 세그먼트는 앞뒤 대사와 병합하여 내부 정렬 오류 가능성 완화

    - 세그먼트별 독립 노이즈 제거로 청크 경계 노이즈 불일치 최소화
    - Chatterbox 내부 AlignmentStreamAnalyzer 빈 슬라이스 IndexError에 대한 안전 래퍼 적용
    - API: `model.generate(text, language_id="ko", audio_prompt_path=..., exaggeration=..., cfg_weight=...)`
    - 파라미터 안내
      - exaggeration (기본 0.5): 감정 표현 강도, 높을수록 표현력 증가
      - cfg_weight (기본 0.5): 화자 일관성 제어, 낮을수록 억양 전달 감소
  - 음성파일 생성
    - `hands-on/06.tts/chatterbox-single/results/result_{YYYYMMDD}_{HHMMSS}.wav`
    - 타임스탬프는 한국시간(`Asia/Seoul`) 기준
    - 예: `result_20260527_181010.wav`
    - 출력 형식: WAV (16-bit PCM)

  - (중요) message 파라미터(@MyShell)는 오디오에 불가청 워터마크로 삽입됨
  - (중요) tgt_se(화자 임베딩)는 화자당 1회만 추출 후 재사용 — 라인마다 재추출 시 성능 저하
  - (중요) WAV 외 참조 음성(MP3/M4A/FLAC/OGG 등)은 최초 실행 시 ffmpeg로 WAV 변환하여 voices/ 에 저장,
    이후 실행에서는 변환된 WAV 직접 사용 (임시 파일 방식 아님)
  - (중요) 기존 mapping.json에 비-WAV 파일명이 있으면 변환된 WAV 파일명으로 자동 마이그레이션
  - (중요) 매핑 파일 존재 시 "Change mapping? (y/N)" 프롬프트로 재선택 기회 제공
