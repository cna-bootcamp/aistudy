## 2. 개요

### 2.1 텍스트 요약 (Text Summarization)

긴 텍스트에서 핵심 내용을 추출하여 짧고 간결한 형태로 변환하는 자연어 처리 기술. 정보 과부하 시대에 효율적인 문서 처리를 위한 핵심 기술로 활용.

### 2.2 요약 방식

| 방식 | 설명 |
|------|------|
| **추출적 요약 (Extractive)** | 원문에서 중요한 문장을 그대로 추출하여 요약 구성 |
| **생성적 요약 (Abstractive)** | 원문 내용을 이해하고 새로운 문장으로 재구성하여 요약 생성 |

### 2.3 주요 활용 사례

| 분야 | 설명 |
|------|------|
| **뉴스 요약** | 긴 뉴스 기사를 헤드라인이나 짧은 요약으로 변환 |
| **문서 분석** | 보고서, 논문, 계약서 등 장문 문서의 핵심 내용 추출 |
| **회의록 요약** | 회의 내용을 간략한 액션 아이템으로 정리 |
| **RAG 파이프라인** | 검색된 문서를 요약하여 LLM 컨텍스트 효율화 |

## 3. 모델 정보

### 3.1 LLM 기반 요약

대규모 언어 모델(LLM)을 활용한 생성적 요약 방식. 높은 품질의 요약과 맥락 이해 능력이 특징.

#### 3.1.1 Cloud LLM

API를 통해 클라우드에서 실행되는 대규모 언어 모델. GPU 불필요, API Key만으로 즉시 사용 가능.

**주요 제공자 비교**

| 제공자 | 대표 모델 | 특징 | 비용 |
|--------|-----------|------|------|
| **Groq** | llama-3.3-70b-versatile | LPU 기반 초고속 추론 (456 tok/s) | 무료 티어 제공 |
| OpenAI | gpt-4o | 멀티모달, 높은 품질 | 유료 |
| Anthropic | claude-sonnet-4 | 안전성, 긴 컨텍스트 | 유료 |
| Google | gemini-2.0-flash | TPU 기반, 빠른 속도 | 무료 티어 제공 |

**Groq 특징**
- LPU(Language Processing Unit): AI 추론 전용 하드웨어
- GPU 대비 6~10배 빠른 토큰 생성 속도
- OpenAI 호환 API (기존 코드 쉽게 전환)

**핵심 코드**

```python
from groq import Groq
from dotenv import load_dotenv
import os

# API 키 로드
load_dotenv()
client = Groq(api_key=os.getenv("GROQ_API_KEY"))

# 요약 요청
response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    max_tokens=4096,
    messages=[{"role": "user", "content": f"다음 문서를 요약해 주세요:\n{text}"}]
)

summary = response.choices[0].message.content
```

#### 3.1.2 EXAONE (LG AI Research)

LG AI연구원에서 개발한 한국어/영어 이중언어 대규모 언어 모델. 과기정통부 AI 파운데이션 모델 평가에서 종합 1위 기록.

**특징**
- 한국어/영어 이중언어 지원
- Instruction-tuned 모델 (Base/Instruct 구분 없음)

  | 구분 | Base 모델 | Instruct 모델 |
  |------|-----------|---------------|
  | 학습 방식 | 사전학습(Pre-training)만 수행 | 사전학습 + 지시 미세조정(SFT/RLHF) |
  | 용도 | 다음 토큰 예측, 텍스트 완성 | 사용자 지시 수행, 대화형 응답 |
  | 예시 | Llama-3-8B | Llama-3-8B-Instruct |

- apply_chat_template 사용 시 enable_thinking=False 설정 필요
- 한국어 요약 시 temperature=0.1 권장 

**제한사항**
- transformers >= 4.54.0 필요
- 첫 실행 시 약 2.5GB 모델 다운로드

**핵심 코드**

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "LGAI-EXAONE/EXAONE-4.0-1.2B"
tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    dtype=torch.float16,
    device_map="auto",
    trust_remote_code=True
)

# Chat 템플릿 적용 (reasoning 모드 비활성화)
messages = [{"role": "user", "content": prompt}]
formatted_prompt = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True, enable_thinking=False
)

# 텍스트 생성
generated_ids = model.generate(
    input_ids, attention_mask=attention_mask,
    max_new_tokens=2048, temperature=0.1, repetition_penalty=1.1
)
```

### 3.2 특화 요약 모델 기반

특정 언어나 도메인에 최적화된 요약 전용 모델. 경량화되어 빠른 추론 속도 제공.

#### 3.2.1 KoBART-summarization (SKT AI)

SKT AI에서 개발한 한국어 BART 모델. 국내 뉴스 및 문서 요약 데이터셋으로 파인튜닝된 생성 요약 모델.

**특징**
- 한국어 전용 요약 모델
- BART (Bidirectional and Auto-Regressive Transformers) 아키텍처
- 경량 모델로 빠른 추론 속도
- 청크 분할로 긴 문서 처리 가능

**핵심 코드**

```python
from transformers import PreTrainedTokenizerFast, BartForConditionalGeneration

model_name = "gogamza/kobart-summarization"
tokenizer = PreTrainedTokenizerFast.from_pretrained(model_name)
model = BartForConditionalGeneration.from_pretrained(model_name)

# 요약 생성
inputs = tokenizer(text, max_length=1024, truncation=True, return_tensors="pt")
summary_ids = model.generate(
    input_ids=inputs["input_ids"],
    max_length=150, min_length=30,
    num_beams=4, length_penalty=1.0, no_repeat_ngram_size=3
)
summary = tokenizer.decode(summary_ids[0], skip_special_tokens=True)
```

#### 3.2.2 기타 요약 모델

| 분류 | 모델 | 특징 | Hugging Face 경로 |
|------|------|------|------------------|
| **한국어 전용** | pko-T5 | 한국어 논문/도서/레포트 요약 특화 | `eenzeenee/t5-base-korean-summarization` |
| **다국어** | mT5 | 50개 이상 언어 지원, Text-to-Text 방식 | `google/mt5-small`, `google/mt5-base` |

| **영어 전용** | DistilBART | 경량화된 BART, 빠른 추론 | `sshleifer/distilbart-cnn-12-6` |

### 4.3 LPU 사용

LPU(Language Processing Unit)는 Groq이 설계한 AI 추론 전용 프로세서.
GPU 대비 최대 **6~10배** 빠른 토큰 생성 속도가 특징이며,
OpenAI 호환 API로 간편하게 사용 가능.

**5개 모델 속도 비교 결과** (동일 문서 16,755자 요약)

| 순위 | 모델 | 소요 시간 | 처리 속도 (tok/s) |
|------|------|----------|------------------|
| 1 | **Groq (LPU)** | 7.22초 | **456.1** |
| 2 | Gemini 2.0 Flash | 8.50초 | 149.4 |
| 3 | OpenAI GPT-4o | 14.50초 | 34.7 |
| 4 | Claude Sonnet 4 | 33.81초 | 43.1 |
| 5 | Claude Opus 4.5 | 41.46초 | 56.2 |

**용도별 추천**

| 용도 | 추천 모델 |
|------|----------|
| 실시간 챗봇/스트리밍 | Groq (LPU) — 초저지연 |
| 문서 요약 (품질 우선) | Claude Opus 4.5 — 체계적 구조화 |
| 비용 효율 | Claude Sonnet 4 또는 Gemini Flash |

**Groq 단독 실행 방법**

위 비교 결과는 참고용 측정치임. 현재 실습 예제(`hands-on/03.summary/groq/summary.py`)는  
Groq 단일 모델(`openai/gpt-oss-120b`)로 문서를 요약하는 예제임.

```bash
cd hands-on/03.summary/groq
python -m venv venv
# Windows
venv\Scripts\Activate.ps1
# macOS/Linux
# source venv/bin/activate
pip install -r requirements.txt
python summary.py
```

> `hands-on/.env` 또는 실행 디렉터리 `.env`에 API Key 설정 필요:
> `GROQ_API_KEY=gsk_xxxx...`
