## 2. 개요

### 2.1 PDF 처리

PDF(Portable Document Format)에서 텍스트, 테이블, 이미지 등의 데이터를 추출하여 구조화된 형식(Markdown, JSON 등)으로 변환하는 기술. LLM 및 RAG(검색 증강 생성) 파이프라인의 데이터 전처리 단계에서 핵심적인 역할 담당.

### 2.2 OCR (Optical Character Recognition)

스캔된 문서나 이미지 내의 텍스트를 인식하여 편집 가능한 텍스트로 변환하는 기술. PDF 내 이미지화된 텍스트 추출 시 필수.

### 2.3 주요 활용 사례

| 분야 | 설명 |
|------|------|
| **RAG 데이터 전처리** | PDF 문서를 청킹하여 벡터 DB에 저장하기 위한 텍스트 추출 |
| **문서 자동화** | 계약서, 보고서, 명세서 등에서 정형 데이터 추출 |
| **지식 베이스 구축** | 기술 문서, 논문 등을 마크다운으로 변환하여 검색 시스템 구축 |
| **데이터 마이그레이션** | 레거시 PDF 문서를 최신 포맷으로 변환 |

## 3. 모델 정보

### 3.1 AI 기반 PDF 처리

복잡한 레이아웃과 테이블 구조를 AI 모델로 분석하여 정확하게 추출하는 방식. 설치가 복잡하지만 정확도 높음.

#### 3.1.1 Docling (IBM)

IBM에서 개발한 문서 처리 라이브러리. PDF, DOCX, PPTX 등 다양한 포맷 지원.

**특징**
- 복잡한 다단 레이아웃, 중첩된 테이블을 Markdown/JSON으로 완벽 변환
- OCR 내장 (EasyOCR 기반, 한국어/영어 지원)
- TableFormer 모델로 정밀한 테이블 구조 분석
- 수식, 코드 블록, 이미지 캡션 인식 지원
- 하드웨어 가속 지원 (CPU/CUDA/MPS 자동 감지)

**제한사항**
- 초기 모델 다운로드 필요 (~2GB+)

**핵심 코드**

```python
from docling.document_converter import DocumentConverter, PdfFormatOption
from docling.datamodel.base_models import InputFormat
from docling.datamodel.pipeline_options import (
    PdfPipelineOptions, TableFormerMode, TableStructureOptions, EasyOcrOptions
)

pipeline_options = PdfPipelineOptions()
pipeline_options.do_ocr = True
pipeline_options.ocr_options = EasyOcrOptions(lang=["ko", "en"])
pipeline_options.table_structure_options = TableStructureOptions(
    mode=TableFormerMode.ACCURATE
)

converter = DocumentConverter(
    format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=pipeline_options)}
)
result = converter.convert(pdf_path)
```

### 3.2 규칙 기반 PDF 처리

PDF 내부 구조를 직접 파싱하여 텍스트와 객체를 추출하는 방식. 설치가 간단하고 속도 빠름.

#### 3.2.1 PyMuPDF (fitz)

MuPDF 엔진의 Python 바인딩. 속도와 범용성이 뛰어난 전통의 강자.

**특징**
- 처리 속도가 다른 라이브러리 대비 수배~수십 배 빠름
- PDF 수정, 페이지 병합 등 편집 기능 강력
- pymupdf4llm 확장으로 LLM 최적화 Markdown 출력 제공
- 이미지 추출 능력 최상

**핵심 코드**

```python
import pymupdf4llm

# margins: (left, top, right, bottom) - 단위: 포인트 (72pt = 1인치)
md_text = pymupdf4llm.to_markdown(
    pdf_path,
    margins=(0, 50, 0, 50),  # 상단/하단 헤더/푸터 영역 제외
    show_progress=True,
    write_images=False,
)
```

#### 3.2.2 pdfplumber

PDF 내부 객체(선, 사각형, 글자 등)의 좌표 정보를 상세하게 제공하는 라이브러리.

**특징**
- 테이블 경계선이 없거나 복잡한 경우에도 파라미터 조정으로 정밀 추출 가능
- 시각적 디버깅 기능 제공
- pdfminer.six 기반으로 텍스트 추출 정교함 높음
- 페이지 crop 기능으로 특정 영역만 추출 가능

**핵심 코드**

```python
import pdfplumber

HEADER_RATIO = 0.07  # 상단 7% 제외
FOOTER_RATIO = 0.07  # 하단 7% 제외

with pdfplumber.open(pdf_path) as pdf:
    for page in pdf.pages:
        # 본문 영역만 크롭
        body_bbox = (0, page.height * HEADER_RATIO, 
                     page.width, page.height * (1 - FOOTER_RATIO))
        body_page = page.crop(body_bbox)
        
        text = body_page.extract_text(layout=True)
        tables = body_page.extract_tables()
```

### 3.3 방식별 비교 정리

프로젝트 상황에 따른 최적 라이브러리 선택 가이드.

| 구분 | Docling | PyMuPDF | pdfplumber |
| :--- | :--- | :--- | :--- |
| **설치 난이도** | ⭐⭐⭐⭐⭐ (복잡) | ⭐ (매우 쉬움) | ⭐ (매우 쉬움) |
| **GPU 필요** | O (권장, CPU 가능) | X | X |
| **텍스트 추출** | 매우 우수 (구조 중심) | 우수 (속도 중심) | 매우 우수 (위치 중심) |
| **테이블 추출** | **최상 (AI 분석)** | 우수 | 우수 (세밀한 설정 가능) |
| **이미지 추출** | 우수 | **최상** | 보통 |
| **OCR 지원** | **내장 (EasyOCR)** | 외부 연동 필요 | 외부 연동 필요 |
| **처리 속도** | 느림 | **매우 빠름** | 느림 |
| **비용** | **무료 (로컬)** | **무료 (로컬)** | **무료 (로컬)** |
| **권장 용도** | **RAG/AI 학습 데이터 전처리** | 대용량 PDF 빠른 처리 | 정형 서식 정밀 추출 |

### 4.2 작성 프롬프트
프롬프트를 사용하여 직접 예제를 개발하는 가이드입니다.  

#### PyMuPDF/pdfplumber 예제
hands-on/04.pdf/PyMuPDF/pdf2md.py, hands-on/04.pdf/pdfplumber/pdf2md.py 참조

```
[목표]
PDF를 마크다운으로 변환하는 프로그램 개발
[역할]
당신은 AI 개발자임
[입력]
- 대상 PDF: hands-on/04.pdf/AI GARAGE Proposal.pdf
[처리]
- 대상 PDF를 파일을 `hands-on/04.pdf/`으로 복사  
- PyMuPDF와 pdfplumber 라이브러리를 사용한 예제를 에이젼트를 호출하여 병렬로 개발 
  - {LIBRARY}: {PyMuPDF 또는 pdfplumber}로 지정
  - {LIBRARY명} 라이브러리를 사용하여 파이썬으로 개발
  - 의존성 정의: requirements.txt
  - 변환 결과파일 경로: result.md
- 개발된 프로그램 테스트 및 버그 Fix: 에이젼트 호출하여 병렬 수행
- 각 {LIBRARY}/README.md 파일에 어플리케이션 소스 설명과 가상환경에서의 실행 방법 작성
[출력]
- hands-on/04.pdf/{LIBRARY}/pdf2md.py
- hands-on/04.pdf/{LIBRARY}/requirements.txt
- hands-on/04.pdf/{LIBRARY}/README.md

[제약조건]
- MUST
  - 헤더와 푸터의 텍스트는 제외하고 본문만 변환
  - GPU 사용 시 PyTorch는 CUDA 12.1 이상에서 다운로드

```

#### Docling 예제

```

PDF를 마크다운으로 변환하는 프로그램 개발
[역할]
당신은 AI 개발자임
[입력]
- 대상 PDF: hands-on/04.pdf/AI GARAGE Proposal.pdf
- {LIBRARY}: docling
[처리]
- {LIBRARY} 라이브러리를 사용하여 파이썬으로 개발
  - OCR을 이용하여 원본의 스캔된 이미지에서 텍스트 추출 (한국어/영어)
  - 헤더(Header)와 푸터(Footer)를 제외하고 본문만 변환
  - TableFormer ACCURATE 모드로 정확한 테이블 추출
  - 수식 및 코드 블록 인식
  - 이미지 추출 및 캡션 처리
  - 원본 PDF 내 이미지를 별도 파일로 추출
    - generate_page_images 사용하여 페이지 전체 이미지 생성
    - generate_picture_images 사용하여 문서 내 그림/사진 추출
    - 이미지 저장 경로: `hands-on/04.pdf/{LIBRARY}/images/` 디렉토리 하위에 생성
    - 마크다운에서 이미지 참조 시 상대경로 사용 (예: images/image_1.png)
  - 의존성 정의: requirements.txt
  - 변환파일 경로: hands-on/04.pdf/{LIBRARY}/result.md
[출력]
- hands-on/04.pdf/{LIBRARY}/pdf2md.py
- hands-on/04.pdf/{LIBRARY}/requirements.txt
- hands-on/04.pdf/{LIBRARY}/README.md

[제약사항]
- MUST: 
  - 하드웨어 가속 지원 (CPU/CUDA/MPS 자동 감지)
  - GPU 사용 시 PyTorch는 CUDA 12.1 이상에서 다운로드
  - 아래 라이브러리 반드시 포함
    - easyocr: OCR엔진
    - hf_xet: Hugging Face 모델 고속 다운로드
```
