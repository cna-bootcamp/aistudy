# n8n Cloud 무료 체험

n8n Cloud의 14일 무료 체험을 통해 모든 기능을 제한 없이 사용 가능

## 무료 체험 혜택

### 포함 기능
- 모든 Pro 기능 사용 가능
- 무제한 워크플로우 생성
- 모든 통합 노드 사용
- AI 기능 포함
- Source Control 지원
- 팀 협업 기능

### 제한 사항
- 14일 시간 제한
- 체험 종료 후 자동 비활성화
- 신용카드 등록 불필요

## 무료 체험 시작 방법

### 1단계: 계정 생성
```
1. n8n.io/cloud 방문
2. "Start Free Trial" 버튼 클릭
3. 이메일 주소 입력
4. 비밀번호 설정
5. 이메일 인증 완료
```

### 2단계: 워크스페이스 설정
```
1. 워크스페이스 이름 입력
2. 사용 목적 선택
3. 팀 규모 선택
4. 초기 설정 완료
```

### 3단계: 첫 워크플로우 생성
```
1. "Create Workflow" 클릭
2. 템플릿 선택 또는 빈 워크플로우 시작
3. 노드 추가 및 연결
4. 워크플로우 테스트
5. 활성화
```

## 무료 체험 이후

### 유료 플랜 전환
- 체험 기간 중 언제든지 전환 가능
- 기존 워크플로우 및 데이터 유지
- 신용카드 등록 후 즉시 활성화

### 체험 종료 시
- 워크플로우 자동 비활성화
- 데이터는 30일간 보관
- 내보내기 기능 사용 가능
- 재활성화는 유료 플랜 구독 후 가능

## 체험 기간 활용 팁

### 1주차: 기본 기능 익히기
- 노드 사용법 학습
- 간단한 워크플로우 생성
- 트리거 및 조건문 활용

### 2주차: 고급 기능 활용
- AI 노드 실험
- Source Control 설정
- 팀 협업 기능 테스트
- 복잡한 워크플로우 구축

## 자주 묻는 질문

### Q: 신용카드가 필요한가요?
A: 아니요, 무료 체험은 신용카드 없이 시작 가능

### Q: 체험 종료 후 자동 결제되나요?
A: 아니요, 자동 결제 없음. 수동으로 플랜을 선택해야 함

### Q: 데이터는 어떻게 되나요?
A: 30일간 보관되며 내보내기 가능

### Q: 팀 멤버를 추가할 수 있나요?
A: 가능. 무료 체험 중 팀 협업 기능 전부 사용 가능
