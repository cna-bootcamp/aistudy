# Cloud 관리자 대시보드

n8n Cloud 관리자 대시보드는 워크스페이스의 모든 측면을 관리할 수 있는 중앙 집중식 관리 인터페이스

## 대시보드 접근

### 접근 방법
```
1. n8n Cloud 로그인
2. 우측 상단 프로필 아이콘 클릭
3. "Settings" 선택
4. "Admin Dashboard" 메뉴 선택
```

### 필요 권한
- Owner 또는 Admin 역할 필요
- Member 역할은 제한된 설정만 접근 가능

## 주요 기능 섹션

### 1. Overview (개요)
- 워크스페이스 전체 통계
- 활성 워크플로우 수
- 월간 실행 횟수
- 팀 멤버 수
- 사용 현황 그래프

### 2. Users (사용자 관리)
- 팀 멤버 목록 조회
- 새 사용자 초대
- 역할 및 권한 관리
- 사용자 비활성화/제거
- 대기 중인 초대 관리

### 3. Billing (결제 관리)
- 현재 플랜 정보
- 사용량 및 청구 내역
- 결제 방법 관리
- 청구서 다운로드
- 플랜 업그레이드/다운그레이드

### 4. Security (보안 설정)
- 2단계 인증(2FA) 설정
- SSO 구성
- API 키 관리
- 세션 관리
- 보안 로그 조회

### 5. Workspace Settings (워크스페이스 설정)
- 워크스페이스 이름 변경
- 시간대 설정
- 기본 언어 설정
- 알림 설정
- 데이터 보존 정책

### 6. Integrations (통합 관리)
- OAuth 앱 관리
- 웹훅 설정
- 외부 서비스 연동
- API 액세스 관리

### 7. Audit Logs (감사 로그)
- 사용자 활동 로그
- 워크플로우 변경 이력
- 보안 이벤트
- 로그 필터링 및 내보내기

## 사용자 관리

### 사용자 초대
```
1. Users 섹션 이동
2. "Invite User" 클릭
3. 이메일 주소 입력
4. 역할 선택 (Owner/Admin/Member)
5. 초대 이메일 발송
```

### 역할 변경
```
1. Users 목록에서 사용자 선택
2. 역할 드롭다운 클릭
3. 새 역할 선택
4. 변경사항 저장
```

### 사용자 제거
```
1. Users 목록에서 사용자 선택
2. "Remove" 버튼 클릭
3. 확인 대화상자에서 확인
4. 사용자 즉시 접근 차단
```

## 결제 및 플랜 관리

### 현재 플랜 확인
- Billing 섹션에서 조회
- 포함된 기능 목록
- 사용 한도 및 현재 사용량
- 다음 결제 예정일

### 결제 방법 추가
```
1. Billing > Payment Methods
2. "Add Payment Method" 클릭
3. 카드 정보 입력
4. 저장
```

### 청구서 다운로드
```
1. Billing > Invoices
2. 원하는 청구서 선택
3. "Download" 버튼 클릭
4. PDF 다운로드
```

## 보안 설정

### 2FA 강제 적용
```
1. Security 섹션 이동
2. "Enforce 2FA" 토글 활성화
3. 유예 기간 설정 (예: 7일)
4. 모든 사용자에게 알림 발송
```

### SSO 설정
```
1. Security > SSO Configuration
2. SSO 제공자 선택 (SAML/OIDC)
3. 인증서 및 메타데이터 업로드
4. 도메인 매핑 설정
5. 테스트 로그인 수행
```

### API 키 관리
```
1. Security > API Keys
2. "Generate New Key" 클릭
3. 키 이름 및 권한 설정
4. 키 생성 및 안전하게 저장
```

## 워크스페이스 설정

### 시간대 변경
```
1. Workspace Settings 이동
2. Timezone 드롭다운 선택
3. 원하는 시간대 선택
4. Save 클릭
```

### 데이터 보존 설정
```
1. Workspace Settings > Data Retention
2. 실행 데이터 보존 기간 설정
3. 자동 삭제 정책 구성
4. 변경사항 저장
```

## 감사 로그 활용

### 로그 조회
```
1. Audit Logs 섹션 이동
2. 날짜 범위 선택
3. 이벤트 유형 필터링
4. 사용자별 필터링
```

### 로그 내보내기
```
1. 필터 조건 설정
2. "Export" 버튼 클릭
3. 형식 선택 (CSV/JSON)
4. 다운로드
```

## 모니터링 및 알림

### 사용량 모니터링
- 실시간 실행 현황
- 월간 사용 추이
- 한도 근접 알림
- 이상 활동 감지

### 알림 설정
```
1. Workspace Settings > Notifications
2. 알림 유형 선택
   - 사용량 한도 근접
   - 보안 이벤트
   - 결제 관련
   - 시스템 업데이트
3. 수신자 설정
4. 저장
```
