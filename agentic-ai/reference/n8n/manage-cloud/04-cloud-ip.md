# Cloud IP 주소

n8n Cloud에서 사용하는 IP 주소 정보 및 방화벽 설정 가이드

## 중요 사항

⚠️ **IP 주소 변경 가능성**

n8n Cloud의 IP 주소는 사전 통지 없이 변경될 수 있음. n8n은 동적 클라우드 환경에서 운영되며 수요에 따라 인프라를 확장하므로 정적 소스 IP를 보장할 수 없음

**권장사항:**
- 강력한 인증 사용
- 안전한 전송 프로토콜 사용
- IP 기반 화이트리스트보다 OAuth 또는 API 키 인증 선호

## IP 주소 사용 시나리오

### 방화벽 화이트리스트
외부 서비스가 방화벽으로 보호되는 경우 위 IP 주소를 화이트리스트에 추가 가능

**설정 예시 (iptables):**
```bash
# n8n Cloud IP 허용
iptables -A INPUT -s 20.79.227.226/32 -j ACCEPT
iptables -A INPUT -s 20.113.47.122/32 -j ACCEPT
iptables -A INPUT -s 20.218.202.73/32 -j ACCEPT
# ... 나머지 IP 추가
```

### 데이터베이스 접근 제어
데이터베이스 방화벽 규칙에 n8n Cloud IP 추가

**AWS RDS 예시:**
```
Security Group Inbound Rules:
Type: PostgreSQL
Protocol: TCP
Port: 5432
Source: 20.79.227.226/32
```

### API 서버 접근 제어
자체 API 서버에 대한 접근 제어

**Nginx 예시:**
```nginx
location /api {
    allow 20.79.227.226/32;
    allow 20.113.47.122/32;
    # ... 나머지 IP 추가
    deny all;

    proxy_pass http://backend;
}
```

## 보안 모범 사례

### 1. 인증 기반 보안 우선
```
✅ 권장:
- OAuth 2.0 인증
- API 키 인증
- JWT 토큰 인증
- 상호 TLS (mTLS)

❌ 비권장:
- IP 주소만으로 인증
- 기본 인증 (HTTP Basic Auth)
- 인증 없는 공개 엔드포인트
```

### 2. 전송 계층 보안
```
- HTTPS/TLS 1.2 이상 필수
- 인증서 검증 활성화
- 안전한 암호화 스위트 사용
```

### 3. 다층 보안
```
IP 화이트리스트 + 인증 + 암호화
```

## IP 변경 대응 방안

### 자동화된 IP 업데이트
```python
import requests

def update_firewall_rules():
    # n8n Cloud IP 목록 가져오기
    response = requests.get('https://api.n8n.io/cloud-ips')
    ip_list = response.json()['ips']

    # 방화벽 규칙 업데이트
    for ip in ip_list:
        add_firewall_rule(ip)
```

### 알림 설정
```
1. n8n Cloud 상태 페이지 구독
2. IP 변경 시 이메일 알림 수신
3. 자동화된 규칙 업데이트 트리거
```

### 정기 검토
```
- 월간 IP 목록 검토
- 방화벽 규칙 동기화
- 미사용 IP 제거
```

## 트러블슈팅

### 연결 실패 문제
```
증상: n8n 워크플로우가 외부 서비스에 연결 실패

해결 단계:
1. 대상 서비스의 방화벽 로그 확인
2. n8n Cloud IP가 허용되어 있는지 확인
3. 모든 IP 주소가 규칙에 포함되어 있는지 검증
4. 포트 및 프로토콜 확인
```

### 간헐적 연결 문제
```
증상: 때때로 연결되고 때때로 실패

원인: 새로운 IP 주소 사용 시작
해결: 최신 IP 목록으로 방화벽 규칙 업데이트
```

```
1. 영업팀 문의: sales@n8n.io
2. Enterprise 플랜 구독
3. Static IP 옵션 추가
4. IP 주소 할당 및 구성
```
