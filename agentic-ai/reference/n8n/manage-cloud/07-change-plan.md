# 플랜 변경

n8n Cloud 플랜을 업그레이드, 다운그레이드 또는 취소하는 방법

## 플랜 비교

### Starter
```
가격: $20/월 (연간 결제 시 할인)

포함 사항:
- 2,500 워크플로우 실행/월
- 20개 활성 워크플로우
- 5 GB 스토리지
- 이메일 지원
- 7일 실행 히스토리
- 2명 팀 멤버
```

### Pro
```
가격: $50/월 (연간 결제 시 할인)

포함 사항:
- 10,000 워크플로우 실행/월
- 50개 활성 워크플로우
- 20 GB 스토리지
- 우선 이메일 지원
- 30일 실행 히스토리
- 5명 팀 멤버
- Source Control
- 고급 권한 관리
```

### Enterprise
```
가격: 맞춤형 견적

포함 사항:
- 무제한 워크플로우 실행
- 무제한 활성 워크플로우
- 무제한 스토리지
- 전담 지원 (SLA 포함)
- 90일+ 실행 히스토리
- 무제한 팀 멤버
- SSO (SAML/OIDC)
- Static IP
- 맞춤형 SLA
- 온보딩 지원
- 전담 계정 관리자
```

## 플랜 업그레이드

### 업그레이드 절차

**1단계: 현재 플랜 확인**
```
1. Settings > Billing
2. Current Plan 섹션 확인
3. 사용량 통계 검토
```

**2단계: 플랜 선택**
```
1. Settings > Billing > Change Plan
2. 원하는 플랜 선택
3. 연간/월간 결제 선택
4. 추가 옵션 선택 (있는 경우)
```

**3단계: 결제 정보 입력**
```
1. 결제 방법 선택:
   - 신용카드
   - 청구서 발행 (Enterprise)
2. 카드 정보 입력
3. 청구 주소 입력
4. Confirm
```

**4단계: 즉시 적용**
```
- 업그레이드 즉시 적용
- 기존 데이터 및 워크플로우 유지
- 새로운 한도 즉시 사용 가능
- 비례 배분 청구 (Pro-rated)
```

### 업그레이드 시기

**권장 업그레이드 시나리오:**
```
Starter → Pro:
- 실행 한도 80% 이상 사용
- 5개 이상 팀 멤버 필요
- Source Control 필요
- 더 긴 실행 히스토리 필요

Pro → Enterprise:
- 대규모 팀 (10명 이상)
- 높은 실행 빈도
- SSO 필요
- Static IP 필요
- SLA 보장 필요
```

## 플랜 다운그레이드

### 다운그레이드 절차

**1단계: 영향 평가**
```
다운그레이드 전 확인 사항:
- 현재 사용량이 새 플랜 한도 내인가?
- 사용 중인 기능이 새 플랜에 포함되는가?
- 팀 멤버 수가 한도 내인가?
- 데이터 손실 가능성은 없는가?
```

**2단계: 플랜 선택**
```
1. Settings > Billing > Change Plan
2. 다운그레이드할 플랜 선택
3. 영향 받는 항목 검토
4. Continue
```

**3단계: 조정 작업**
```
필요한 경우:
- 초과 워크플로우 비활성화
- 팀 멤버 제거
- 데이터 정리
- 기능 사용 중단
```

**4단계: 확인 및 적용**
```
- 다음 결제 주기부터 적용
- 현재 주기는 기존 플랜 유지
- 환불 없음 (이미 결제된 기간)
```

### 다운그레이드 영향

**Pro → Starter 다운그레이드 시:**
```
제한되는 기능:
- Source Control 비활성화
- 고급 권한 관리 비활성화
- 실행 히스토리 7일로 축소
- 팀 멤버 2명으로 제한
- 활성 워크플로우 20개로 제한
```

**데이터 처리:**
```
- 초과 워크플로우는 자동 비활성화
- 실행 히스토리는 보존 기간 후 삭제
- Source Control 데이터는 읽기 전용
```

## 플랜 취소

### 취소 절차

**1단계: 데이터 백업**
```
중요: 취소 전 반드시 백업!

1. Workflows > Export All
2. Credentials 정보 기록
3. 중요 실행 데이터 내보내기
4. 설정 정보 기록
```

**2단계: 취소 요청**
```
1. Settings > Billing
2. Cancel Subscription 버튼
3. 취소 이유 선택 (피드백)
4. Confirm Cancellation
```

**3단계: 계정 처리**
```
취소 즉시:
- 신규 실행 중단
- 워크플로우 비활성화
- 읽기 전용 모드 전환

취소 후 30일:
- 데이터 보존
- 내보내기 가능
- 재활성화 가능

30일 후:
- 계정 영구 삭제
- 데이터 영구 삭제
- 복구 불가능
```

## 결제 관리

### 결제 방법 관리

**카드 추가/변경:**
```
1. Settings > Billing > Payment Methods
2. Add Payment Method
3. 카드 정보 입력
4. Make Default (기본 카드로 설정)
5. Save
```

**결제 실패 처리:**
```
결제 실패 시:
1. 이메일 알림 발송
2. 3일 내 재시도 (3회)
3. 계정 일시 중단
4. 7일 내 미결제 시 취소

복구:
1. 결제 정보 업데이트
2. 미결제 금액 결제
3. 계정 즉시 재활성화
```

### 청구서 관리

**청구서 조회:**
```
1. Settings > Billing > Invoices
2. 청구서 목록 확인
3. 상세 내역 클릭
```

**청구서 다운로드:**
```
1. Invoice 클릭
2. Download PDF 버튼
3. 저장 또는 인쇄
```

**청구 정보 변경:**
```
1. Settings > Billing > Billing Information
2. 회사명, 주소, 세금 ID 등 수정
3. Save
4. 다음 청구서부터 반영
```

## 사용량 모니터링

### 실시간 사용량 확인
```
1. Settings > Usage
2. 현재 사용량 확인:
   - Workflow Executions
   - Active Workflows
   - Storage Used
   - Team Members
3. 추세 그래프 확인
```

### 사용량 알림 설정
```
1. Settings > Notifications
2. Usage Alerts 섹션
3. 알림 임계값 설정:
   - 80% 사용 시 경고
   - 95% 사용 시 긴급 알림
4. 수신자 이메일 설정
5. Save
```

### 사용량 최적화

**실행 횟수 줄이기:**
```
- 폴링 간격 조정
- 조건부 실행 활용
- 중복 워크플로우 통합
- 배치 처리 사용
```

**스토리지 최적화:**
```
- 오래된 실행 데이터 삭제
- Binary 데이터 외부 저장
- 로그 레벨 조정
- 정기적인 정리
```

## 연간 결제 할인

### 할인 혜택
```
월간 결제 대비:
- Starter: 15% 할인
- Pro: 20% 할인

예시:
Pro 플랜 월 $50
- 월간: $50 x 12 = $600/년
- 연간: $480/년 (20% 할인)
- 절감액: $120/년
```

### 연간 플랜 전환
```
1. Settings > Billing
2. Switch to Annual Billing
3. 할인 금액 확인
4. Confirm
5. 즉시 연간 요금 청구
6. 월별 크레딧 적용
```

## Enterprise 플랜

### 견적 요청
```
1. n8n.io/pricing 방문
2. "Contact Sales" 클릭
3. 정보 입력:
   - 회사명
   - 예상 사용량
   - 필요 기능
   - 팀 규모
4. 영업팀 연락 대기
```

### 맞춤 계약
```
협상 가능 항목:
- 가격 및 볼륨 할인
- SLA 조건
- 데이터 센터 위치
- 전담 지원 수준
- 계약 기간
- 결제 조건
```

## 자주 묻는 질문

### Q: 업그레이드 시 즉시 적용되나요?
A: 네, 업그레이드는 즉시 적용되며 새로운 한도를 바로 사용 가능

### Q: 다운그레이드 시 환불받나요?
A: 아니요, 이미 결제된 기간은 환불되지 않음. 다음 주기부터 새 요금 적용

### Q: 연중에 연간 플랜으로 전환 가능한가요?
A: 가능. 남은 월간 크레딧이 적용되어 연간 요금에서 차감됨

### Q: 무료로 다시 전환할 수 있나요?
A: n8n Cloud는 무료 플랜이 없음. 취소 후 Self-hosted 버전 사용 가능
