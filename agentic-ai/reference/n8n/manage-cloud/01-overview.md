# n8n Cloud 관리 개요

n8n Cloud는 완전 관리형 워크플로우 자동화 플랫폼으로, 인프라 관리 없이 자동화 워크플로우를 구축하고 실행 가능

## 주요 기능

### 관리 기능
- Cloud 관리자 대시보드를 통한 중앙 집중식 관리
- 사용자 및 팀 관리
- 플랜 및 결제 관리
- 워크플로우 버전 관리

### 보안 및 접근 제어
- 역할 기반 접근 제어(RBAC)
- Single Sign-On(SSO) 지원
- 2단계 인증(2FA)
- Cloud IP 주소 관리

### 데이터 관리
- 자동 백업
- 워크플로우 내보내기/가져오기
- 실행 데이터 관리
- 데이터 보존 정책

### 성능 및 확장성
- 자동 스케일링
- 동시 실행 관리
- 성능 모니터링
- 실행 우선순위 설정

## 플랜 유형

### Free Trial
- 14일 무료 체험
- 모든 기능 사용 가능
- 신용카드 불필요

### Starter
- 개인 및 소규모 팀용
- 기본 워크플로우 실행
- 제한된 실행 시간

### Pro
- 중소기업용
- 확장된 실행 시간
- 우선 지원

### Enterprise
- 대규모 조직용
- 무제한 실행
- 전담 지원
- SLA 보장

## 시작하기

1. n8n Cloud 계정 생성
2. 워크스페이스 설정
3. 첫 번째 워크플로우 생성
4. 팀 멤버 초대
5. 워크플로우 활성화 및 모니터링
