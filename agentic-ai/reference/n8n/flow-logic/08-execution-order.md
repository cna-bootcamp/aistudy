# 다중 브랜치 워크플로우의 실행 순서 (Execution Order)

n8n의 node 실행 순서는 사용 중인 n8n 버전에 따라 다름:

- 버전 1.0 이전에 생성된 workflow의 경우: n8n은 각 브랜치의 첫 번째 node를 실행한 다음 각 브랜치의 두 번째
  node를 실행하는 방식으로 진행함
- 버전 1.0 이상에서 생성된 workflow의 경우: 각 브랜치를 차례로 실행하여 한 브랜치를 완료한 후 다른 브랜치를
  시작함. n8n은 캔버스에서의 위치를 기반으로 브랜치 순서를 지정함 (위에서 아래로). 두 브랜치가 동일한 높이에
  있는 경우 가장 왼쪽 브랜치가 먼저 실행됨
