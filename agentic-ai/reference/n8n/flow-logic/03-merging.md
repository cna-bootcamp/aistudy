# 데이터 병합 (Merging Data)

병합은 여러 데이터 스트림을 하나로 결합함. workflow 요구사항에 따라 다양한 node를 사용하여 구현 가능

- 다른 데이터 스트림 또는 node의 데이터 병합: Merge node를 사용하여 다양한 소스의 데이터를 하나로 결합
- 여러 node 실행의 데이터 병합: Code node를 사용하여 node 또는 여러 node의 다중 실행 데이터를 병합하는 복잡한
  시나리오 처리
- 데이터 비교 및 병합: Compare Datasets node를 사용하여 비교를 기반으로 데이터 스트림을 비교, 병합, 출력

각 방법에 대한 자세한 내용은 아래 섹션에서 확인 가능

## 다른 데이터 스트림의 데이터 병합

workflow가 분기되면 별도의 스트림을 다시 하나의 스트림으로 결합할 수 있음

다양한 병합 유형을 보여주는 예제 workflow: 데이터셋 추가, 새 항목만 유지, 기존 항목만 유지 등.
Merge node 문서에 각 병합 작업에 대한 세부 정보가 포함되어 있음

## 다른 node의 데이터 병합

Merge node를 사용하여 workflow가 별도의 데이터 스트림으로 분리되지 않은 경우에도 이전 두 node의 데이터를 결합
가능. 여러 node에서 생성된 데이터로부터 단일 데이터셋을 생성하려는 경우 유용함

## 여러 node 실행의 데이터 병합

Code node를 사용하여 여러 node 실행의 데이터를 병합함. 일부 루핑 (Looping) 시나리오에서 유용함

### Node 실행과 workflow 실행

이 섹션은 여러 node 실행의 데이터 병합을 설명함. 단일 workflow 실행 중에 node가 여러 번 실행되는 경우를 의미함

Loop Over Items 및 Wait를 사용하여 인위적으로 여러 실행을 생성하는 예제 workflow 참조

## 비교, 병합, 다시 분기

Compare Datasets node는 데이터 스트림을 병합하기 전에 비교함. 최대 4개의 다른 데이터 스트림을 출력할 수 있음
