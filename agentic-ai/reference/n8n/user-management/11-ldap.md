# LDAP 통합

## 개요

LDAP (Lightweight Directory Access Protocol)는 n8n에서 엔터프라이즈 디렉토리 서비스와 통합하기 위한 인증 방법.
기존 LDAP 디렉토리를 활용하여 사용자 인증 및 계정 관리 수행 가능.

## LDAP 구성 요소

n8n은 LDAP를 두 가지 방식으로 지원:

### 1. LDAP 노드
워크플로우 내에서 LDAP 서버와 상호작용:
- LDAP 쿼리 실행
- 사용자 및 그룹 정보 조회
- 디렉토리 항목 검색
- LDAP 데이터 기반 자동화 구현
- 위치: `n8n-nodes-base.ldap/`

### 2. LDAP 자격증명
LDAP 서버 연결을 위한 인증 정보 관리:
- LDAP 서버 주소 및 포트
- 바인드 DN (Distinguished Name)
- 바인드 비밀번호
- TLS/SSL 설정
- 자격증명 섹션에서 관리

## 사용자 인증을 위한 LDAP 설정

### LDAP 활성화
n8n에서 LDAP 인증 기능 활성화:

#### 초기 설정
- 관리자 권한으로 n8n 접속
- 사용자 관리 설정 메뉴 이동
- LDAP 인증 옵션 활성화
- 라이선스 또는 플랜 요구사항 확인

#### LDAP 서버 구성
n8n과 LDAP 서버 연결 설정:
- **서버 주소**: LDAP 서버 호스트명 또는 IP 주소
- **포트**: LDAP 포트 (기본값: 389, LDAPS: 636)
- **보안 연결**: TLS/SSL 활성화 옵션
- **Base DN**: 사용자 검색 시작 지점

#### 바인드 자격증명
LDAP 서버 인증 정보:
- **Bind DN**: LDAP 서버에 연결할 관리자 또는 서비스 계정 DN
- **Bind Password**: 바인드 계정의 비밀번호
- 읽기 전용 권한으로 충분 (최소 권한 원칙)

#### 사용자 검색 설정
LDAP 사용자 조회 구성:
- **User DN**: 사용자가 위치한 디렉토리 경로
- **User Filter**: 사용자 검색 필터 (예: `(objectClass=person)`)
- **Username Attribute**: 로그인 ID로 사용할 속성 (예: `uid`, `sAMAccountName`)
- **Email Attribute**: 이메일 주소 속성 (예: `mail`)

#### 그룹 매핑 (선택사항)
LDAP 그룹을 n8n 역할로 매핑:
- 그룹 Base DN 설정
- 그룹 멤버십 속성 정의
- n8n 역할 매핑 규칙 설정

### n8n 및 LDAP 계정 병합
기존 n8n 로컬 계정과 LDAP 계정 통합:

#### 병합 프로세스
LDAP 활성화 전 존재하던 n8n 계정 처리:
- 이메일 주소 기반 계정 매칭
- 로컬 계정과 LDAP 사용자 연결
- 기존 워크플로우 및 데이터 보존

#### 병합 옵션
- **자동 병합**: 이메일 일치 시 자동으로 계정 연결
- **수동 병합**: 관리자가 명시적으로 계정 매핑
- **새 계정 생성**: LDAP 사용자를 새 n8n 계정으로 생성

#### 주의사항
계정 병합 시 고려사항:
- 이메일 주소 정확성 확인
- 중복 계정 방지
- 병합 전 데이터 백업
- 사용자에게 변경 사항 공지

### n8n의 LDAP 사용자 계정
LDAP 인증을 통해 생성된 사용자 계정 관리:

#### 계정 생성
LDAP 사용자의 첫 로그인 시:
- LDAP 인증 성공
- n8n에 자동으로 사용자 계정 생성
- LDAP 속성을 n8n 프로필로 매핑
- 기본 역할 할당

#### 속성 동기화
LDAP와 n8n 간 사용자 정보 동기화:
- 로그인 시 속성 업데이트
- 이메일, 이름 등 프로필 정보 동기화
- 그룹 멤버십 기반 역할 업데이트

#### 사용자 라이프사이클
LDAP 통합 환경에서의 사용자 관리:
- **신규 사용자**: LDAP에 추가 시 n8n 자동 액세스 가능
- **비활성화**: LDAP에서 비활성화 시 n8n 액세스 차단
- **삭제**: LDAP에서 삭제 시 n8n 로그인 불가 (계정 데이터는 보존)

#### 역할 및 권한
LDAP 그룹 기반 역할 할당:
- LDAP 그룹 멤버십 확인
- 그룹별 n8n 역할 매핑
- 로그인 시 역할 자동 업데이트
- 다중 그룹 멤버십 처리

### LDAP 비활성화
LDAP 인증 기능 끄기:

#### 비활성화 절차
- 관리자 설정에서 LDAP 비활성화
- 기존 LDAP 사용자 처리 방법 선택
- 대체 인증 방법 활성화

#### 사용자 계정 처리 옵션
LDAP 비활성화 후 계정 관리:
- **로컬 계정으로 전환**: LDAP 사용자를 로컬 인증으로 변경
- **계정 유지**: 사용자 데이터 보존, 로그인 불가
- **비밀번호 재설정**: 사용자가 로컬 비밀번호 설정

#### 주의사항
- LDAP 비활성화 전 사용자에게 공지
- 비밀번호 재설정 프로세스 준비
- 데이터 백업 수행
- 대체 인증 방법 준비

## LDAP 서버 유형

### Microsoft Active Directory
가장 일반적인 LDAP 구현:
- **Username Attribute**: `sAMAccountName`
- **User Filter**: `(&(objectClass=user)(objectCategory=person))`
- **Default Port**: 389 (LDAP), 636 (LDAPS), 3268 (Global Catalog)
- **Group Attribute**: `memberOf`

### OpenLDAP
오픈소스 LDAP 서버:
- **Username Attribute**: `uid`
- **User Filter**: `(objectClass=inetOrgPerson)`
- **Default Port**: 389 (LDAP), 636 (LDAPS)
- **Group Attribute**: `member` 또는 `uniqueMember`

### Apache Directory Server
Java 기반 LDAP 서버:
- 표준 LDAP 속성 사용
- OpenLDAP과 유사한 구성

### 기타 LDAP 호환 서버
표준 LDAP 프로토콜 지원하는 모든 디렉토리 서비스

## 보안 설정

### TLS/SSL 암호화
안전한 LDAP 연결:
- **LDAPS (LDAP over SSL)**: 포트 636 사용
- **StartTLS**: 포트 389에서 TLS로 업그레이드
- 인증서 검증 옵션
- 자체 서명 인증서 처리

### 최소 권한 원칙
LDAP 바인드 계정의 권한 제한:
- 읽기 전용 권한만 부여
- 필요한 디렉토리 범위로 액세스 제한
- 민감한 속성 액세스 제한

### 비밀번호 보안
LDAP 자격증명 보호:
- n8n 자격증명 암호화 저장
- 비밀번호 정기 변경
- 강력한 비밀번호 정책 적용

## 문제 해결

### 연결 문제
LDAP 서버 연결 실패 시:
- 서버 주소 및 포트 확인
- 네트워크 연결 및 방화벽 규칙 검증
- LDAP 서버 상태 확인
- TLS/SSL 인증서 검증

### 인증 실패
사용자 로그인 실패 시:
- Bind DN 및 비밀번호 확인
- User DN 및 Filter 검증
- Username Attribute 정확성 확인
- LDAP 로그 검토

### 속성 매핑 오류
사용자 정보 불일치 시:
- 속성 이름 정확성 확인
- LDAP 스키마 검증
- 속성 값 형식 확인
- 기본값 설정 검토

### 그룹 매핑 문제
역할 할당 오류 시:
- 그룹 DN 및 필터 확인
- 멤버십 속성 검증
- 매핑 규칙 검토
- 그룹 계층 구조 확인

- 그룹 멤버십 확인

- 동적 액세스 제어

### 자격증명 관리
LDAP 자격증명 설정 및 사용:
- 재사용 가능한 자격증명 생성

- 안전한 자격증명 공유

### 통합 시나리오
LDAP와 다른 시스템 연동:

- 조직 변경 사항 동기화

## 관련 인증 방법

LDAP는 다른 엔터프라이즈 인증 방법과 함께 사용 가능:

### SAML
Single Sign-On을 위한 페더레이션 인증:
- LDAP와 SAML 동시 지원 가능
- IdP가 LDAP를 백엔드로 사용하는 경우 통합

### OIDC
OAuth 2.0 기반 현대적 인증:
- LDAP 디렉토리와 OIDC Provider 통합
- 토큰 기반 인증과 LDAP 사용자 정보 연동

### 다중 인증 방법
여러 인증 방법 병행 사용:
- LDAP 사용자와 로컬 사용자 공존
- 그룹별 인증 방법 차별화
- 백업 인증 방법 유지

## 제한 사항

### 라이선스 요구사항
LDAP 기능은 특정 n8n 플랜에서만 사용 가능할 수 있음

### 성능 고려사항
대규모 디렉토리 환경:
- LDAP 쿼리 최적화 필요
- 캐싱 전략 고려
- 네트워크 지연 고려

### 프로토콜 제한
LDAP 프로토콜의 제약:
- 실시간 동기화 제한
- 일부 고급 IdP 기능 미지원
- 복잡한 그룹 계층 구조 처리 제한
