# 사용자 관리

## 개요

n8n 인스턴스의 사용자 계정 관리 기능.
관리자는 사용자 추가, 제거 및 초대 관리 수행 가능.

## 주요 관리 작업

### 사용자 삭제
관리자는 n8n 인스턴스에서 사용자 계정 제거 가능:
- 계정 완전 삭제
- 사용자의 모든 권한 및 액세스 제거
- 관련 리소스 처리

### 대기 중인 사용자에게 초대 재전송
초기 초대를 수락하지 않은 사용자에게 초대 재전송 가능:
- 초대 상태 확인
- 새 초대 이메일 발송
- 만료된 초대 갱신

## 확장 사용자 관리 기능

포괄적인 사용자 관리는 기본 계정 관리를 넘어 다음을 포함:

### 계정 유형
다양한 사용자 역할 및 권한 수준:
- 구독 또는 사용자 등급 옵션
- 계정 수준별 기능 가용성
- 협업 기능 차이

### 역할 기반 액세스 제어 (RBAC)
세밀한 권한 관리:
- 역할 유형 정의
- 프로젝트 수준 액세스 제어
- 사용자 지정 역할 생성

### 인증 방법
엔터프라이즈 환경을 위한 통합:
- LDAP 디렉토리 서비스 연결
- OIDC (OpenID Connect) 구성
- SAML Single Sign-On 통합

### 보안 기능
계정 보안 강화:
- 이중 인증 (2FA) 설정
- 비밀번호 정책 관리
- 세션 관리

### 모범 사례
권장 사용자 관리 접근 방식:
- 최소 권한 원칙 적용
- 정기적인 액세스 검토
- 역할 및 권한 문서화

## 배포 유형별 지원

Cloud 기반 및 Self-hosted n8n 배포 모두 지원됨.
배포 유형 및 계정 등급에 따라 기능 차이 있음.
