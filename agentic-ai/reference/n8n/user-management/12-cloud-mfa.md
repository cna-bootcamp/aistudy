# n8n Cloud MFA (다중 인증)

## 개요

Multi-Factor Authentication (MFA)는 n8n Cloud 계정의 보안을 강화하기 위한 추가 인증 계층.
비밀번호 외에 추가 인증 요소를 요구하여 계정 보안 강화.

## MFA란?

### 개념
다중 인증은 두 개 이상의 인증 요소를 요구하는 보안 방법:
- **지식 요소**: 비밀번호, PIN
- **소유 요소**: 스마트폰, 하드웨어 토큰
- **생체 요소**: 지문, 얼굴 인식

### n8n Cloud MFA
n8n Cloud에서 지원하는 MFA 방법:
- Time-based One-Time Password (TOTP)
- 인증 앱 기반 OTP 생성
- 표준 TOTP 프로토콜 준수

## MFA 설정

### 요구사항
MFA 활성화를 위한 준비:
- n8n Cloud 계정
- 스마트폰 또는 태블릿
- 인증 앱 (Authenticator App)

### 지원 인증 앱
TOTP를 지원하는 인증 앱:
- **Google Authenticator**: Android, iOS
- **Microsoft Authenticator**: Android, iOS
- **Authy**: Android, iOS, 데스크톱
- **1Password**: 비밀번호 관리자 내장 TOTP
- **LastPass Authenticator**: Android, iOS
- 기타 TOTP 호환 앱

### MFA 활성화 절차

#### 1단계: 계정 설정 접속
- n8n Cloud에 로그인
- 우측 상단 사용자 메뉴 클릭
- "Account Settings" 또는 "프로필 설정" 선택

#### 2단계: MFA 섹션 찾기
- 보안 또는 인증 섹션 이동
- "Multi-Factor Authentication" 옵션 찾기
- "Enable MFA" 또는 "MFA 활성화" 버튼 클릭

#### 3단계: QR 코드 스캔
- 화면에 QR 코드 표시됨
- 인증 앱 열기
- "계정 추가" 또는 "+" 버튼 선택
- QR 코드 스캔 기능으로 코드 스캔

#### 4단계: 수동 입력 (선택사항)
QR 코드 스캔이 불가능한 경우:
- "수동 입력" 또는 "키 입력" 옵션 선택
- 화면에 표시된 시크릿 키 복사
- 인증 앱에 수동으로 입력
- 계정 이름: "n8n Cloud" 또는 사용자 정의

#### 5단계: 인증 코드 확인
- 인증 앱에서 생성된 6자리 코드 확인
- n8n 설정 페이지에 코드 입력
- "Verify" 또는 "확인" 버튼 클릭

#### 6단계: 복구 코드 저장
- MFA 활성화 후 복구 코드 제공됨
- 복구 코드를 안전한 곳에 저장
- 인증 앱 접근 불가 시 사용
- 복구 코드는 한 번만 표시되므로 즉시 저장 필요

## MFA 로그인

### 일반 로그인 절차
MFA 활성화 후 로그인 프로세스:

#### 1단계: 이메일 및 비밀번호 입력
- n8n Cloud 로그인 페이지 접속
- 이메일 주소 입력
- 비밀번호 입력
- "Sign In" 또는 "로그인" 클릭

#### 2단계: MFA 코드 입력
- 인증 앱 열기
- n8n Cloud 계정의 현재 6자리 코드 확인
- 코드를 로그인 페이지에 입력
- "Verify" 또는 "확인" 클릭

#### 3단계: 로그인 완료
- 인증 성공 시 n8n Cloud 대시보드 접속

### 신뢰할 수 있는 기기
일부 구현에서는 "이 기기를 신뢰" 옵션 제공:
- 체크박스 선택 시 일정 기간 MFA 생략
- 보안을 위해 개인 기기에서만 사용 권장
- 공용 기기에서는 사용 금지

## 복구 코드 사용

### 복구 코드란?
인증 앱에 접근할 수 없을 때 사용하는 백업 코드:
- MFA 설정 시 제공됨
- 일회용 코드
- 여러 개의 복구 코드 제공

### 복구 코드 사용 시나리오
- 스마트폰 분실 또는 도난
- 인증 앱 삭제 또는 데이터 손실
- 새 기기로 전환 전
- 인증 앱 오작동

### 복구 코드로 로그인
- 로그인 시 MFA 코드 입력 화면에서
- "Use recovery code" 또는 "복구 코드 사용" 링크 클릭
- 저장된 복구 코드 중 하나 입력
- 로그인 후 즉시 MFA 재설정 권장

### 복구 코드 재생성
- 계정 설정의 MFA 섹션 접속
- "Regenerate recovery codes" 옵션 선택
- 새로운 복구 코드 세트 생성됨
- 이전 복구 코드는 무효화됨
- 새 코드를 안전하게 저장

## MFA 관리

### MFA 재설정
새 기기로 MFA 이전:

#### 기존 기기 접근 가능한 경우
1. 계정 설정 접속
2. MFA 비활성화
3. 새 기기에서 MFA 재활성화
4. 새 QR 코드 스캔

#### 기존 기기 접근 불가능한 경우
1. 복구 코드로 로그인
2. 계정 설정에서 MFA 재설정
3. 새 기기에서 MFA 설정

### MFA 비활성화
보안상 권장하지 않지만 필요 시 비활성화 가능:
- 계정 설정의 MFA 섹션 접속
- "Disable MFA" 또는 "MFA 비활성화" 선택
- 현재 MFA 코드 입력으로 확인
- 비활성화 후 비밀번호만으로 로그인 가능

### 인증 앱 변경
다른 인증 앱으로 전환:
- 기존 MFA 비활성화
- 새 인증 앱 설치
- MFA 재활성화
- 새 앱으로 QR 코드 스캔

## 보안 모범 사례

### 복구 코드 관리
- **오프라인 저장**: 종이에 인쇄하여 안전한 장소에 보관
- **비밀번호 관리자**: 암호화된 비밀번호 관리자에 저장
- **여러 곳에 백업**: 집과 사무실 등 분산 보관
- **정기적 확인**: 복구 코드 유효성 주기적 확인

### 인증 앱 백업
인증 앱 데이터 백업 방법:
- **Authy**: 클라우드 백업 기능 제공
- **1Password, LastPass**: 자동 동기화
- **Google Authenticator**: 수동 백업 필요 (최신 버전은 백업 지원)
- 기기 변경 전 항상 백업 확인

### 기기 보안
인증 앱이 설치된 기기 보호:
- 화면 잠금 설정 (PIN, 패턴, 생체인식)
- 기기 분실 시 원격 잠금 및 삭제 기능 활성화
- 최신 보안 업데이트 유지
- 의심스러운 앱 설치 주의

### 피싱 공격 방지
- n8n 공식 웹사이트에서만 로그인
- 이메일 링크를 통한 로그인 주의
- MFA 코드를 제3자와 절대 공유 금지
- 의심스러운 로그인 시도 즉시 보고

## 문제 해결

### 인증 코드가 작동하지 않음
시간 동기화 문제 가능성:
- 인증 앱 설정에서 시간 동기화 확인
- 기기의 시계가 자동 설정되어 있는지 확인
- 수동으로 시간 동기화 실행
- 코드가 30초마다 갱신되므로 최신 코드 사용

### 복구 코드를 분실한 경우
- 다른 복구 코드가 남아있다면 사용
- 모든 복구 코드 분실 시 n8n 지원팀에 문의
- 계정 소유권 확인 절차 필요
- 보안을 위해 신원 확인 프로세스 진행

### 새 기기로 전환
계획적인 기기 변경:
1. 기존 기기에서 MFA 비활성화
2. 새 기기에 인증 앱 설치
3. MFA 재활성화 및 설정
4. 새 복구 코드 저장

예상치 못한 기기 손실:
1. 복구 코드로 로그인
2. MFA 재설정
3. 새 기기에서 설정
4. 새 복구 코드 저장

### 지원 문의
MFA 관련 문제 해결이 어려운 경우:
- n8n 지원팀 이메일 문의
- 커뮤니티 포럼에서 도움 요청
- 계정 소유권 증명 자료 준비
- 응답 시간 고려하여 미리 문의

## 추가 보안 권장사항

### 강력한 비밀번호
MFA와 함께 강력한 비밀번호 사용:
- 최소 12자 이상
- 대소문자, 숫자, 특수문자 조합
- 다른 서비스와 다른 고유 비밀번호
- 비밀번호 관리자 사용 권장

### 정기적인 보안 검토
- 계정 활동 로그 주기적 확인
- 의심스러운 로그인 시도 모니터링
- 사용하지 않는 세션 종료
- 복구 코드 유효성 주기적 확인

### 계정 알림
보안 알림 설정:
- 새 기기 로그인 알림
- 비밀번호 변경 알림
- MFA 설정 변경 알림
- 의심스러운 활동 경고

## 조직 관리자를 위한 권장사항

### MFA 정책
조직 전체 MFA 정책 수립:
- 모든 사용자에게 MFA 활성화 요구
- 정기적인 보안 교육 실시
- MFA 설정 가이드 제공
- 지원 프로세스 수립

### 사용자 지원
팀원의 MFA 설정 지원:
- 단계별 설정 가이드 제공
- 초기 설정 지원 세션
- 문제 해결 담당자 지정
- 복구 프로세스 문서화

### 모니터링 및 감사
보안 준수 모니터링:
- MFA 활성화율 추적
- 미활성화 사용자 파악 및 독려
- 로그인 패턴 분석
- 보안 인시던트 대응 계획

## 참고 사항

### 가용성
- MFA는 n8n Cloud 계정에서 사용 가능
- Self-hosted 인스턴스는 별도 MFA 구성 필요
- 계정 유형에 따라 MFA 옵션 상이할 수 있음

### 표준 준수
- TOTP (Time-based One-Time Password) 프로토콜 사용
- RFC 6238 표준 준수
- 대부분의 TOTP 호환 앱과 작동

### 향후 개선
n8n은 지속적으로 보안 기능을 개선하고 있으며, 향후 추가 MFA 방법 지원 가능성 있음.
