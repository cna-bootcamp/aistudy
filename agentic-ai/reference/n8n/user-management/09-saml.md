# SAML 인증

## 개요

SAML (Security Assertion Markup Language)은 n8n에서 엔터프라이즈 인증 방법으로 제공되는 사용자 액세스 및 ID 관리 기능.
조직의 기존 ID 관리 시스템과 n8n을 통합하여 중앙 집중식 사용자 액세스 제어 및 Single Sign-On (SSO) 기능 제공.

## 주요 SAML 기능

### 1. 설정 및 구성
n8n 인스턴스 내에서 SAML 인증 구현을 위한 전용 설정 가이드:
- SAML 활성화 절차
- Identity Provider (IdP) 연결 설정
- 메타데이터 교환 구성
- 인증서 및 키 관리

### 2. Identity Provider 특정 통합
다양한 IdP와의 통합 지원:
- **Okta Workforce Identity**: Okta와 페더레이션 인증 구성을 위한 전용 문서
- **기타 IdP**: 일반적인 SAML 2.0 호환 Identity Provider 지원
- Provider별 구성 차이점 및 최적화 가이드

### 3. 사용자 관리
SAML을 통한 사용자 관리 기능:
- 자동 사용자 프로비저닝 (Automatic User Provisioning)
- Identity Provider를 통한 계정 관리
- 사용자 속성 매핑
- 그룹 및 역할 동기화

### 4. 문제 해결 리소스
SAML 구현 시 발생할 수 있는 일반적인 문제 해결:
- 인증 실패 디버깅
- 메타데이터 불일치 해결
- 인증서 만료 문제
- 사용자 속성 매핑 오류

## 활용 사례

SAML 인증을 통해 엔터프라이즈는 다음을 달성 가능:

### 중앙 집중식 ID 관리
기존 ID 관리 시스템과 n8n 통합:
- 단일 사용자 디렉토리 유지
- 중앙에서 사용자 생성 및 삭제
- 일관된 인증 정책 적용

### Single Sign-On (SSO)
사용자 경험 개선 및 보안 강화:
- 하나의 자격증명으로 여러 시스템 액세스
- 비밀번호 관리 부담 감소
- 세션 관리 중앙화

### 보안 프로토콜 활용
확립된 보안 표준 사용:
- SAML 2.0 표준 준수
- 암호화된 인증 교환
- 신뢰할 수 있는 페더레이션

### 자동화된 사용자 라이프사이클
효율적인 사용자 관리:
- 신규 직원 자동 온보딩
- 퇴사자 자동 오프보딩
- 부서 이동 시 권한 자동 조정

## 관련 인증 방법

SAML은 "사용자 및 액세스 관리" 섹션 내에서 다른 엔터프라이즈 인증 방법과 함께 제공됨:

### LDAP
Lightweight Directory Access Protocol을 통한 디렉토리 서비스 연결:
- 기존 LDAP 디렉토리 활용
- 사용자 인증 및 속성 조회
- 그룹 멤버십 관리

### OIDC
OpenID Connect를 통한 현대적인 인증:
- OAuth 2.0 기반 인증
- 토큰 기반 액세스 제어
- 모바일 및 웹 애플리케이션 지원

## SAML 구현 단계

### 1단계: SAML 활성화
n8n 인스턴스에서 SAML 기능 활성화

### 2단계: Identity Provider 구성
IdP 측에서 n8n을 Service Provider로 등록:
- 메타데이터 교환
- 인증서 설정
- 엔드포인트 URL 구성

### 3단계: 속성 매핑 구성
SAML 속성을 n8n 사용자 필드로 매핑:
- 이메일 주소 매핑
- 사용자 이름 매핑
- 역할 및 그룹 매핑

### 4단계: 테스트 및 검증
SAML 인증 플로우 테스트:
- 테스트 사용자로 로그인
- 속성 매핑 확인
- 오류 처리 검증

### 5단계: 프로덕션 배포
전체 사용자에게 SAML 인증 활성화

## 보안 고려사항

### 인증서 관리
SAML 인증서의 안전한 관리:
- 정기적인 인증서 갱신
- 안전한 키 저장
- 인증서 만료 모니터링

### 메타데이터 보안
메타데이터 파일의 보안 관리:
- 메타데이터 무결성 검증
- 안전한 메타데이터 교환
- 정기적인 메타데이터 업데이트

### 세션 관리
SAML 세션의 적절한 관리:
- 세션 타임아웃 설정
- 재인증 정책
- 로그아웃 처리

## 모범 사례

### IdP 선택
조직에 적합한 Identity Provider 선택:
- 기존 엔터프라이즈 시스템과의 호환성
- SAML 2.0 표준 준수
- 신뢰할 수 있는 벤더 선택

### 속성 매핑 설계
효과적인 사용자 속성 매핑:
- 필수 속성 정의
- 일관된 명명 규칙
- 기본값 처리 방안

### 테스트 전략
철저한 SAML 구현 테스트:
- 단계별 테스트 수행
- 다양한 시나리오 검증
- 오류 처리 확인

### 모니터링 및 로깅
SAML 인증 활동 모니터링:
- 인증 성공/실패 로깅
- 비정상 패턴 감지
- 정기적인 로그 검토

## 제한 사항 및 요구사항

### 라이선스 요구사항
SAML 기능은 특정 n8n 라이선스 또는 플랜에서만 사용 가능할 수 있음

### 기술 요구사항
SAML 구현을 위한 기술적 전제조건:
- SAML 2.0 호환 Identity Provider
- HTTPS 통신 지원
- 유효한 SSL/TLS 인증서

### 네트워크 요구사항
n8n과 IdP 간 네트워크 연결:
- IdP 엔드포인트 접근 가능
- 방화벽 규칙 구성
- DNS 설정 확인
