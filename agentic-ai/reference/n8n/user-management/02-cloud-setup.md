# Cloud 설정

## 개요

n8n Cloud 인스턴스의 사용자 관리 설정을 위한 가이드.

## 설정 단계

### 1단계: 앱 내 설정
n8n 애플리케이션 내에서 초기 구성 수행

### 2단계: 사용자 초대
Cloud 인스턴스에 사용자 추가 프로세스

## 관련 기능

Cloud 설정은 다음과 같은 사용자 관리 기능과 통합됨:

- **사용자 관리 기능**: 계정 추가, 제거 및 관리
- **계정 유형**: 다양한 사용자 역할 및 권한 수준
- **역할 기반 액세스 제어 (RBAC)**: 역할 유형, 프로젝트 및 사용자 지정 역할 포함
- **프로젝트 구성**: 워크플로우 및 리소스 조직화 기능
- **보안 기능**: 이중 인증(2FA) 포함
- **엔터프라이즈 인증 방법**: LDAP, OIDC, SAML 통합

## 제한 사항

Cloud 및 Self-hosted 배포에 따라 사용 가능한 기능이 다를 수 있음.
계정 등급에 따라 일부 기능이 제한될 수 있음.

## 참고 사항

설정 완료 후 사용자를 초대하고 적절한 역할과 권한을 할당하여 협업 환경 구축 가능.
