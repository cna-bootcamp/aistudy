# 계정 유형

## 개요

n8n은 다양한 요구사항을 충족하기 위해 여러 계정 유형 제공.
각 계정 유형은 서로 다른 기능, 권한 및 협업 기능 포함.

## 계정 유형 구성 요소

### 구독 및 사용자 등급 옵션
조직의 규모와 요구사항에 따른 다양한 등급:
- 개인 사용자를 위한 기본 등급
- 팀 협업을 위한 중급 등급
- 엔터프라이즈 기능을 위한 고급 등급

### 계정 수준별 기능 가용성
등급에 따라 제공되는 기능:
- 워크플로우 실행 제한
- 활성 워크플로우 수
- 스토리지 용량
- API 호출 제한
- 고급 기능 액세스

### 사용자 권한 구조
계정 유형별 권한 차이:
- 워크플로우 생성 및 편집 권한
- 자격증명 관리 권한
- 사용자 관리 권한
- 시스템 설정 액세스

### 협업 기능
팀 작업을 위한 기능:
- 다중 사용자 액세스
- 역할 기반 권한 관리
- 프로젝트 공유 및 협업
- 워크플로우 공동 편집

## 관련 기능

계정 유형은 다음 기능과 통합됨:
- **역할 기반 액세스 제어 (RBAC)**: 세밀한 권한 관리
- **프로젝트 관리**: 워크플로우 및 리소스 조직화
- **사용자 관리**: 팀 구성원 추가 및 관리
- **인증 방법**: LDAP, OIDC, SAML 엔터프라이즈 통합

## 계정 선택 가이드

적절한 계정 유형 선택 시 고려사항:
- 팀 규모 및 협업 요구사항
- 필요한 워크플로우 복잡도
- 보안 및 규정 준수 요구사항
- 예산 및 비용 효율성
- 확장 계획

## 참고 사항

계정 유형은 Cloud 및 Self-hosted 배포에 따라 다를 수 있음.
상세한 기능 비교는 n8n 공식 웹사이트 또는 영업팀 문의를 통해 확인 가능.
