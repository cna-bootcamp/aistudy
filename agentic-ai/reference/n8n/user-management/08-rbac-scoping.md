# RBAC 범위 지정 (Scoping)

## 개요

RBAC 범위 지정은 n8n에서 권한 및 액세스 제어의 적용 범위를 정의하는 메커니즘.
사용자 역할과 권한이 어떻게 특정 리소스 및 컨텍스트에 적용되는지 결정함.

## 범위 지정 개념

### 인스턴스 수준 범위
n8n 인스턴스 전체에 적용되는 권한:
- 글로벌 관리자 권한
- 시스템 설정 액세스
- 전체 사용자 관리
- 인스턴스 전반의 정책 적용

### 프로젝트 수준 범위
특정 프로젝트 내로 제한된 권한:
- 프로젝트별 관리자 역할
- 프로젝트 내 워크플로우 액세스
- 프로젝트 자격증명 사용 권한
- 프로젝트 팀원 관리

### 리소스 수준 범위
개별 워크플로우 또는 자격증명에 대한 세밀한 제어:
- 특정 워크플로우 편집 권한
- 자격증명별 액세스 제어
- 실행 권한 관리
- 공유 설정 제어

## 범위 지정 적용

### 역할과 범위의 조합
역할과 범위를 조합하여 정확한 액세스 제어 구현:
- **인스턴스 Admin**: 전체 인스턴스 관리 권한
- **프로젝트 Admin**: 특정 프로젝트 관리 권한
- **프로젝트 Editor**: 프로젝트 내 편집 권한
- **프로젝트 Viewer**: 프로젝트 내 읽기 전용 권한

### 권한 상속
상위 범위의 권한이 하위 범위로 상속:
- 인스턴스 관리자는 모든 프로젝트 액세스 가능
- 프로젝트 관리자는 해당 프로젝트 내 모든 리소스 관리 가능
- 명시적 제한이 없는 한 권한 전파

### 권한 제한
특정 범위에서 권한 제한 가능:
- 프로젝트별 액세스 경계 설정
- 리소스별 공유 제어
- 명시적 거부 규칙 적용

## 범위 지정 구성

### 프로젝트 범위 설정
프로젝트 생성 시 범위 정의:
- 프로젝트 가시성 설정
- 기본 멤버 역할 지정
- 리소스 공유 정책 설정

### 사용자 범위 할당
사용자에게 특정 범위의 역할 할당:
- 프로젝트별 역할 지정
- 다중 프로젝트 액세스 관리
- 범위별 권한 차등 적용

### 리소스 범위 제어
워크플로우 및 자격증명의 공유 범위 설정:
- 프로젝트 내 공유
- 특정 사용자와 공유
- 전체 인스턴스 공유

## 범위 지정 모범 사례

### 명확한 경계 설정
프로젝트 및 리소스의 명확한 범위 경계 정의:
- 프로젝트 목적 및 범위 문서화
- 팀별 프로젝트 분리
- 환경별 프로젝트 구분

### 최소 권한 범위
필요한 최소 범위로 권한 제한:
- 업무 수행에 필요한 프로젝트만 액세스 부여
- 리소스별 명시적 공유
- 불필요한 전역 권한 회피

### 계층적 관리
조직 구조를 반영한 범위 계층 설계:
- 부서별 프로젝트 그룹
- 팀별 하위 프로젝트
- 역할 기반 계층 구조

### 정기적인 범위 검토
액세스 범위의 주기적 검토 및 조정:
- 분기별 프로젝트 멤버십 검토
- 미사용 액세스 권한 회수
- 범위 변경 이력 관리

## 활용 사례

### 부서별 격리
각 부서를 별도 프로젝트로 구성하여 데이터 격리:
- 영업팀 프로젝트
- 마케팅팀 프로젝트
- IT팀 프로젝트
- 부서 간 액세스 제한

### 클라이언트 프로젝트 분리
클라이언트별 독립적인 범위 설정:
- 클라이언트 A 프로젝트
- 클라이언트 B 프로젝트
- 클라이언트 데이터 격리
- 담당 팀만 액세스 가능

### 환경별 범위 지정
개발, 스테이징, 프로덕션 환경 분리:
- 개발 환경: 모든 개발자 액세스
- 스테이징 환경: QA 팀 및 승인자 액세스
- 프로덕션 환경: 제한된 관리자만 액세스

### 계약자 및 외부 사용자
외부 협력자에 대한 제한적 범위 설정:
- 특정 프로젝트만 액세스
- 읽기 전용 권한
- 기간 제한 액세스

## 통합 기능

범위 지정은 다음 기능과 통합됨:
- **프로젝트**: 범위의 기본 컨테이너
- **역할 유형**: 범위 내 적용되는 권한 정의
- **사용자 지정 역할**: 범위별 커스텀 권한 설정
- **자격증명 공유**: 범위 기반 자격증명 액세스 제어

## 참고 사항

범위 지정 기능은 n8n 버전 및 라이선스에 따라 다를 수 있음.
고급 범위 지정 옵션은 엔터프라이즈 플랜에서 사용 가능할 수 있음.
