# User Management 개요

## 소개

n8n의 User Management는 n8n 배포 환경에서 사용자 및 시스템 액세스를 관리하기 위한 포괄적인 기능을 제공함.
Cloud 및 Self-hosted 시나리오 모두 지원.

## 핵심 관리 영역

### Cloud 설정
n8n Cloud 환경을 위한 구성 기능

### 사용자 관리
사용자 계정 관리 및 운영:
- 사용자 추가 및 제거
- 계정 상태 관리
- 초대 재전송

### 계정 유형
다양한 사용자 계정 카테고리 및 등급:
- 구독 또는 사용자 등급 옵션
- 계정 수준별 기능 가용성
- 사용자 권한 구조
- 협업 기능

### 역할 기반 액세스 제어 (RBAC)
권한 관리 시스템:
- 역할 유형 및 정의
- 프로젝트 관리
- 사용자 지정 역할 생성

### 모범 사례
사용자 관리를 위한 권장 접근 방식

### 이중 인증 (2FA)
계정 보안 구현

### LDAP 통합
디렉토리 서비스 연결:
- LDAP 활성화
- n8n 및 LDAP 계정 병합
- LDAP 사용자 계정 관리
- LDAP 비활성화

### OIDC 설정
OpenID Connect 구성 및 문제 해결 가이드

### SAML 구현
Security Assertion Markup Language 인증:
- 설정 절차
- Okta Workforce Identity 구성
- SAML을 통한 사용자 관리
- 문제 해결 리소스

## 주요 기능

n8n의 User Management는 소규모 팀부터 정교한 권한 관리가 필요한 대규모 엔터프라이즈 환경까지 적합한 세밀하고
유연한 액세스 제어 제공함.
