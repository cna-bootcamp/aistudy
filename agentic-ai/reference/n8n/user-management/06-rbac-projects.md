# RBAC 프로젝트

## 개요

프로젝트는 n8n의 역할 기반 액세스 제어 내에서 워크플로우와 리소스를 조직화하고 액세스를 관리하기 위한 핵심 기능.
프로젝트를 통해 작업을 구획화하고 역할 기반 권한으로 제어 가능.

## 주요 기능

### 프로젝트 생성
새로운 프로젝트 설정:
- 프로젝트 이름 및 설명 정의
- 초기 설정 및 구성
- 프로젝트 범위 설정

### 사용자 관리
프로젝트에 팀 구성원 추가 및 제거:
- 프로젝트별 사용자 할당
- 사용자별 역할 지정
- 팀 구성 변경 관리

### 프로젝트 삭제
더 이상 필요하지 않은 프로젝트 제거:
- 프로젝트 리소스 정리
- 데이터 아카이브 또는 이전
- 안전한 프로젝트 종료

### 리소스 마이그레이션
워크플로우 및 자격증명을 다른 프로젝트 또는 사용자 간 이동:
- 워크플로우 이동 및 복사
- 자격증명 재할당
- 프로젝트 간 리소스 재구성
- 사용자 간 소유권 이전

### 외부 시크릿 통합
프로젝트 컨텍스트 내에서 외부 시크릿 관리 시스템 사용:
- 외부 시크릿 저장소 연결
- 프로젝트별 시크릿 액세스 제어
- 보안 자격증명 관리 강화

## 프로젝트 기능

프로젝트는 다음과 같은 조직 컨테이너 역할 수행:

### 워크플로우 분리
- 프로젝트별 워크플로우 그룹화
- 독립적인 워크플로우 관리
- 명확한 소유권 및 책임 구분

### 자격증명 격리
- 프로젝트별 자격증명 저장
- 자격증명 공유 범위 제어
- 보안 경계 설정

### 액세스 제어
- 역할 기반 권한을 통한 액세스 관리
- 프로젝트별 가시성 제어
- 사용자별 수정 권한 설정

### 리소스 전송
- 유연한 리소스 이동
- 프로젝트 공간 간 전송
- 팀 재구성 지원

## 사용자 지정 역할과의 통합

프로젝트는 사용자 지정 역할 및 기타 액세스 제어 기능과 함께 작동:
- 프로젝트별 역할 할당
- 세밀한 권한 관리
- n8n 인스턴스 전체에 걸친 일관된 액세스 제어

## 활용 사례

- **부서별 격리**: 각 부서의 워크플로우를 별도 프로젝트로 관리
- **클라이언트 프로젝트**: 클라이언트별 독립적인 프로젝트 공간 제공
- **환경 분리**: 개발, 스테이징, 프로덕션 환경을 별도 프로젝트로 구성
- **팀 협업**: 팀별 프로젝트 생성 및 공동 작업 수행

## 이점

- **명확한 구조**: 조직화된 워크플로우 및 리소스 관리
- **보안 강화**: 프로젝트 경계를 통한 액세스 제한
- **유연한 협업**: 프로젝트별 팀 구성 및 권한 설정
- **확장 가능성**: 조직 성장에 따른 프로젝트 추가 및 관리
