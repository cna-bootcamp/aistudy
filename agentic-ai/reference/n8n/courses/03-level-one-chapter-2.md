# n8n Level One - Chapter 2: 미니 워크플로우 구축

## 페이지 구조

이 문서 페이지는 n8n 학습 경로, 특히 Level One 텍스트 코스의 일부임. 페이지 제목은 "미니 워크플로우 구축"이며 기초 코스 자료의
두 번째 챕터 역할을 수행함

## 주요 콘텐츠 섹션

페이지에 표시된 목차에 따라 이 챕터는 다음을 다룸:

1. **Manual Trigger 노드 추가** - 워크플로우를 수동으로 트리거하는 방법 소개
2. **Hacker News 노드 추가** - Hacker News 통합 연결
3. **Hacker News 노드 구성** - 노드 매개변수 및 설정 구성
4. **노드 실행** - 노드 실행 및 실행 결과 검토
5. **워크플로우 저장** - 완성된 워크플로우 저장
6. **요약** - 챕터 요약

## 컨텍스트

이 챕터는 다음 탐색 계층 구조에 나타남:
- Using n8n → Getting started → Text courses → Level one

페이지에는 검색 기능, 탐색 이동 경로, 관련 리소스 링크(n8n home, Forum, Tutorials blog)와 같은 표준 문서 기능이 포함됨

## 참고

제공된 발췌문에는 완전한 수업 콘텐츠보다는 주로 탐색 요소, 메타데이터 및 페이지 구조 정보가 포함되어 있어 전체 교육 텍스트 콘텐츠가
완전히 표시되지 않았음
