# n8n Level One - Chapter 1: 에디터 UI 탐색

## 페이지 제목
"에디터 UI 탐색" - n8n Docs

## 개요
n8n Level One 텍스트 코스의 첫 번째 챕터로, n8n 워크플로우 에디터의 기본 인터페이스 및 탐색 요소를 소개함

## 주요 콘텐츠 섹션

### 시작하기
에디터의 기본 레이아웃과 구성에 대한 소개로 챕터가 시작됨

### 에디터 UI 설정
이 섹션은 세 가지 주요 인터페이스 영역을 다룸:

**왼쪽 패널** - 워크플로우 구축을 위한 노드 검색 및 선택 도구 포함

**상단 바** - 저장, 게시, 실행 옵션을 포함하여 워크플로우 관리를 위한 필수 컨트롤 제공

**캔버스** - 사용자가 구성요소를 배치하고 연결하여 자동화 시퀀스를 시각적으로 구성하는 중앙 작업 공간

### 노드
노드 작업에 대한 전용 지침:

**노드 찾기** - 방대한 n8n 라이브러리 내에서 특정 노드 유형을 찾는 방법

**노드 추가** - 워크플로우 로직을 구축하기 위해 캔버스에 노드를 삽입하는 프로세스

**노드 버튼** - 개별 노드에서 사용 가능한 대화형 컨트롤 및 옵션

## 학습 구조
코스는 순차적으로 진행되며, 이 챕터는 다음 단계로 진행하기 전 기초 역할을 수행함:
- 미니 워크플로우 구축
- 실제 사용 사례 자동화
- 워크플로우 설계 원칙
- 실용적인 구현 챕터

## 목적
이 입문 챕터는 학습자가 더 복잡한 워크플로우 구성을 다루기 전에 n8n 에디터를 효과적으로 탐색하는 데 필요한 필수 UI 이해력을
제공함
