# n8n Level One Chapter 3: 실제 사용 사례 자동화

## 페이지 구조
n8n Level One 텍스트 코스의 Chapter 3에 대한 목차 페이지로, "실제 사용 사례 자동화"라는 제목을 가짐

## 사용 가능한 콘텐츠 섹션
**시나리오 이해** - 이 챕터의 목차에 유일한 하위 섹션으로 나열됨

## 탐색 컨텍스트
- **이전 챕터**: Chapter 2 - 미니 워크플로우 구축
- **다음 챕터**: Chapter 4 - 워크플로우 설계
- **코스 구조**: Text courses 섹션 내 Level One의 일부
- **코스 경로**: Using n8n > Getting started > Text courses > Level one

## 관련 챕터 정보
이 페이지는 이 챕터가 여러 하위 섹션을 포함하는 "워크플로우 구축" 다음에 온다는 것을 나타냄:
- 데이터 웨어하우스에서 데이터 가져오기
- Airtable에 데이터 삽입
- 주문 필터링
- 주문 처리를 위한 값 설정
- 예약된 주문 계산
- 팀에 알림 전송
- 워크플로우 스케줄링
- 워크플로우 활성화 및 검토

## 참고
제공된 발췌문에는 이 챕터 페이지의 본문 콘텐츠가 나타나지 않음—탐색 메뉴와 목차만 표시됨. 실제 학습 자료는 "시나리오 이해"를
클릭하여 액세스할 수 있음
