# n8n Level One Chapter 5.1: 데이터 웨어하우스에서 데이터 가져오기

## 페이지 개요
n8n Level One 코스의 교육 모듈로, 특히 Chapter 5.1은 자동화된 워크플로우 구축의 일부로 데이터 웨어하우스에서 데이터를 추출하는
것에 중점을 둠

## 다루는 주요 주제

### 학습 목표
이 챕터는 사용자에게 다음을 가르침:
- 처음부터 새 워크플로우 생성
- HTTP Request 노드 추가 및 구성
- 데이터 웨어하우스 소스에서 데이터 조회

### 주요 섹션

**새 워크플로우 생성**
n8n 에디터에서 새로운 워크플로우 프로젝트를 초기화하는 지침

**HTTP Request 노드 추가**
데이터 웨어하우스를 포함한 외부 데이터 소스에 대한 연결을 가능하게 하는 HTTP Request 노드를 선택하고 구현하는 방법에 대한 안내

**데이터 가져오기**
API 엔드포인트 또는 데이터베이스 연결을 통해 데이터를 가져오는 실용적인 단계로, 구성 및 테스트를 다룸

**다음 단계**
데이터 삽입, 필터링 및 처리 작업을 다루는 후속 챕터로 학습자를 안내하는 전환 정보

## 구조
콘텐츠는 점진적인 학습 패턴을 따르며, 데이터 웨어하우스 시스템과 상호 작용하는 자동화된 비즈니스 프로세스를 생성하기 위한 기초
기술을 구축함. 각 섹션에는 n8n 플랫폼 내에서 실습을 위해 설계된 실행 가능한 지침이 포함됨
