# n8n Level One Chapter 5.3: 주문 필터링

## 페이지 개요
n8n 문서의 Level One 코스, 특히 Chapter 5.3의 교육 모듈로, 워크플로우 자동화에서 주문 필터링을 다룸

## 주요 학습 목표
이 챕터는 후속 워크플로우 노드를 통해 처리하기 전에 주문을 필터링하는 조건부 로직을 구현하는 방법을 사용자에게 가르침

## 주요 섹션

### 섹션 1: Airtable 노드 앞에 If 노드 추가
이 섹션은 데이터가 Airtable 통합에 도달하기 전에 특정 기준에 따라 주문을 평가하는 조건부 노드를 삽입하도록 사용자를 안내함

### 섹션 2: If 노드 구성
필터링 요구 사항을 충족하는 주문을 결정하기 위한 조건부 로직 매개변수 설정에 중점을 둔 지침

### 섹션 3: Airtable에 데이터 삽입
이 세그먼트는 필터링된 결과가 데이터 저장을 위해 Airtable 노드로 진행되는 방법을 시연함

### 섹션 4: 다음 단계
후속 워크플로우 모듈을 위해 학습자를 준비시키는 전환 섹션

## 핵심 워크플로우 개념
이 모듈은 n8n 워크플로우 내에서 필터링 메커니즘이 작동하는 방식을 구축하며, 정의된 조건에 따라 다른 항목을 제외하면서 관련
데이터 항목만 자동화가 처리하도록 허용함

## 관련 학습 경로
이 챕터는 Level One 교육의 "워크플로우 구축" 섹션 내에 위치하며, 데이터 웨어하우스 조회에 대한 챕터를 따르고 주문 처리 및 팀
알림에 대한 모듈 앞에 배치됨
