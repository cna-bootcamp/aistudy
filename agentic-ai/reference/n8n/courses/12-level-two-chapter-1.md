# n8n Level Two Chapter 1: 데이터 구조 이해

## 페이지 개요
n8n Level Two 텍스트 코스의 첫 번째 챕터로, 워크플로우에서 데이터 작업을 위한 기초 개념에 중점을 둠

## 다루는 주요 주제

### 1. n8n의 데이터 구조
챕터는 n8n이 워크플로우 내에서 정보를 구성하고 처리하는 방법을 소개하며, 데이터 처리를 위한 기본 프레임워크를 구축함

### 2. Code 노드로 데이터 세트 생성
사용자는 n8n의 Code 노드를 사용하여 사용자 정의 데이터 세트를 생성하는 방법을 배우며, 워크플로우 내에서 프로그래밍 방식으로
데이터를 생성할 수 있음

**연습 포함:** 데이터 세트 생성 기술의 실용적인 적용

### 3. Code 노드로 노드 데이터 참조
이 섹션은 코드를 작성할 때 이전 노드의 출력에 액세스하고 활용하는 방법을 가르침

**연습 포함:** 데이터 참조에 대한 실습

### 4. 데이터 변환
챕터는 워크플로우 요구 사항을 충족하기 위해 데이터를 수정하고 재구성하는 기술을 다룸

**연습 포함:** 적용된 변환 연습

## 코스 구조 컨텍스트
이 챕터는 기초 Level One 코스를 따르는 n8n 텍스트 기반 커리큘럼의 Level Two의 일부임. 전체 Level Two 코스에는 데이터 유형
처리, 데이터 병합/분할, 오류 처리 및 비즈니스 워크플로우 자동화에 대한 추가 챕터가 포함됨

## 대상 독자
Level One을 완료하고 n8n 워크플로우에서 데이터 조작에 대한 더 깊은 이해를 원하는 중급 사용자
