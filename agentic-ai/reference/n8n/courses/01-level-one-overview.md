# n8n Level One 코스 개요

## 코스 제목
**Level One: Text Courses**

## 코스 구조

Level One 코스는 다음 챕터들로 구성됨:

1. **에디터 UI 탐색** - n8n 인터페이스 소개
2. **미니 워크플로우 구축** - 간단한 워크플로우 실습 생성
3. **실제 사용 사례 자동화** - 실용적인 적용 시나리오
4. **워크플로우 설계** - 계획 및 아키텍처 개념
5. **워크플로우 구축** - 하위 섹션이 포함된 포괄적인 구현 섹션:
   - 데이터 웨어하우스에서 데이터 조회
   - Airtable에 데이터 삽입
   - 주문 필터링
   - 주문 처리를 위한 값 설정
   - 예약된 주문 계산
   - 팀에 알림 전송
   - 워크플로우 스케줄링
   - 워크플로우 활성화 및 검토
6. **워크플로우 내보내기 및 가져오기** - 데이터 이식성
7. **지식 테스트** - 평가 및 복습

## 주요 학습 구성요소

이 코스는 기초 개념부터 실용적인 구현까지 진행되며, 데이터 웨어하우스, Airtable 통합, 주문 처리, 팀 알림, 워크플로우 스케줄링을
포함하는 실제 비즈니스 워크플로우 시나리오로 완성됨

## 대상 독자
n8n 워크플로우 자동화에 대한 구조화된 실습 교육을 원하는 초보자
