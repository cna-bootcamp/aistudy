# n8n Level Two Chapter 2: 다양한 데이터 유형 처리

## 페이지 개요
이 챕터는 HTML, XML, 날짜, 시간 및 바이너리 데이터를 포함하여 n8n 워크플로우에서 다양한 데이터 형식을 처리하는 방법을 학습자에게
가르침

## 주요 섹션

### 1. HTML 및 XML 데이터
챕터는 구조화된 마크업 언어를 추출하고 조작하는 기술을 다룸. 학습자는 실용적인 연습을 통해 HTML 파싱 및 XML 변환 작업을 수행함

**HTML 연습**: 학생들은 n8n의 내장 노드를 사용하여 HTML 콘텐츠에서 데이터를 추출하는 연습을 함

**XML 연습**: 학습자는 XML 형식 정보를 파싱하고 처리하는 경험을 얻음

### 2. 날짜, 시간 및 간격 데이터
이 섹션은 시간 데이터 처리를 다루며, 워크플로우 내에서 날짜 및 시간 값을 형식화, 파싱 및 조작하는 방법을 가르침

**날짜 연습**: 학습자가 날짜 변환 및 계산 작업을 수행하는 실용적인 활동

### 3. 바이너리 데이터
챕터는 이미지, PDF 및 기타 인코딩된 콘텐츠를 포함하는 워크플로우에 필수적인 비텍스트 파일 형식 처리를 설명함

**바이너리 연습 1 및 2**: 바이너리 파일 작업 관리 기술을 구축하는 점진적인 연습

## 학습 경로 컨텍스트
이 챕터는 n8n 텍스트 기반 교육 커리큘럼의 Level Two의 일부로, "데이터 구조 이해" 다음과 "데이터 병합 및 분할" 앞에 위치함

## 관련 주제
- 데이터 변환 기술
- 다양한 데이터 유형에 대한 노드 작업
- 데이터 처리 워크플로우의 오류 처리
