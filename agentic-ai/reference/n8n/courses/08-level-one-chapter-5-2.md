# n8n Level One: Chapter 5.2 - Airtable에 데이터 삽입

## 페이지 개요
n8n Level One 코스의 교육 모듈로, 워크플로우에 Airtable을 통합하여 데이터를 삽입하는 방법을 사용자에게 가르침

## 주요 학습 목표
이 챕터는 사용자를 다음을 통해 안내함:
- 데이터 삽입을 위한 Airtable 테이블 설정
- 이전 워크플로우 단계에 Airtable 노드 연결
- 기능을 검증하기 위한 Airtable 통합 테스트

## 식별된 주요 섹션

### 1. 테이블 구성
사용자가 n8n 워크플로우로부터 데이터를 수신하도록 Airtable 워크스페이스를 준비함

### 2. HTTP Request 노드에 Airtable 노드 추가
이 섹션은 Airtable 노드 연결을 설명하며, HTTP 요청에서 Airtable 레코드로의 데이터 파이프라인을 구축함

### 3. Airtable 노드 테스트
사용자는 워크플로우를 실행하고 결과를 검증하여 데이터가 Airtable로 성공적으로 흐르는지 확인함

### 4. 다음 단계
이 마무리 섹션은 학습자를 교육 경로의 후속 레슨으로 안내함

## 관련 코스 구조
이 챕터는 Level One의 "워크플로우 구축" 단원 내에 위치하며, 데이터 웨어하우스 조회 레슨 다음과 주문 필터링 모듈 이전에 배치됨

## 탐색 컨텍스트
이 페이지는 n8n의 포괄적인 문서 시스템 내에 존재하며, 메인 탐색 메뉴를 통해 액세스 가능하고 텍스트 기반 코스 아래에 구성됨
