# 워크플로우별 실행 (Workflow-level Executions)

## 개요

n8n 문서 사이트의 "워크플로우별 실행" 페이지에 대한 문서임. 네비게이션 구조의 목차에 따르면, 문서는 다음을
다루어야 함:

1. **단일 워크플로우의 실행 보기**
2. **실행 필터링**
3. **실패한 워크플로우 재시도**

## 주요 기능

### 1. 단일 워크플로우의 실행 보기
특정 워크플로우의 실행 기록을 확인하는 방법
- 워크플로우의 모든 과거 실행 목록 보기
- 각 실행의 상태 및 결과 확인
- 실행 시간 및 기간 정보

### 2. 실행 필터링
실행 목록을 검색하고 필터링하는 기능
- 날짜 범위로 필터링
- 실행 상태로 필터링 (성공, 실패, 진행 중)
- 특정 조건에 맞는 실행 찾기

### 3. 실패한 워크플로우 재시도
실패한 실행을 다시 시도하는 방법
- 실패 지점부터 워크플로우 재실행
- 전체 워크플로우 재실행
- 오류 수정 후 재시도

## 워크플로우 수준 관리

이 문서는 개별 워크플로우의 실행 관리에 초점을 맞춤. 프로젝트 전체의 모든 실행을 보는 것과는 달리, 이 기능은
특정 워크플로우의 실행 히스토리와 관리에 집중함

## 실용적 활용

**모니터링**
워크플로우의 실행 패턴과 성공률을 추적하여 성능 모니터링

**디버깅**
실패한 실행을 분석하고 재시도하여 문제 해결

**운영 관리**
특정 워크플로우의 실행 히스토리를 통해 운영 상태 파악

## 참고사항

실제 설명 텍스트는 제공된 소스 자료에 포함되지 않았음. HTML 추출물은 주로 사이트의 네비게이션 프레임워크, 스타일링
코드, 메뉴 구조를 포함하고 있으며 문서 본문은 누락되었음. 워크플로우별 실행 문서의 완전하고 정확한 요약을 제공하려면
네비게이션 요소 이후에 나타나는 실제 문서 본문이 필요함
