# 공유 (Sharing)

## 개요

n8n의 워크플로우 공유 기능을 다루는 문서 페이지임. 제공된 자료에서 전체 문서 콘텐츠는 잘려 있지만, 목차는 주요
주제를 보여줌

## 주요 섹션

### 1. 워크플로우 공유 (Share a Workflow)
다른 사용자와 워크플로우를 공유하는 방법에 대한 세부 정보
- 팀원에게 워크플로우 액세스 권한 부여
- 공유 설정 구성
- 권한 수준 선택

### 2. 공유된 워크플로우 보기 (View Shared Workflows)
다른 사람이 공유한 워크플로우에 접근하는 방법에 대한 지침
- 공유받은 워크플로우 목록 확인
- 공유 워크플로우 열기 및 실행
- 권한에 따른 작업 수행

### 3. 워크플로우 역할 및 권한 (Workflow Roles and Permissions)
다양한 액세스 수준과 각 역할이 수행할 수 있는 작업에 대한 정보
- 역할 기반 액세스 제어 (RBAC)
- 각 역할의 구체적인 권한
- 권한 수준별 가능한 작업

### 4. 공유되지 않은 자격 증명으로 노드 편집 제한 (Node Editing Restrictions with Unshared Credentials)
자격 증명이 워크플로우와 함께 공유되지 않았을 때의 제한 사항 설명
- 보안 경계 유지
- 자격 증명 보호
- 제한된 편집 기능

## 협업 기능

**팀 협업**
공유 기능을 통해 워크플로우 작성자가 다른 팀원에게 액세스 권한을 부여하여 협업 가능

**역할 기반 권한**
시스템은 역할 기반 권한 모델을 사용하여 공유 워크플로우에서 다른 사용자가 수행할 수 있는 작업을 제어함

**보안 관리**
자격 증명이 공유되지 않은 경우 특정 편집 기능이 제한되어 보안 경계를 유지함

## 컨텍스트

이 기능은 n8n의 더 넓은 사용자 관리 및 액세스 제어 시스템의 일부로, 역할 기반 액세스 제어(RBAC), 프로젝트,
플랫폼 전체에 걸쳐 더 세밀한 권한 관리를 위한 커스텀 역할을 포함함

## 활용 사례

**지식 공유**
팀원 간 워크플로우를 공유하여 베스트 프랙티스 전파

**협업 개발**
여러 사용자가 워크플로우를 함께 개발하고 개선

**역할 분리**
적절한 권한 수준을 통해 역할에 따른 액세스 제어

## 참고사항

워크플로우 공유는 팀 협업과 지식 공유를 위한 핵심 기능임. 역할 기반 권한 시스템은 보안을 유지하면서 효과적인
협업을 가능하게 함
