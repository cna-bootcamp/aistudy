# 태그 (Tags)

## 개요

n8n의 워크플로우 태그 기능에 대한 문서임. 제공된 웹페이지 콘텐츠에서 실제 문서 내용은 누락되어 있으며, 주로
네비게이션 메뉴와 구조 요소를 포함함

## 문서 구조

페이지는 태그 문서의 목차에 다음 섹션을 다루어야 함을 나타냄:

### 1. 워크플로우에 태그 추가 (Add a Tag to a Workflow)
워크플로우에 태그를 할당하는 방법
- 새 태그 생성
- 기존 태그 적용
- 여러 태그 할당

### 2. 태그로 필터링 (Filter by Tag)
태그를 사용하여 워크플로우를 검색하고 필터링하는 방법
- 특정 태그가 있는 워크플로우 찾기
- 여러 태그로 필터링
- 태그 기반 워크플로우 정리

### 3. 태그 관리 (Manage Tags)
태그를 생성, 편집 및 삭제하는 방법
- 태그 이름 변경
- 태그 삭제
- 태그 정리 및 유지관리

## 컨텍스트

이 문서 페이지는 n8n의 "앱 사용하기" 섹션 내 "워크플로우 이해하기"에 속하며, 태그가 n8n 플랫폼 내에서 조직화
및 관리 목적의 기능임을 시사함

## 태그의 활용

**조직화 (Organization)**
태그를 사용하여 워크플로우를 카테고리별로 분류하고 정리
- 프로젝트별 그룹화
- 부서별 분류
- 기능별 구분

**검색 및 필터링 (Search and Filter)**
대량의 워크플로우에서 특정 워크플로우를 빠르게 찾기
- 태그 기반 검색
- 복수 태그 조합 필터
- 효율적인 워크플로우 탐색

**팀 협업 (Team Collaboration)**
팀 전체에서 일관된 분류 체계 유지
- 공통 태그 규칙 적용
- 워크플로우 소유권 표시
- 상태 및 단계 추적

## 베스트 프랙티스

**일관된 명명**
태그 이름을 일관되게 유지하여 혼란 방지

**적절한 개수**
너무 많은 태그는 오히려 복잡성을 증가시킬 수 있으므로 적절한 수준 유지

**정기적인 정리**
사용하지 않는 태그는 정기적으로 제거하여 시스템 깔끔하게 유지

## 참고사항

태그는 대규모 워크플로우 환경에서 조직화와 검색 효율성을 크게 향상시키는 도구임. 제공된 전체 문서 텍스트가 없어
상세한 사용 지침은 n8n 문서 페이지를 직접 참조해야 함
