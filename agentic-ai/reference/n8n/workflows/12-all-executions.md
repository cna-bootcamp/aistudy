# 전체 실행 (All Executions)

## 개요

n8n Docs의 워크플로우 실행 관리를 다루는 페이지임. 이 페이지는 "앱 사용" → "워크플로우 이해" → "실행" →
"전체 실행" 위치에 있음

## 페이지 구조

페이지는 다음 섹션을 포함하는 목차를 가지고 있음:

- **실행 필터링**
- **실패한 워크플로우 재시도**
- **이전 실행의 데이터를 현재 워크플로우로 로드**

## 주요 기능

### 1. 실행 필터링 (Filter Executions)
모든 워크플로우의 실행을 검색하고 필터링하는 기능
- 전체 프로젝트의 실행 기록 검색
- 다양한 조건으로 실행 필터링
- 특정 워크플로우, 날짜, 상태별 필터링

### 2. 실패한 워크플로우 재시도 (Retry Failed Workflows)
실패한 워크플로우를 다시 실행하는 방법
- 실패 지점부터 재실행
- 오류 수정 후 재시도
- 배치로 여러 실패한 실행 재시도

### 3. 이전 실행 데이터 로드 (Load Data from Previous Executions)
과거 실행의 데이터를 현재 워크플로우로 가져오는 기능
- 이전 실행 결과 재사용
- 테스트 및 디버깅에 유용
- 수동 실행 시 과거 데이터로 테스트

## 컨텍스트

이 문서 페이지는 워크플로우 실행을 포괄적으로 관리하는 방법을 다룸. 다음과 같은 관련 주제와 함께 위치함:

- 수동, 부분 및 프로덕션 실행
- 더티 노드
- 워크플로우별 실행
- 커스텀 실행 데이터
- 실행 디버그

## 전체 실행 vs 워크플로우별 실행

**전체 실행 (All Executions)**
- 모든 워크플로우의 실행을 통합 뷰로 제공
- 프로젝트 전체의 실행 상태 모니터링
- 크로스 워크플로우 분석 가능

**워크플로우별 실행 (Workflow-level Executions)**
- 특정 워크플로우의 실행만 표시
- 개별 워크플로우의 상세 분석에 집중

## 참고사항

실제 상세한 콘텐츠는 제공된 소스 자료에서 잘려 있으며, 페이지는 주로 네비게이션 메뉴와 구조 요소를 포함함.
완전한 문서 텍스트와 각 섹션의 전체 설명을 보려면 문서 페이지를 직접 방문해야 함
