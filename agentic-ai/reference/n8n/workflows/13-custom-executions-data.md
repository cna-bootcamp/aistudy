# 커스텀 실행 데이터 (Custom Executions Data)

## 개요

n8n 워크플로우 실행 중에 커스텀 데이터를 설정하고 접근하는 방법을 다루는 문서 페이지임

## 주요 섹션

문서는 두 가지 주요 하위 섹션을 포함함:

### 1. 커스텀 실행 데이터 설정 (Set Custom Executions Data)
워크플로우 실행 중에 커스텀 정보를 저장하는 방법에 대한 지침
- Code 노드를 통한 데이터 저장
- 실행 컨텍스트에 커스텀 객체 추가
- 실행 수명 주기 동안 데이터 유지

### 2. 실행 중 커스텀 데이터 객체 접근 (Access the Custom Data Object During Execution)
동일한 실행 내에서 이전에 저장한 커스텀 데이터를 검색하는 방법
- Code 노드에서 데이터 읽기
- 워크플로우의 다른 노드에서 데이터 활용
- 실행 간 데이터 공유

## 구현 세부사항

구조에 따르면, 이 기능은 "Code 노드"와 통합되어 있어 개발자가 JavaScript/Node.js 코드 블록을 사용하여 커스텀
실행 데이터와 상호작용할 수 있음을 시사함

## 활용 사례

**실행 컨텍스트 저장**
외부 데이터베이스나 변수에 의존하지 않고 여러 노드 실행에 걸쳐 지속적인 데이터 저장이 필요한 워크플로우에 유용함

**디버깅 및 로깅**
실행 중 중간 결과나 메타데이터를 저장하여 디버깅 및 분석에 활용

**조건부 로직**
이전 노드의 실행 결과를 기반으로 후속 노드의 동작을 결정

## 데이터 범위

커스텀 데이터는 단일 실행 수명 주기로 범위가 지정됨. 즉, 한 번의 워크플로우 실행 내에서만 데이터가 유지되며,
실행이 완료되면 데이터는 사라짐

## 컨텍스트

이 기능은 n8n 플랫폼 가이드의 "실행" 섹션 내에 위치하며, 디버깅, 수동 실행, 더티 노드와 같은 관련 주제와 함께
제공됨

## 참고사항

커스텀 실행 데이터는 복잡한 워크플로우에서 노드 간 상태 관리와 데이터 공유를 위한 강력한 도구임. Code 노드를
통한 프로그래밍 방식의 접근으로 유연한 데이터 처리가 가능함
