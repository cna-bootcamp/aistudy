# 설정 (Settings)

## 개요

n8n의 **워크플로우 설정**에 대한 문서 페이지임. "앱 사용하기" 섹션의 "워크플로우 이해하기" 내에 속함

## 페이지 구조

페이지는 워크플로우 구성 옵션에 대한 참조 가이드 역할을 하며, 다음 주요 섹션을 포함하는 목차가 있음:

### 워크플로우 설정 접근 (Access Workflow Settings)
설정을 찾는 방법에 대한 지침
- 워크플로우 편집기에서 설정 메뉴 열기
- 설정 페이지 네비게이션

### 사용 가능한 설정 (Available Settings)
모든 구성 가능한 옵션의 상세 분류:

#### 1. 실행 순서 (Execution Order)
워크플로우 내에서 노드 실행 순서를 제어
- 순차 실행
- 병렬 실행

#### 2. 오류 워크플로우 (Error Workflow)
오류 알림을 위한 워크플로우 설정
- 오류 발생 시 실행될 별도 워크플로우 지정
- 오류 로깅 및 알림 자동화

#### 3. 이 워크플로우를 호출할 수 있는 대상 (This Workflow Can Be Called By)
다른 워크플로우에서 현재 워크플로우를 호출할 수 있는 권한 설정
- 서브 워크플로우로 사용
- 재사용 가능한 워크플로우 구성

#### 4. 타임존 (Timezone)
워크플로우의 타임존 설정
- 스케줄 트리거의 시간 기준
- 날짜/시간 관련 작업의 타임존

#### 5. 실패한 프로덕션 실행 저장 (Save Failed Production Executions)
실패한 프로덕션 실행의 히스토리 저장 여부
- 오류 분석을 위한 데이터 보존
- 스토리지 관리

#### 6. 성공한 프로덕션 실행 저장 (Save Successful Production Executions)
성공한 프로덕션 실행의 히스토리 저장 여부
- 실행 로그 관리
- 스토리지 최적화

#### 7. 수동 실행 저장 (Save Manual Executions)
수동 실행의 히스토리 저장 여부
- 테스트 실행 추적
- 디버깅 데이터 보존

#### 8. 실행 진행 상황 저장 (Save Execution Progress)
실행 중간 단계의 데이터 저장
- 장기 실행 워크플로우 모니터링
- 진행 상황 추적

#### 9. 타임아웃 워크플로우 (Timeout Workflow)
워크플로우 실행 제한 시간 설정
- 무한 루프 방지
- 리소스 관리

#### 10. 예상 절약 시간 (Estimated Time Saved)
워크플로우 자동화로 절약된 예상 시간 표시
- ROI 계산
- 자동화 효과 측정

## 컨텍스트

이 문서 페이지는 워크플로우 관리, 통합, 호스팅, 코딩 기능, 고급 AI 기능을 다루는 포괄적인 n8n 지식 베이스의
일부임. 페이지는 n8n 자동화 플랫폼에서 워크플로우 구성을 관리하는 사용자를 위한 리소스 자료로서 계층적 네비게이션
구조 내에 나타남: n8n 사용 > 앱 사용 > 워크플로우 이해 > 설정

주변 문서 생태계는 노드, 트리거, 자격 증명, 데이터 처리, 엔터프라이즈 기능에 대한 광범위한 내용을 포함하여,
이것이 n8n 자동화 플랫폼에서 워크플로우 구성을 관리하는 사용자를 위한 리소스 자료임을 나타냄

## 참고사항

워크플로우 설정은 워크플로우의 동작, 성능 및 리소스 사용을 세밀하게 제어할 수 있게 함. 적절한 설정 구성은
효율적이고 안정적인 워크플로우 운영에 필수적임
