# 노드 (Nodes)

## 개요

노드는 n8n 워크플로우의 기본 빌딩 블록임. 이 문서는 n8n 플랫폼에서 노드를 이해하고 사용하는 방법을 다룸

## 주요 노드 카테고리

문서는 세 가지 주요 노드 유형을 다룸:

### 1. 코어 노드 (Core Nodes)
워크플로우 로직을 위한 내장 기본 컴포넌트
- 조건부 분기
- 데이터 변환
- 제어 흐름 관리

### 2. 액션 (Actions)
외부 애플리케이션 및 서비스에 연결하는 통합 노드
- API 호출 수행
- 데이터 조작 및 전송
- 외부 시스템과의 상호작용

### 3. 트리거 (Triggers)
워크플로우 실행을 시작하는 이벤트 기반 노드
- Webhook 수신
- 예약된 실행
- 외부 이벤트 감지

## 노드 작업 개요

**트리거와 액션:**
- 트리거는 이벤트 개시자 역할을 수행함
- 액션은 워크플로우 내에서 수행되는 특정 작업을 나타냄

## 노드 관리

문서는 다음에 대한 가이드를 제공함:
- 워크플로우에 노드 추가 (빈 워크플로우 및 기존 워크플로우에 모두)
- 노드 컨트롤 및 기능
- 노드 설정 구성
- 노드 간 연결

## 통합 범위

노드 생태계는 다음을 포함한 수백 개의 서비스와의 통합을 제공함:
- 커뮤니케이션 플랫폼: Slack, Discord, Teams
- 데이터베이스: MongoDB, PostgreSQL
- 비즈니스 도구: Salesforce, HubSpot
- AI 서비스: OpenAI, Google Gemini
- 클라우드 제공업체: AWS, Azure, Google Cloud

## 참고사항

실제 상세한 문서 내용은 제공된 소스 자료에서 잘림 현상이 있어 주로 네비게이션 메뉴 구조를 포함하고 있음.
포괄적인 사용 지침은 전체 문서 페이지를 참조해야 함
