# 더티 노드 (Dirty Nodes)

## 개요

n8n 워크플로우에서 "더티 노드"에 대한 문서임. 페이지 구조는 다음 목차 항목을 포함함:

- 더티 노드 데이터를 인식하는 방법
- n8n이 노드를 더티로 표시하는 이유
- 더티 노드 해결하기

## 더티 노드란?

더티 노드는 업스트림 데이터가 변경되었을 때 n8n이 특정 노드를 표시하는 상태임. 이는 노드가 가지고 있는 데이터가
최신이 아니거나 재실행이 필요함을 나타냄

## 주요 개념

### 1. 더티 노드 데이터 인식 방법
워크플로우에서 더티 노드를 식별하기 위한 시각적 표시기
- 노드의 시각적 변화를 통해 더티 상태 확인
- 워크플로우 편집기에서 표시되는 특정 아이콘이나 색상

### 2. n8n이 노드를 더티로 표시하는 이유
노드가 더티 상태가 되는 원인
- 업스트림 노드의 데이터 변경
- 워크플로우 구조 변경
- 노드 설정 수정

### 3. 더티 노드 해결
더티 노드 상태를 해결하거나 지우는 단계
- 워크플로우 재실행
- 수동으로 노드 새로고침
- 데이터 동기화

## 실용적 의미

**데이터 일관성**
더티 노드 시스템은 워크플로우 내에서 데이터 일관성을 유지하는 데 도움이 됨

**실행 효율성**
변경된 데이터가 있는 노드만 재실행하도록 하여 효율성을 높임

**디버깅 지원**
더티 상태는 개발자가 워크플로우의 어느 부분이 업데이트가 필요한지 쉽게 식별할 수 있게 함

## 참고사항

실제 상세한 문서 내용(더티 노드 인식 방법, 원인, 해결 단계를 설명하는 본문)은 제공된 텍스트에 포함되지 않았음.
완전한 더티 노드 문서를 보려면 문서 본문 섹션을 포함하는 완전한 페이지 콘텐츠가 필요함
