# 생성 및 실행 (Create and Run)

## 개요

n8n에서 워크플로우를 생성하고 실행하는 기본 프로세스를 다루는 섹션임

## 주요 주제

### 워크플로우 생성

초기 워크플로우 생성 프로세스에 전념하는 섹션이 있음

### 워크플로우 수동 실행

온디맨드 방식으로 워크플로우 실행을 트리거하는 방법을 다룸. 수동 실행을 통해 사용자는 예약된 트리거나 외부 이벤트를
기다리지 않고도 자동화 시퀀스를 테스트하고 디버그할 수 있음

### 워크플로우 자동 실행

문서는 자동 워크플로우 실행을 다루며, 다음을 포함함:
- **예약된 트리거** - 워크플로우가 미리 정해진 간격으로 실행 가능
- **이벤트 기반 트리거** - 외부 이벤트나 webhook 호출에 대응하여 자동화가 활성화될 수 있음

## 네비게이션 컨텍스트

이 페이지는 n8n 문서의 "앱 사용하기" 카테고리 내 "워크플로우 이해하기" 섹션의 일부임. 동일한 섹션의 관련 주제는
다음을 포함함:
- 워크플로우 저장 및 배포
- 워크플로우 구성 요소 (노드, 연결, 스티키 노트)
- 실행 모니터링 및 디버깅
- 워크플로우 태그, 템플릿 및 공유 옵션
- 설정 및 워크플로우 히스토리

문서는 기본 워크플로우 생성부터 고급 관리 및 실행 전략까지 진행하는 사용자를 위한 구조화된 학습 경로를 제공함
