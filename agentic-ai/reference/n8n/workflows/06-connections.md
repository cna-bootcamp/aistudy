# 연결 (Connections)

## 개요

연결은 n8n 워크플로우에서 노드 간의 링크로, 데이터 흐름을 가능하게 하고 실행 순서를 결정함

## 주요 작업

페이지 구조는 두 가지 주요 작업 영역을 나타냄:

### 1. 연결 생성 (Create a Connection)
노드 간에 새로운 연결을 설정하는 방법에 대한 지침
- 노드의 출력 포트에서 다른 노드의 입력 포트로 드래그
- 데이터 흐름 경로 정의
- 실행 순서 결정

### 2. 연결 삭제 (Delete a Connection)
기존 연결을 제거하는 방법
- 불필요한 데이터 흐름 제거
- 워크플로우 구조 재구성

## 핵심 컨텍스트

문서는 연결을 노드, 스티키 노트, 실행과 함께 더 넓은 워크플로우 컴포넌트 계층 구조 내에 배치함. 이는 연결이
기능적인 워크플로우를 구성하기 위한 기본 빌딩 블록임을 시사함

연결 문서는 "워크플로우 이해하기"의 "구성 요소" 섹션의 일부로 표시되어, 워크플로우를 구축하는 방법을 배우는
사용자에게 필수 지식임을 나타냄. 계층적 구성은 연결이 노드 자체에 대한 학습 후에 나오므로, 사용자가 연결 메커니즘을
마스터하기 전에 노드 기본 사항을 이해해야 함을 시사함

## 문서 구조

문서는 이론적 설명보다는 실용적인 작업을 다루는 개별 섹션을 가진 참조 가이드로 기능함. 이 작업 지향적 접근 방식은
사용자가 특정 워크플로우 구축 목표를 달성하는 데 도움이 됨

## 참고사항

연결은 워크플로우의 로직과 데이터 흐름을 정의하는 중요한 요소임. 적절한 연결 설정은 워크플로우의 정확한 실행과
의도한 결과를 보장하는 데 필수적임
