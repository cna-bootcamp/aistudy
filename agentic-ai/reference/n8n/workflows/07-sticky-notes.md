# 스티키 노트 (Sticky Notes)

## 개요

스티키 노트는 n8n 워크플로우 편집기에서 주석 요소를 추가할 수 있는 기능임. 워크플로우 자동화 플랫폼인 n8n에서
스티키 노트 기능에 대한 문서 페이지임

## 목차

페이지는 다음 주제를 다룸:

### 기본 작업
- 스티키 노트 생성
- 스티키 노트 편집
- 색상 변경

### 고급 기능
- 스티키 노트 위치 지정
- Markdown으로 작성
- 이미지를 전체 너비로 만들기
- YouTube 동영상 삽입

## 컨텍스트

이 문서 페이지는 n8n Docs 네비게이션 구조 내에 다음과 같이 위치함:
- n8n 사용 → 앱 사용 → 워크플로우 이해 → 구성 요소 → **스티키 노트**

## 주요 특징

**문서화 도구**
스티키 노트는 워크플로우에 설명과 주석을 추가하여 팀원 간의 이해를 돕고 유지보수를 용이하게 함

**Markdown 지원**
Markdown 구문을 지원하여 풍부한 텍스트 형식 및 구조화된 문서 작성 가능

**미디어 임베딩**
이미지 및 YouTube 동영상과 같은 미디어를 포함할 수 있어 시각적 문서화 지원

**시각적 구성**
색상 변경 및 위치 지정을 통해 워크플로우를 시각적으로 구성하고 정리할 수 있음

## 참고사항

스티키 노트는 복잡한 워크플로우를 문서화하고 팀원 간의 커뮤니케이션을 개선하는 데 유용한 도구임. 특히 Markdown
지원을 통해 구조화된 문서를 작성할 수 있어 기술 문서화에 적합함
