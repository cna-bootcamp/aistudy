# 디버그 (Debug)

## 개요

n8n에서 과거 워크플로우 실행을 디버그하고 재실행하는 방법을 다루는 문서 페이지임

## 페이지 정보

이 페이지는 n8n의 "실행" 문서 섹션의 일부로, "앱 사용하기" 카테고리 내 "워크플로우 이해하기"에 속함

## 관련 문서 섹션

실행 문서는 여러 상호 연결된 주제를 포함함:

### 실행 유형
- **수동, 부분 및 프로덕션 실행** - 사용 가능한 다양한 실행 유형
- **더티 노드** - 오래된 데이터를 가진 노드 처리
- **워크플로우별 실행** - 단일 워크플로우 실행 추적
- **전체 실행** - 워크플로우 전반의 실행 보기
- **커스텀 실행 데이터** - 실행 메타데이터 기록

## 목차

페이지는 "데이터 로드" 섹션을 언급하며, 문서가 과거 실행 정보를 검색하고 작업하는 방법을 다룸을 시사함

## 디버깅 기능

**과거 실행 데이터 로드**
이전 실행의 데이터를 현재 워크플로우로 가져와서 디버깅 가능
- 실패한 실행의 입력 데이터로 재현
- 문제 상황 재구성
- 단계별 데이터 흐름 분석

**재실행 (Re-run)**
과거 실행을 다시 실행하여 문제 해결
- 동일한 입력으로 워크플로우 재실행
- 수정 사항 검증
- 오류 재현 및 수정 확인

## 네비게이션 컨텍스트

이 문서는 n8n의 포괄적인 워크플로우 관리 시스템 내에 위치하며, 자격 증명 관리, 사용자 액세스 제어, 소스 제어
통합과 같은 엔터프라이즈 기능과 함께 실행 관련 기능 옆에 배치됨

전체 문서 구조는 n8n이 워크플로우 자동화 플랫폼의 일부로 강력한 실행 추적, 디버깅 및 재실행 기능을 제공함을 시사함

## 참고사항

참조해야 함
