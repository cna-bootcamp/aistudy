# 템플릿 (Templates)

## 개요

n8n 문서의 **템플릿** 섹션임. 이 페이지는 n8n의 워크플로우 자동화를 위한 포괄적인 가이드의 일부임

## 주요 콘텐츠 섹션

문서는 템플릿과 관련된 세 가지 주요 영역을 다룸:

### 1. 템플릿 접근 (Access Templates)
n8n 플랫폼 내에서 사전 구축된 워크플로우 템플릿을 찾고 활용하는 방법을 설명함
- 템플릿 라이브러리 탐색
- 사용 사례별 템플릿 검색
- 템플릿을 워크플로우로 가져오기

### 2. n8n 라이브러리에 워크플로우 추가 (Add Your Workflow to the n8n Library)
자신의 워크플로우를 더 넓은 n8n 커뮤니티 라이브러리에 기여하는 프로세스를 안내하여 다른 사람들이 솔루션을 발견하고
구현할 수 있도록 함
- 워크플로우 제출 절차
- 템플릿 품질 기준
- 커뮤니티 기여 가이드라인

### 3. 셀프 호스팅 n8n: 자체 라이브러리 사용 (Self-hosted n8n: Use Your Own Library)
셀프 호스팅 n8n 인스턴스를 실행하는 조직을 위해 커스텀 템플릿 라이브러리 생성에 대한 기술 가이드를 제공함

주요 하위 섹션:

#### 엔드포인트 (Endpoints)
템플릿 관리에 필요한 API 엔드포인트 문서
- 템플릿 목록 조회 API
- 템플릿 상세 정보 API
- 템플릿 검색 API

#### 쿼리 파라미터 (Query Parameters)
템플릿 쿼리를 필터링하고 커스터마이징하는 데 사용되는 파라미터에 대한 세부 정보
- 카테고리 필터
- 검색 키워드
- 페이지네이션 파라미터

#### 데이터 스키마 (Data Schema)
템플릿 데이터 구조에 대한 사양
- 템플릿 메타데이터 형식
- 워크플로우 정의 구조
- 필수 및 선택 필드

## 컨텍스트

이 문서는 "앱 사용하기" 카테고리 내 "워크플로우 이해하기"에 속하며, 실행, 태그, 공유, 설정과 같은 다른 워크플로우
관리 주제와 함께 배치됨. 리소스는 클라우드 및 셀프 호스팅 환경 모든 배포 수준의 n8n 사용자를 대상으로 함

## 템플릿의 이점

**빠른 시작**
사전 구축된 템플릿을 사용하여 처음부터 시작하지 않고 빠르게 워크플로우 구축

**베스트 프랙티스**
커뮤니티에서 검증된 워크플로우 패턴 및 구조 학습

**시간 절약**
일반적인 사용 사례에 대한 검증된 솔루션 활용

**커뮤니티 기여**
자신의 워크플로우를 공유하여 다른 사용자 지원

## 셀프 호스팅 템플릿 라이브러리

**조직 맞춤화**
기업 환경에서 내부 표준 및 베스트 프랙티스를 반영한 커스텀 템플릿 라이브러리 구축

**API 기반 관리**
RESTful API를 통한 프로그래밍 방식의 템플릿 관리

**중앙 집중식 제어**
조직 전체에서 승인된 워크플로우 템플릿 배포 및 관리

## 참고사항

템플릿은 n8n 워크플로우 개발을 가속화하고 베스트 프랙티스를 전파하는 강력한 메커니즘임. 클라우드 사용자는 공개
라이브러리를 활용하고, 셀프 호스팅 사용자는 자체 커스텀 라이브러리를 구축하여 조직의 특정 요구사항에 맞출 수 있음
