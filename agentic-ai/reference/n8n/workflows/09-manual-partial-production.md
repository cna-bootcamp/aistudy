# 수동, 부분 및 프로덕션 실행

## 개요

n8n의 다양한 실행 유형과 모드에 대한 문서임. 페이지 제목과 목차는 다음 주제를 다룰 것으로 나타남:

- 수동 실행 (Manual Executions)
- 부분 실행 (Partial Executions) - 문제 해결 포함
- 프로덕션 실행 (Production Executions)

## 실행 유형

### 1. 수동 실행 (Manual Executions)
사용자가 직접 트리거하는 워크플로우 실행
- 테스트 및 디버깅 목적으로 사용
- 워크플로우 편집기에서 "Execute Workflow" 버튼을 통해 실행
- 실시간으로 각 노드의 실행 결과 확인 가능

### 2. 부분 실행 (Partial Executions)
워크플로우의 일부 노드만 실행하는 방식
- 특정 노드부터 실행 시작 가능
- 디버깅 및 테스트 시 효율적
- **문제 해결**: 부분 실행 관련 문제 해결 단계 포함

### 3. 프로덕션 실행 (Production Executions)
자동으로 실행되는 배포된 워크플로우
- 트리거 이벤트나 스케줄에 따라 자동 실행
- 실제 운영 환경에서 사용
- 실행 히스토리 및 로그 저장

## 주요 특징

**테스트와 디버깅**
수동 및 부분 실행은 워크플로우를 프로덕션에 배포하기 전에 철저히 테스트할 수 있게 함

**실행 제어**
다양한 실행 모드를 통해 개발자는 워크플로우의 실행 방식을 세밀하게 제어할 수 있음

**문제 해결**
부분 실행의 문제 해결 섹션은 실행 중 발생할 수 있는 문제를 해결하는 방법을 제공함

## 참고사항

실제 상세한 본문 내용은 제공된 소스 자료에 포함되지 않았음. 페이지는 주로 네비게이션 계층 구조, 자격 증명 목록,
통합 참조를 포함하고 있으나, 각 실행 유형을 설명하는 실질적인 설명 콘텐츠는 잘려 있음
