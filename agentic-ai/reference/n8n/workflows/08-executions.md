# 실행 (Executions)

## 개요

n8n Docs의 **실행** 섹션에 대한 문서 랜딩 페이지임. 이 페이지는 "앱 사용" > "워크플로우 이해" > "실행"
문서 계층 구조의 일부임

## 사용 가능한 실행 관련 문서 주제

페이지는 여러 주요 실행 관련 문서 영역을 개괄함:

### 1. 수동, 부분 및 프로덕션 실행
다양한 실행 유형 및 모드를 다룸
- 수동 실행: 사용자가 직접 트리거하는 실행
- 부분 실행: 워크플로우의 일부만 실행
- 프로덕션 실행: 자동으로 실행되는 배포된 워크플로우

### 2. 더티 노드 (Dirty Nodes)
워크플로우 실행 중 노드 상태를 다룸
- 업스트림 데이터 변경 시 노드가 "더티" 상태로 표시됨
- 더티 노드 인식 및 해결 방법

### 3. 워크플로우별 실행
단일 워크플로우 실행 관리에 대한 문서
- 특정 워크플로우의 실행 기록 보기
- 실행 필터링 및 검색

### 4. 전체 실행 (All Executions)
모든 실행 레코드 보기 및 관리에 대한 정보
- 프로젝트 전체의 실행 추적
- 실행 통계 및 분석

### 5. 커스텀 실행 데이터
실행 데이터 처리 커스터마이징에 대한 세부 정보
- 실행 중 커스텀 데이터 저장
- 데이터 접근 및 활용

### 6. 실행 디버그
워크플로우 실행 디버깅을 위한 도구 및 기법
- 실행 오류 추적
- 데이터 흐름 검사

## 컨텍스트

이 문서 섹션은 n8n의 더 넓은 워크플로우 관리 문서의 일부로, 워크플로우 생성, 구성 요소(노드 및 연결), 배포 및
기타 핵심 워크플로우 기능에 대한 주제를 포함함. 실행 섹션은 특히 워크플로우가 실행되는 방식과 사용자가 이러한
실행 프로세스를 모니터링하고, 디버그하고, 관리할 수 있는 방법에 초점을 맞춤

## 참고사항

실행 관리는 n8n 워크플로우의 생명주기에서 중요한 부분임. 효과적인 실행 모니터링과 디버깅은 안정적이고 효율적인
자동화를 보장하는 데 필수적임
