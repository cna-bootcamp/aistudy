# n8n Insights

## 개요

Insights는 n8n 워크플로우의 성능과 비즈니스 임팩트를 측정하고 시각화하는 Enterprise 분석 기능임

## 주요 기능

### 워크플로우 분석
- 실행 통계 및 추이
- 성능 메트릭
- 자동화로 인한 시간 절약 계산
- 비용 효율성 측정

### 비즈니스 가치 정량화
- ROI(투자 수익률) 계산
- 생산성 향상 지표
- 자동화 효과 측정
- 경영진 보고 자료

## Insights Summary Banner

### 개요
워크플로우 목록 상단에 표시되는 요약 배너로 주요 지표를 한눈에 확인 가능

### 표시 정보
**총 워크플로우 수**:
- 활성 워크플로우
- 비활성 워크플로우
- 전체 워크플로우

**실행 통계**:
- 오늘 실행 횟수
- 이번 주 실행 횟수
- 이번 달 실행 횟수

**시간 절약**:
- 오늘 절약한 시간
- 이번 주 절약한 시간
- 이번 달 절약한 시간
- 누적 절약 시간

**성공률**:
- 전체 성공률
- 최근 24시간 성공률
- 주간 성공률 추이

## Insights Dashboard

### 접근 방법
- n8n 메인 메뉴에서 "Insights" 클릭
- 또는 워크플로우 목록에서 "View Insights" 선택

### 대시보드 구성

**1. 개요 섹션**:
- 총 실행 횟수
- 평균 실행 시간
- 총 시간 절약
- 워크플로우 효율성 점수

**2. 실행 추이 그래프**:
- 시간별/일별/주별/월별 실행 횟수
- 성공/실패 분포
- 피크 타임 분석

**3. 성능 메트릭**:
- 워크플로우별 평균 실행 시간
- 가장 느린 워크플로우
- 가장 자주 실행되는 워크플로우
- 리소스 사용량

**4. 오류 분석**:
- 실패율 추이
- 오류 유형별 분류
- 가장 많이 실패하는 워크플로우
- 오류 발생 패턴

**5. 시간 절약 리포트**:
- 워크플로우별 시간 절약
- 총 누적 시간 절약
- 비용 절감 효과
- ROI 계산

### 대시보드 커스터마이징
- 위젯 추가/제거
- 레이아웃 조정
- 필터 적용 (날짜, 워크플로우, 프로젝트)

## 시간 절약 메트릭

### Fixed Time Saved (고정 시간 절약)

**개념**:
워크플로우 실행 시마다 절약되는 고정된 시간 값

**설정 방법**:
1. 워크플로우 설정 열기
2. "Insights" 탭 선택
3. "Fixed Time Saved" 입력
4. 예: 30분 (0.5시간)

**사용 사례**:
- 반복 작업 자동화
- 데이터 입력 자동화
- 리포트 생성 자동화

**계산 예시**:
```
워크플로우 실행 횟수: 100회/월
고정 시간 절약: 0.5시간/실행
월간 총 시간 절약: 100 × 0.5 = 50시간
```

### Dynamic Time Saved (동적 시간 절약)

**개념**:
워크플로우의 실제 실행 시간과 데이터 양을 기반으로 계산된 시간 절약

**계산 방식**:
```javascript
// 처리된 아이템 수 기반
동적 시간 절약 = 처리된 아이템 수 × 아이템당 수동 처리 시간

// 예시
처리된 이메일: 50개
이메일당 수동 처리 시간: 2분
동적 시간 절약: 50 × 2분 = 100분 = 1.67시간
```

**설정 방법**:
1. 워크플로우 설정
2. "Dynamic Time Saved Formula" 입력
3. Expression 사용 가능
4. 예: `{{ $json.itemsProcessed * 0.033 }}`

**사용 사례**:
- 데이터 처리량에 비례하는 작업
- 배치 처리
- API 호출 자동화

### 시간 절약 비교

| 항목 | Fixed Time Saved | Dynamic Time Saved |
|------|------------------|-------------------|
| 계산 방식 | 고정 값 | 실행 데이터 기반 |
| 설정 | 단순 (숫자 입력) | 복잡 (수식) |
| 정확도 | 추정치 | 실제 데이터 반영 |
| 사용 난이도 | 쉬움 | 중급 |
| 적합한 경우 | 단순 반복 작업 | 변동 작업량 |

### 시간 절약 최적화

**정확한 측정**:
1. 실제 수동 작업 시간 측정
2. 여러 사용자의 평균 시간 계산
3. 학습 곡선 고려
4. 정기적인 재평가

**현실적인 값 설정**:
- 과대 평가 방지
- 실제 작업 시간 기반
- 준비 시간 포함
- 검증 시간 포함

### 히스토리컬 데이터

Insights를 지원하는 버전으로 업그레이드하면 기존 실행 히스토리를 자동으로 분석하여 Insights에 포함

**데이터 범위**:
- n8n은 기본적으로 실행 데이터 보관
- 보관 정책에 따라 과거 데이터 범위 결정
- Enterprise에서는 더 긴 보관 기간 지원

**마이그레이션 프로세스**:
1. 버전 업그레이드
2. 자동 데이터 스캔
3. Insights 메트릭 계산
4. 대시보드에 반영

### 데이터 보관 정책

**기본 보관 기간**:
- Community: 30일
- Pro: 90일
- Enterprise: 커스터마이징 가능 (최대 무제한)

**보관 기간 설정**:
```bash
N8N_EXECUTIONS_DATA_PRUNE=true
N8N_EXECUTIONS_DATA_MAX_AGE=168  # 시간 단위 (7일)
```

## 비즈니스 가치 측정

### ROI 계산

**계산 공식**:
```
ROI = (절약된 비용 - n8n 비용) / n8n 비용 × 100%

절약된 비용 = 절약된 시간 × 시간당 인건비
```

**예시**:
```
월간 시간 절약: 200시간
시간당 인건비: $50
월간 절약 비용: 200 × $50 = $10,000

n8n 월 비용: $1,000
월간 순 절약: $10,000 - $1,000 = $9,000
ROI: ($9,000 / $1,000) × 100% = 900%
```

### 생산성 향상

**측정 지표**:
- 처리된 작업량 증가
- 응답 시간 단축

- 직원 만족도 향상

**직접 비용 절감**:
