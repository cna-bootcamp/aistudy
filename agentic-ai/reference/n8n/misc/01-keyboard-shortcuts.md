# n8n 키보드 단축키

## 개요

n8n 에디터에서 생산성을 높이는 키보드 단축키 모음

## 워크플로우 제어

### 기본 작업
| 단축키 | 설명 |
|--------|------|
| `Ctrl + S` (Win/Linux)<br>`Cmd + S` (Mac) | 워크플로우 저장 |
| `Ctrl + A` (Win/Linux)<br>`Cmd + A` (Mac) | 모든 노드 선택 |
| `Ctrl + Enter` | 워크플로우 실행 |
| `Ctrl + Alt + N` | 새 워크플로우 생성 |
| `Escape` | 선택 해제 또는 패널 닫기 |

### 실행 제어
| 단축키 | 설명 |
|--------|------|
| `Ctrl + Enter` | 전체 워크플로우 실행 |
| `Ctrl + Shift + Enter` | 선택된 노드부터 실행 |
| `Alt + Enter` | 현재 노드만 실행 |

## 캔버스 조작

### 캔버스 이동
| 단축키 | 설명 |
|--------|------|
| `Space + Drag` | 캔버스 이동 (팬) |
| `마우스 휠` | 캔버스 상하 스크롤 |
| `Shift + 마우스 휠` | 캔버스 좌우 스크롤 |
| `방향키` | 캔버스 이동 |

### 캔버스 확대/축소
| 단축키 | 설명 |
|--------|------|
| `Ctrl + 마우스 휠` (Win/Linux)<br>`Cmd + 마우스 휠` (Mac) | 확대/축소 |
| `Ctrl + +` (Win/Linux)<br>`Cmd + +` (Mac) | 확대 |
| `Ctrl + -` (Win/Linux)<br>`Cmd + -` (Mac) | 축소 |
| `Ctrl + 0` (Win/Linux)<br>`Cmd + 0` (Mac) | 100% 크기로 리셋 |
| `Ctrl + 1` (Win/Linux)<br>`Cmd + 1` (Mac) | 모든 노드가 보이도록 자동 조정 |

### 캔버스의 노드
| 단축키 | 설명 |
|--------|------|
| `더블클릭` | 노드 설정 패널 열기 |
| `클릭 + Drag` | 노드 이동 |
| `Shift + 클릭` | 여러 노드 선택 |
| `Drag 영역 선택` | 영역 내 모든 노드 선택 |
| `Ctrl + 클릭` (Win/Linux)<br>`Cmd + 클릭` (Mac) | 노드를 선택/해제 토글 |

### 선택된 노드 작업
| 단축키 | 설명 |
|--------|------|
| `Delete` 또는 `Backspace` | 선택된 노드 삭제 |
| `Ctrl + C` (Win/Linux)<br>`Cmd + C` (Mac) | 선택된 노드 복사 |
| `Ctrl + X` (Win/Linux)<br>`Cmd + X` (Mac) | 선택된 노드 잘라내기 |
| `Ctrl + V` (Win/Linux)<br>`Cmd + V` (Mac) | 노드 붙여넣기 |
| `Ctrl + D` (Win/Linux)<br>`Cmd + D` (Mac) | 선택된 노드 복제 |
| `방향키` | 선택된 노드 이동 (1픽셀) |
| `Shift + 방향키` | 선택된 노드 빠르게 이동 (10픽셀) |
| `Ctrl + A` (Win/Linux)<br>`Cmd + A` (Mac) | 모든 노드 선택 |
| `/` | 선택된 노드 비활성화/활성화 |
| `D` | 선택된 노드 비활성화 |
| `P` | 선택된 노드의 데이터 피닝 토글 |
| `R` | 선택된 노드 이름 변경 |
| `Enter` | 선택된 노드 설정 열기 |

## 노드 패널

### 노드 추가
| 단축키 | 설명 |
|--------|------|
| `Tab` | 노드 추가 패널 열기 |
| `Shift + Tab` | 연결점에서 노드 추가 패널 열기 |
| `+` 버튼 클릭 | 노드 추가 패널 열기 |

### 노드 패널 카테고리
| 단축키 | 설명 |
|--------|------|
| `방향키` | 카테고리 또는 노드 탐색 |
| `Enter` | 선택된 노드 추가 |
| `Escape` | 패널 닫기 |
| `문자 입력` | 노드 검색 |

## 노드 내부 작업

### 노드 설정 패널
| 단축키 | 설명 |
|--------|------|
| `Tab` | 다음 입력 필드로 이동 |
| `Shift + Tab` | 이전 입력 필드로 이동 |
| `Enter` | 폼 제출 (노드 설정 저장) |
| `Escape` | 설정 패널 닫기 (변경사항 취소) |
| `Ctrl + Enter` | 노드 실행 |

### Expression 에디터
| 단축키 | 설명 |
|--------|------|
| `Ctrl + Space` | 자동완성 제안 표시 |
| `Tab` | 자동완성 항목 선택 |
| `Escape` | 자동완성 닫기 |
| `Ctrl + /` (Win/Linux)<br>`Cmd + /` (Mac) | 줄 주석 토글 |

### 코드 에디터 (Code 노드)
| 단축키 | 설명 |
|--------|------|
| `Ctrl + Space` | 자동완성 |
| `Ctrl + F` (Win/Linux)<br>`Cmd + F` (Mac) | 찾기 |
| `Ctrl + H` (Win/Linux)<br>`Cmd + H` (Mac) | 찾아 바꾸기 |
| `Ctrl + /` (Win/Linux)<br>`Cmd + /` (Mac) | 줄 주석 토글 |
| `Ctrl + ]` (Win/Linux)<br>`Cmd + ]` (Mac) | 들여쓰기 |
| `Ctrl + [` (Win/Linux)<br>`Cmd + [` (Mac) | 내어쓰기 |
| `Tab` | 들여쓰기 또는 자동완성 선택 |
| `Shift + Tab` | 내어쓰기 |

## 커맨드 바

### 커맨드 바 접근
| 단축키 | 설명 |
|--------|------|
| `Ctrl + K` (Win/Linux)<br>`Cmd + K` (Mac) | 커맨드 바 열기 |
| `문자 입력` | 명령 검색 |
| `방향키` | 명령 탐색 |
| `Enter` | 선택된 명령 실행 |
| `Escape` | 커맨드 바 닫기 |

### 자주 사용하는 명령
- `New Workflow`: 새 워크플로우
- `Save Workflow`: 워크플로우 저장
- `Execute Workflow`: 워크플로우 실행
- `Activate Workflow`: 워크플로우 활성화
- `Open Settings`: 설정 열기
- `Show Executions`: 실행 이력 보기

## 플랫폼별 차이점

### Windows/Linux
- `Ctrl` 키를 주로 사용
- `Delete` 또는 `Backspace`로 삭제
- `Alt` 키로 추가 기능

### macOS
- `Cmd` 키를 주로 사용 (`Ctrl` 대신)
- `Backspace` 또는 `Fn + Delete`로 삭제
- `Option` 키로 추가 기능 (Windows의 `Alt`)

## 커스터마이징

### 단축키 변경
일부 n8n 버전에서는 사용자 정의 단축키 설정 가능:
1. 설정 메뉴 열기
2. "Keyboard Shortcuts" 섹션
3. 원하는 단축키 변경
4. 저장 및 적용

### 충돌 방지
- 브라우저 단축키와 충돌 시 n8n 단축키 우선
- 브라우저 확장 프로그램 단축키 충돌 주의
- 운영체제 단축키는 우선순위 최상위

## 생산성 팁

### 빠른 워크플로우 구축
1. `Tab`으로 노드 추가
2. 노드명 입력으로 빠른 검색
3. `Enter`로 노드 추가
4. `Tab`으로 다음 노드 연결점에서 추가
5. 반복

### 효율적인 편집
1. `Ctrl + D`로 노드 빠르게 복제
2. `Shift + 방향키`로 노드 정렬
3. `Ctrl + A`로 전체 선택 후 그룹 이동
4. `P`로 테스트 데이터 피닝

### 디버깅 단축키
1. `Ctrl + Enter`로 전체 실행
2. 문제 노드 선택
3. `Alt + Enter`로 해당 노드만 재실행
4. 데이터 확인 후 수정

## 학습 전략

### 초보자
기본 단축키부터 익히기:
- `Ctrl + S`: 저장
- `Ctrl + Enter`: 실행
- `Tab`: 노드 추가
- `Delete`: 노드 삭제
- `Ctrl + C/V`: 복사/붙여넣기

### 중급자
효율성 단축키 추가:
- `Ctrl + D`: 복제
- `Ctrl + K`: 커맨드 바
- `Space + Drag`: 캔버스 이동
- `P`: 데이터 피닝
- `R`: 이름 변경

### 고급자
전문가 단축키 마스터:
- 노드 내비게이션 단축키
- Expression 에디터 단축키
- 커스텀 단축키 설정
- 매크로 스타일 워크플로우 구축
