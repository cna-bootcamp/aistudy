# 데이터 변환 (Transforming Data)

## 개요

n8n은 모든 노드가 수신 데이터를 올바르게 처리할 수 있도록 사전 정의된 데이터 구조를 사용함.
수신 데이터의 구조가 다른 경우, 각 아이템이 개별적으로 처리될 수 있도록 변환이 필요함.

예를 들어, HTTP Request 노드의 출력이 n8n 데이터 구조와 호환되지 않는 경우,
노드는 데이터를 반환하지만 하나의 아이템만 반환된 것으로 표시함.

## 데이터 변환 노드

이러한 구조를 n8n 데이터 구조로 변환하기 위해 다음 노드를 사용할 수 있음:

| 노드 | 설명 |
|------|------|
| **Aggregate** | 별도의 아이템 또는 그 일부를 가져와 개별 아이템으로 그룹화 |
| **Limit** | 정의된 최대 수를 초과하는 아이템 제거 |
| **Remove Duplicates** | 모든 필드 또는 필드 하위 집합에서 동일한 아이템을 식별하고 삭제 |
| **Sort** | 원하는 순서로 목록을 정렬하거나 무작위 선택 생성 |
| **Split Out** | 목록을 포함하는 단일 데이터 아이템을 여러 아이템으로 분리 |
| **Summarize** | Excel 피벗 테이블과 유사한 방식으로 아이템을 집계 |
