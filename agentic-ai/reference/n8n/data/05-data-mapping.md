# 데이터 매핑 (Data Mapping)

## 개요

데이터 매핑은 이전 노드의 데이터를 참조하는 것을 의미함.
데이터를 변경(변환)하는 것이 아니라 단순히 참조하는 것임.

## 매핑 방법

데이터를 매핑하는 두 가지 방법:

1. **표현식 편집기 사용**: 표현식을 직접 작성하여 데이터를 참조
2. **드래그 앤 드롭**: INPUT에서 파라미터로 데이터를 드래그하여 표현식을 자동 생성

매핑 및 아이템 링킹과 관련된 오류는 Item linking errors 문서를 참조할 것.
