# 코드를 사용한 데이터 처리 (Processing Data with Code)

## 개요

코드를 사용하여 노드에서 수신한 데이터를 추가, 제거 및 업데이트할 수 있음.

## 함수 (Function)

함수는 특정 작업을 수행하도록 설계된 코드 블록임.
n8n에서는 커스텀 JavaScript 또는 Python 코드 스니펫을 작성하여
노드에서 수신한 데이터를 추가, 제거, 업데이트할 수 있음.

## Code 노드

- Code 노드는 수신 데이터에 대한 액세스를 제공하며, 이를 조작할 수 있음
- JavaScript 코드를 사용하여 원하는 함수를 생성 가능
- Python 코드도 지원함

## 사용 사례

- 데이터 형식 변환
- 필드 추가/제거
- 조건부 로직 구현
- 외부 라이브러리를 활용한 복잡한 데이터 처리
- 수학적 계산 및 문자열 조작
