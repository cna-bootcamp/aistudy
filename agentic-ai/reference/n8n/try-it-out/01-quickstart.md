# n8n 빠른 시작 가이드

## 개요

n8n은 워크플로우 자동화 플랫폼으로, 다양한 앱과 서비스를 연결하여 자동화된 프로세스를 구축할 수 있음

## 주요 기능

### 워크플로우 관리
- 시각적 워크플로우 편집기를 통한 자동화 프로세스 설계
- 드래그 앤 드롭 방식의 직관적인 인터페이스
- 실시간 워크플로우 실행 및 디버깅

### 통합 지원
- 500개 이상의 앱 통합 지원
- Core 노드: Code, HTTP Request, Schedule Trigger 등
- 주요 서비스: Slack, GitHub, Salesforce 등

### 데이터 처리
- 데이터 흐름 제어 및 변환
- 표현식(Expression)을 통한 동적 데이터 처리
- 데이터 피닝 기능으로 테스트 데이터 고정

## 시작하기

### 학습 리소스
- 빠른 시작 가이드
- 상세 소개 문서
- 비디오 및 텍스트 코스 (초급, 중급, 고급)

### 기본 개념
- **Workflow**: 자동화 프로세스의 기본 단위
- **Node**: 워크플로우 내에서 특정 작업을 수행하는 구성 요소
- **Trigger Node**: 워크플로우를 시작하는 노드
- **Credential**: 외부 서비스 접근을 위한 인증 정보

## 엔터프라이즈 기능

### 소스 제어
- Git 기반의 버전 관리
- 팀 협업을 위한 코드 리뷰 지원

### 외부 시크릿 관리
- 외부 시크릿 스토어 연동
- 안전한 자격 증명 관리

### 고급 기능
- RBAC (역할 기반 접근 제어)
- SAML/OIDC 인증
- API 및 임베드 기능

## 참고사항
- n8n은 코드 작성 없이도 복잡한 자동화 구현 가능
- 필요시 Code 노드를 통한 커스텀 로직 추가 가능
- 정기적인 릴리스 노트 확인으로 최신 기능 파악 권장
