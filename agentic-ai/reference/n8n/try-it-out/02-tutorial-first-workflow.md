# n8n 첫 번째 워크플로우 튜토리얼

## 개요

n8n에서 첫 번째 워크플로우를 생성하는 단계별 가이드

## 준비사항

### 필수 요구사항
- n8n 인스턴스 (클라우드 또는 로컬)
- 웹 브라우저
- 기본적인 자동화 개념 이해

## 워크플로우 생성 단계

### STEP 1. 새 워크플로우 생성
- n8n 에디터 접속
- "New Workflow" 버튼 클릭
- 빈 캔버스 확인

### STEP 2. Trigger 노드 추가
- 워크플로우 시작점 설정
- 주요 Trigger 유형:
  - **Schedule Trigger**: 정해진 시간에 실행
  - **Webhook**: HTTP 요청으로 실행
  - **Manual Trigger**: 수동 실행

### STEP 3. 작업 노드 추가
- Trigger 노드에 연결할 작업 노드 선택
- 노드 검색 또는 카테고리 탐색
- 노드 설정 및 파라미터 입력

### STEP 4. 노드 연결
- 노드 간 연결점(endpoint) 드래그
- 데이터 흐름 방향 확인
- 여러 노드를 순차적으로 연결

### STEP 5. 노드 설정
- 각 노드의 설정 패널 열기
- 필수 파라미터 입력
- 선택적 옵션 조정

### STEP 6. 테스트 실행
- "Execute Workflow" 버튼 클릭
- 각 노드의 실행 결과 확인
- 오류 발생 시 디버깅

### STEP 7. 저장 및 활성화
- 워크플로우 저장
- "Active" 토글로 워크플로우 활성화
- 활성화 상태에서 자동 실행 시작

## 실습 예제: 웹훅 기반 알림

### 시나리오
웹훅으로 데이터를 받아 Slack에 메시지 전송

### 구성
1. **Webhook Trigger**: 데이터 수신
2. **Code Node**: 데이터 변환 (선택사항)
3. **Slack Node**: 메시지 전송

### 구현 단계
```
1. Webhook 노드 추가 및 URL 복사
2. Slack 노드 추가
3. Slack Credential 설정
4. 메시지 내용 구성 (Expression 활용)
5. 테스트 웹훅 전송
6. Slack 메시지 확인
```

## 데이터 처리

### Expression 사용
- 노드 간 데이터 참조: `{{ $json.fieldName }}`
- 이전 노드 데이터: `{{ $node["NodeName"].json }}`
- 환경 변수: `{{ $env.VARIABLE_NAME }}`

### 데이터 변환
- Code 노드를 통한 JavaScript 실행
- 함수 노드로 데이터 매핑
- Filter 노드로 조건부 처리

## 디버깅 팁

### 실행 데이터 확인
- 각 노드 클릭 시 입출력 데이터 표시
- JSON 뷰어로 상세 데이터 확인
- 오류 메시지 및 스택 트레이스 검토

### 데이터 피닝
- 테스트 데이터 고정
- 반복 테스트 시 동일 데이터 사용
- 피닝된 데이터는 회색 아이콘으로 표시

### 일반적인 오류
- **Credential 오류**: 인증 정보 재설정
- **Expression 오류**: 구문 및 경로 확인
- **Connection 오류**: 노드 연결 상태 점검

## 모범 사례

### 워크플로우 구성
- 명확한 노드 이름 설정
- Notes 노드로 문서화
- 복잡한 로직은 서브워크플로우로 분리

### 성능 최적화
- 불필요한 데이터 전달 최소화
- 대량 데이터 처리 시 배치 사용
- 에러 핸들링 노드 추가

### 보안
- Credential 안전하게 관리
- 민감 데이터 로깅 방지
- Webhook URL 보호
