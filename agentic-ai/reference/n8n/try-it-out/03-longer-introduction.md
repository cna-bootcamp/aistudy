# n8n 상세 소개

## n8n이란?

n8n은 확장 가능한 워크플로우 자동화 도구로, 노드 기반 프로그래밍 방식을 통해 다양한 서비스와 API를 연결함

### 주요 특징
- **오픈소스**: 소스 코드 공개 및 커뮤니티 기여 가능
- **자체 호스팅**: 데이터 소유권 및 보안 통제
- **Fair-code 라이선스**: 개인 및 기업 사용 모두 지원
- **확장성**: 커스텀 노드 및 통합 개발 가능

## 핵심 개념

### 워크플로우 (Workflow)
자동화하려는 프로세스를 시각적으로 표현한 것

**구성요소**:
- Trigger: 워크플로우 시작점
- 작업 노드: 데이터 처리 및 작업 수행
- 연결선: 데이터 흐름 경로

**실행 방식**:
- 수동 실행
- 스케줄 기반 실행
- 이벤트 기반 실행 (Webhook, Trigger)

### 노드 (Node)
워크플로우 내에서 특정 기능을 수행하는 개별 단위

**노드 유형**:

1. **Trigger 노드**
   - 워크플로우 시작
   - 예: Schedule Trigger, Webhook, Email Trigger

2. **일반 노드**
   - 데이터 처리 및 작업 수행
   - 예: HTTP Request, Slack, Google Sheets

3. **Core 노드**
   - 기본 제공 유틸리티
   - 예: Code, Function, Merge, Split

### 데이터 흐름
각 노드는 JSON 형식으로 데이터를 주고받음

**데이터 구조**:
```json
[
  {
    "json": {
      "field1": "value1",
      "field2": "value2"
    },
    "binary": {}
  }
]
```

**특징**:
- 배열 형태로 여러 아이템 처리 가능
- JSON 데이터와 바이너리 데이터 모두 지원
- 노드 간 데이터 자동 전달

## Expression 시스템

### 기본 문법
중괄호 두 개로 Expression 표현: `{{ expression }}`

### 주요 사용 사례

**1. 이전 노드 데이터 참조**
```javascript
{{ $json.fieldName }}           // 현재 아이템의 필드
{{ $node["NodeName"].json }}    // 특정 노드의 데이터
{{ $items("NodeName")[0] }}     // 특정 노드의 첫 아이템
```

**2. 데이터 변환**
```javascript
{{ $json.name.toUpperCase() }}              // 대문자 변환
{{ $json.price * 1.1 }}                     // 계산
{{ $json.date.toDateTime() }}               // 날짜 변환
```

**3. 조건부 로직**
```javascript
{{ $json.status === "active" ? "Yes" : "No" }}
{{ $json.items.length > 0 ? $json.items[0] : null }}
```

### 내장 함수
- **날짜/시간**: `$now`, `$today`, `toDateTime()`
- **문자열**: `toUpperCase()`, `toLowerCase()`, `trim()`
- **배열**: `length`, `filter()`, `map()`
- **객체**: `Object.keys()`, `Object.values()`

## 자격 증명 (Credentials)

### 개요
외부 서비스 접근을 위한 인증 정보 관리

### 지원 인증 방식
- **OAuth2**: Google, Microsoft, Slack 등
- **API Key**: 대부분의 REST API
- **Basic Auth**: 사용자명/비밀번호
- **Header Auth**: 커스텀 헤더 인증

### 관리 방법
- 재사용 가능한 Credential 생성
- 워크플로우 간 공유
- 팀원과 Credential 공유 (Enterprise)
- 외부 시크릿 스토어 연동 (Enterprise)

### 보안
- 암호화 저장
- 접근 권한 제어
- 감사 로그 기록

## 캔버스 (Canvas)

### 인터페이스 구성
- **노드 패널**: 사용 가능한 노드 목록
- **작업 영역**: 워크플로우 설계 공간
- **설정 패널**: 노드 및 워크플로우 설정
- **실행 패널**: 실행 결과 및 로그

### 캔버스 조작
- **이동**: 드래그 또는 스페이스바 + 드래그
- **확대/축소**: 마우스 휠 또는 확대/축소 버튼
- **노드 선택**: 클릭 또는 드래그 영역 선택
- **노드 복사**: Ctrl+C / Ctrl+V

### 노드 연결
- 출력 포트에서 입력 포트로 드래그
- 여러 노드를 순차적 또는 병렬로 연결
- 조건부 분기 구성 가능

## 워크플로우 실행

### 실행 모드

**1. 수동 실행**
- "Execute Workflow" 버튼 클릭
- 즉시 실행 및 결과 확인
- 디버깅 및 테스트용

**2. 자동 실행**
- 워크플로우 활성화 필요
- Trigger 조건 충족 시 자동 실행
- 프로덕션 환경용

**3. Webhook 실행**
- HTTP 요청으로 트리거
- 외부 시스템 통합
- 실시간 이벤트 처리

### 실행 데이터
- 각 노드의 입출력 데이터 저장
- 실행 히스토리 조회
- 에러 로그 및 디버깅 정보

### 에러 핸들링
- Error Trigger 노드로 에러 캐치
- 재시도 로직 구성
- 알림 설정 (이메일, Slack 등)

## 데이터 처리 패턴

### 단일 아이템 처리
각 아이템을 개별적으로 처리

### 배치 처리
여러 아이템을 한 번에 처리하여 성능 향상

### 분기 처리
- **IF 노드**: 조건에 따라 경로 분리
- **Switch 노드**: 여러 조건으로 분기
- **Merge 노드**: 분리된 경로 병합

### 루프 처리
- **Split In Batches**: 대량 데이터 배치 처리
- **Loop Over Items**: 각 아이템 반복 처리

## 고급 기능

### Code 노드
JavaScript 코드 직접 작성 가능

**사용 예시**:
```javascript
// 데이터 변환
for (const item of $input.all()) {
  item.json.processedDate = new Date().toISOString();
  item.json.total = item.json.price * item.json.quantity;
}

return $input.all();
```

### Function 노드
복잡한 데이터 변환 로직 구현

### HTTP Request 노드
모든 REST API 호출 가능

**기능**:
- GET, POST, PUT, DELETE 등 모든 HTTP 메서드
- 헤더, 파라미터, 바디 커스터마이징
- 인증 방식 선택
- 응답 처리 및 에러 핸들링

### 서브워크플로우
- 재사용 가능한 워크플로우 모듈화
- Execute Workflow 노드로 호출
- 복잡도 감소 및 유지보수성 향상
