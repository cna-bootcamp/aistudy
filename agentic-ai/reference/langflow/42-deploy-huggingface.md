# Deploy Langflow on Hugging Face Spaces

[Hugging Face Spaces](https://huggingface.co/spaces/)에 Langflow 배포.

## 배포 단계

1. **[Langflow Space](https://huggingface.co/spaces/Langflow/Langflow?duplicate=true)로 이동**

2. **Duplicate Space 클릭**

3. **복제된 Space 설정:**
   - Space 이름 입력
   - 공개(public) 또는 비공개(private) 가시성 선택
   - **Duplicate Space** 클릭

4. **설정 완료 시 새 Space로 자동 리디렉션되어 Langflow 인스턴스 사용 준비 완료**

## 장점

- 간편한 원클릭 배포
- AI/ML 커뮤니티와 쉬운 공유
- 무료 티어 사용 가능
- Hugging Face 생태계와 통합
