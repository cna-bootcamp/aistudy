# Notify and Listen

**Notify**와 **Listen** 컴포넌트는 함께 사용.

## Notify 컴포넌트

현재 Flow의 컨텍스트에서 알림 생성:
- 특정 데이터 콘텐츠 포함
- 상태 식별자 포함

## Listen 컴포넌트

**Notify** 컴포넌트에서 보낸 알림 수신.
수신된 알림 데이터는 Flow의 다른 컴포넌트로 전달 가능 (예: **If-Else** 컴포넌트).

## 사용 패턴

1. **Notify** 컴포넌트에서 특정 이벤트나 상태에 대한 알림 생성
2. **Listen** 컴포넌트에서 해당 알림 수신
3. 수신된 데이터를 기반으로 조건부 처리 또는 후속 작업 수행
