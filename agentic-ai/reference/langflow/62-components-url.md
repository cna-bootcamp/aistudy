# URL

하나 이상의 URL에서 콘텐츠 가져오기, 처리 및 다양한 형식으로 반환.
주어진 깊이까지 링크를 재귀적으로 따라가며, 일반 텍스트 또는 원시 HTML 출력 지원.

## URL 파라미터

| Name | Display Name | 설명 |
|------|--------------|------|
| `urls` | URLs | 재귀적으로 크롤링할 하나 이상의 URL. 비주얼 에디터에서 **Add URL** 클릭으로 여러 URL 추가 |
| `max_depth` | Depth | 링크 순회 제어: 초기 페이지에서 몇 "클릭" 떨어진 곳까지 크롤러가 이동할지. 깊이 1: 주어진 URL의 첫 페이지만. 깊이 2: 첫 페이지 + 첫 페이지에서 직접 링크된 각 페이지 |
| `prevent_outside` | Prevent Outside | 활성화 시 루트 URL과 동일한 도메인 내 URL만 크롤링. 크롤링된 페이지에서 링크되어 있어도 외부 사이트 접근 방지 |
| `use_async` | Use Async | 활성화 시 비동기 로딩 사용. 상당히 빠를 수 있지만 시스템 리소스 더 사용할 수 있음 |
| `format` | Output Format | 원하는 출력 형식: **Text** 또는 **HTML**. 기본값: Text |
| `timeout` | Timeout | 요청 타임아웃 (초) |
| `headers` | Headers | 인증 등에 필요한 경우 요청과 함께 보낼 헤더 |

추가 입력 파라미터: 오류 처리 및 인코딩용.

## URL 출력

**두 가지 출력 제어 설정:**

### Output Format (출력 형식)
크롤링된 페이지에서 추출되는 콘텐츠 제어:

| 설정 | 설명 |
|------|------|
| **Text** (기본값) | 크롤링된 페이지의 HTML에서 텍스트만 추출 |
| **HTML** | 크롤링된 페이지의 전체 원시 HTML 콘텐츠 추출 |

### Output data type (출력 데이터 타입)
컴포넌트 출력 필드에서 다른 컴포넌트로 전달될 데이터 구조 선택:

| 설정 | 설명 |
|------|------|
| **Extracted Pages** | 크롤링된 페이지를 전체 페이지 콘텐츠(`text`)와 `url`, `title` 등의 메타데이터 열로 분리한 `DataFrame` 출력 |
| **Raw Content** | 메타데이터를 포함한 크롤링된 페이지의 전체 텍스트 또는 HTML을 단일 텍스트 블록으로 포함하는 `Message` 출력 |

## Flow에서 사용

**표준 컴포넌트로 사용 시:**
- 선택한 출력 데이터 타입(`DataFrame` 또는 `Message`)을 받는 컴포넌트에 연결
- 직접 호환되는 컴포넌트에 연결하거나 **Type Convert** 컴포넌트로 변환

**처리 컴포넌트 활용:**
- URL 컴포넌트가 크롤링된 페이지에서 많은 데이터 추출 가능
- 특정 필드만 전달하려면 **Parser** 컴포넌트로 해당 데이터만 추출

**Tool Mode로 Agent와 사용 시:**
- 데이터 변환 없이 **Agent** 컴포넌트의 **Tools** 포트에 직접 연결 가능
- 에이전트가 사용자 쿼리에 따라 URL 컴포넌트 사용 여부 결정
- `DataFrame` 또는 `Message` 출력 직접 처리 가능
