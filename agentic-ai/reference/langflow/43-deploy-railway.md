# Deploy Langflow on Railway

[Railway](https://railway.com/?utm_medium=integration&utm_source=docs&utm_campaign=langflow)에 Langflow 배포.

Railway: 자동 배포, 관리형 데이터베이스, 자동 확장을 제공하는 클라우드 인프라 플랫폼.

## 배포 단계

1. **Railway 계정 생성**

   Railway의 Hobby 계정으로 Langflow의 듀얼 코어 CPU 및 2GB RAM 요구 사항 충족 가능.
   자세한 정보: [Railway 가격](https://railway.com/pricing?utm_medium=integration&utm_source=docs&utm_campaign=langflow)

2. **Railway에 Langflow 템플릿 배포:**

   [![Deploy on Railway](https://railway.app/button.svg)](https://railway.com/new/template/JMXEWp?referralCode=MnPSdg&utm_medium=integration&utm_source=docs&utm_campaign=langflow)

3. **(선택) Langflow 배포에 커스텀 설정 추가**

   Langflow Railway 템플릿이 자동으로:
   - 인프라 설정
   - Langflow 배포
   - 애플리케이션 시작

4. **배포 완료 대기**

5. **배포의 공개 URL에서 Langflow 인스턴스로 이동**

   예: `https://APP-NAME.up.railway.app`

## 장점

- 원클릭 배포
- 자동 인프라 설정
- 관리형 데이터베이스 지원
- 자동 확장
- 간편한 환경 변수 관리
