# Mock Data

테스트 및 개발을 위한 샘플 데이터 생성.

## 출력 타입

| 출력 | 설명 |
|------|------|
| `message_output` | Lorem Ipsum 샘플 텍스트가 포함된 [Message (text)](/data-types#message) 출력 |
| `data_output` | `records`에 하나의 샘플 레코드와 `summary` 섹션이 포함된 JSON 구조의 [Data (JSON)](/data-types#data) 객체 |
| `dataframe_output` | `customer_id`, `first_name`, `last_name` 등의 열이 포함된 50개의 모의 레코드가 있는 [DataFrame (tabular)](/data-types#dataframe) |
