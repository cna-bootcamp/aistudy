# 배포 개요 (Publish Overview)

## 핵심 개요

Dify 애플리케이션은 여러 배포 채널을 통해 자동으로 접근 가능. 플랫폼은 웹 앱, API, 웹사이트 임베드, MCP 서버를 통해
사용자가 생성물을 공유할 수 있도록 지원하며, 각 방법마다 별도 설정 불필요.

## 주요 배포 방법

**웹 애플리케이션**은 가장 빠른 배포 방식을 제공. 애플리케이션 배포 시 설치나 승인 프로세스 없이 즉시 공유 가능한
링크를 제공. 인터페이스는 다양한 디바이스 크기에 자동으로 조정됨.

**API 통합**은 개발자가 사용자 경험과 데이터 관리에 대한 완전한 제어를 유지하면서 기존 제품에 AI 기능을 임베드할 수
있도록 지원. 이 방법은 포괄적인 제품 생태계를 구축하는 팀에 적합.

**웹사이트 임베딩**은 웹 애플리케이션을 모든 웹사이트 플랫폼과 호환되는 배포 가능한 채팅 위젯 또는 인라인 프레임으로
변환.

**MCP 서버 통합**은 Claude Desktop 및 Cursor와 같은 개발 도구에 애플리케이션을 연결하여 전문 개발 환경 내에서
접근성을 확장.

## 구현 가이드

문서는 "모든 배포 방법이 동일한 앱 설정을 사용"하며 모든 배포 채널에서 통합 설정이 이루어짐을 강조. 관리자는 앱 설명,
시각적 브랜딩, 접근 제한, 사용률 제한을 런칭 전에 구성해야 함.

중요 경고사항: 배포는 즉시 라이브 버전을 교체하며, 사용자는 지연 없이 다음 상호작용에서 변경사항을 경험함.

## 선택 프레임워크

조직은 특정 목표에 따라 선택해야 함:
- 웹 앱: 신속한 피드백 검증
- API: 제품 통합
- 임베드: 기존 웹사이트
- MCP 서버: 개발 도구 확장
