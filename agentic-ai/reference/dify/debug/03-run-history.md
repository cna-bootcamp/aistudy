# 실행 이력 (Run History)

## 개요

Dify는 워크플로우 실행에 대한 포괄적인 이력 기록을 유지함.
시스템은 애플리케이션 레벨과 개별 노드 레벨 모두에서 데이터를 캡처함.

## 애플리케이션 레벨 실행 이력

각 워크플로우 실행은 인터페이스를 통해 접근 가능한 완전한 로그 항목을 생성함.
사용자는 세 가지 구분된 섹션을 확인 가능함.

### Result 섹션

사용자에게 표시되는 최종 출력을 표시함.
워크플로우가 실패한 경우 여기에 오류 메시지가 표시됨.
이 기능은 Workflow 애플리케이션에만 적용됨.

### Detail 섹션

원본 입력값, 최종 출력값, 실행 중 생성된 시스템 메타데이터를 제공함.

### Tracing 섹션

워크플로우 실행 흐름에 대한 가시성을 제공함.
다음 정보를 포함함:
- 노드 실행 순서
- 각 노드의 실행 시간
- 노드 간 데이터 흐름

이 기능은 성능 병목 지점을 식별하고 분기 또는 조건부 로직을 포함한 복잡한 워크플로우를 이해하는 데 특히 유용함.

## 개별 노드 모니터링

개발자는 특정 노드의 최근 실행을 노드 구성 패널 내에서 "Last run"을 선택하여 확인 가능함.
다음 정보를 표시함:
- 노드의 입력 데이터
- 출력 결과
- 실행 시간 메트릭
