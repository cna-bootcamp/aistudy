# 단일 노드 실행 (Single Node)

## 개요

Dify의 워크플로우에서 개별 노드를 테스트할 수 있는 기능을 제공함.
개발자는 전체 워크플로우를 게시하기 전에 개별 노드의 기능을 검증 가능함.

## 주요 테스트 기능

### 개별 노드 테스트

사용자는 노드를 선택하여 격리된 환경에서 테스트 가능함.
설정 패널을 통해 테스트 데이터를 입력하고 독립적으로 실행함.
이 방식을 통해 전체 워크플로우를 실행하지 않고도 초기 단계에서 문제 감지 가능함.

### 실행 세부정보 검토

테스트 완료 후 "Last run"을 클릭하면 종합적인 실행 정보 표시됨.
입력값(inputs), 출력값(outputs), 실행 시간(timing), 오류 메시지(error messages) 등을 확인 가능함.

### 변수 캐싱 및 편집

노드가 순차적으로 실행될 때 출력값이 Variable Inspector에 캐싱됨.
캐싱된 데이터를 수정하여 다양한 시나리오 시뮬레이션 가능함.
이전 노드를 반복적으로 재실행할 필요가 없어 테스트 효율성이 향상됨.

### 실행 이력 추적

모든 노드 실행은 기록으로 생성됨.
"Last run" 기능을 통해 최근 실행 세부정보에 접근 가능함.
입력 데이터, 출력 결과, 실행 시간 등을 표시함.

## 제약사항

Answer 노드와 End 노드는 단일 노드 테스트 기능을 지원하지 않음.

## 실무 워크플로우

이 테스트 방식은 개발 프로세스를 간소화함.
개발자는 이전 워크플로우 단계를 매번 재구성하지 않고도 다운스트림 노드가 다양한 데이터 입력에 어떻게 반응하는지 테스트 가능함.
반복적인 작업을 줄이고 디버깅 효율성을 높임.
