# 변수 인스펙터 (Variable Inspector)

## 개요

Variable Inspector는 워크플로우를 통해 이동하는 모든 데이터를 표시하는 진단 도구임.
각 노드 실행 후 입력값과 출력값을 캡처하여 사용자가 작업을 관찰하고 다양한 시나리오를 테스트할 수 있도록 지원함.

## 변수 보기

노드가 작업을 완료하면 출력 변수가 화면 하단의 인스펙터 패널에 표시됨.
개별 변수를 클릭하여 전체 내용을 확인 가능함.

## 변수 편집

대부분의 변수 값은 클릭하여 수정 가능함.
다운스트림 노드가 실행될 때 원래 값 대신 편집된 값을 사용함.
이 기능을 통해 전체 워크플로우를 재실행하지 않고도 다양한 시나리오 테스트 가능함.

**중요 사항**: 인스펙터 내에서 변수를 편집해도 해당 변수를 원래 생성한 노드의 실행 기록은 변경되지 않음.

### 실제 사용 예시

LLM 노드가 `SELECT * FROM users`와 같은 SQL 코드를 생성한 경우:
- 인스펙터에서 `SELECT username FROM users`로 수정 가능
- 데이터베이스 노드만 실행하여 다른 결과 관찰 가능
- 이전 단계를 재실행할 필요 없이 빠른 테스트 진행 가능

## 변수 초기화

각 변수 옆의 되돌리기 아이콘을 클릭하여 개별 변수를 원래 상태로 복원 가능함.
"Reset all"을 클릭하면 캐싱된 모든 변수를 동시에 제거함.
