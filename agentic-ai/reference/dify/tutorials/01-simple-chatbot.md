# 간단한 챗봇 (Simple Chatbot)

## 개요

Dify는 개발자가 신속한 프로토타이핑과 안정적인 배포를 통해 정교한 LLM 기반 애플리케이션을 구축, 구현 및 확장할 수 있도록 지원함.
본 가이드는 사용자 문의를 분류하고 위치별 정보로 응답을 보강하는 챗봇 구축 방법을 설명함.

## 프로젝트 구조

튜토리얼은 총 약 11분 소요되는 3단계 순차 프로세스로 구성됨.

### 1단계: Workflow 생성

사용자는 Studio > Workflow > Create from Blank > Orchestrate > New Chatflow > Create로 이동하여 기본 구조를 설정함.

### 2단계: 노드 구성

**LLM 노드 설정:**

LLM 노드는 언어 모델 요청을 처리함. 구성 방법:
- 노드를 생성하고 Start에 연결
- 기본 모델 선택
- 시스템 프롬프트 구현: 모델이 국가를 식별하고, 질문을 재구성하며, 응답을 구조화된 JSON 형식(국가명, 재구성된 질문, 답변 포함)으로 포맷하도록 지시함
- JSON 스키마 검증과 함께 Structured Output 활성화

**Code 노드 구현:**

Python 기반 코드 블록으로 국가별 정보를 검색함. 국가명을 입력으로 받아 일본, 프랑스, 이탈리아에 대한 미리 정의된 재미있는 사실을 반환하며,
매핑되지 않은 국가에 대해서는 대체 메시지 제공.

**Answer 노드 구성:**

최종 노드로 출력을 사용자 친화적 형식으로 결합함. 원본 질문, LLM의 답변, 해당 재미있는 사실을 표시함.

### 3단계: 테스트

Preview 기능을 통해 다양한 국가에 대한 샘플 쿼리로 기능을 검증함.

## 주요 기능 하이라이트

- `{` 또는 `/` 구문을 통한 변수 참조가 가능한 시각적 workflow 디자인
- 일관되고 기계 판독 가능한 LLM 응답을 위한 구조화된 출력
- 백엔드 인프라 없이 workflow 내에서 커스텀 코드 실행
- 전용 answer 노드를 통한 깔끔한 최종 출력 포맷팅
