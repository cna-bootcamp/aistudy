# Twitter 계정 분석기 (Twitter Account Analyzer)

## 개요

본 가이드는 웹 스크래핑과 LLM 기능을 결합하여 X의 API 제한을 우회하면서 Twitter 계정을 분석하는 chatflow 애플리케이션을 Dify에서 구축하는 방법을 설명함.

## 주요 과제

X는 2023년 2월 무료 API 액세스를 중단하고 크롤링 방지 보호를 강화하여 Jina와 같은 기존 도구로는 Twitter 콘텐츠에 직접 액세스하는 것이 비효율적임.

## 솔루션 아키텍처

애플리케이션은 세 가지 주요 구성 요소 사용:

**설정 요구사항:**
- 소셜 미디어 사이트를 지원하는 데이터 스크래핑 플랫폼인 Crawlbase에 등록
- Docker를 통해 Dify를 로컬에 배포하거나 클라우드 샌드박스 사용(200 무료 크레딧 제공)
- 계정 설정에서 LLM 제공자 구성

**Chatflow 구성 요소:**

1. **Start 노드**: Twitter 사용자 ID를 입력 변수로 수용
2. **Code 노드**: Python을 사용하여 사용자 ID를 완전한 Twitter URL로 변환
3. **HTTP Request 노드**: URL과 인증 토큰(환경 변수로 안전하게 저장)을 사용하여 Crawlbase API 호출
4. **LLM 노드**: 스크랩된 콘텐츠를 분석하고 커스텀 지시사항 실행

## 구현 참고사항

- 보안을 위해 API 자격증명은 평문이 아닌 환경 변수에 저장
- 예제는 사용자의 작성 스타일을 모방하는 콘텐츠 생성을 시연함
- 프로덕션 배포 전 기능 테스트 수행

## 대안

Crawlbase가 합리적인 가격을 제공하는 반면, Tweet Scraper V2(Apify를 통해)와 같은 대체 서비스는 더 높은 비용($49/월)으로
잠재적으로 더 안정적인 결과 제공.
