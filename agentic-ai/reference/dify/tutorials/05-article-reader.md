# 파일 업로드를 이용한 기사 리더 (Article Reader Using File Upload)

## 개요

본 가이드는 파일 업로드 기능을 활용하여 전체 지식 베이스 없이 LLM 컨텍스트를 제공하는
기사 리더 어시스턴트를 Dify에서 구축하는 방법을 설명함.

## 학습 목표

튜토리얼은 다섯 가지 주요 역량을 다룸:
- 파일 업로드 기능 구현
- Chatflow 기초
- 효과적인 프롬프트 구성
- Iteration 노드 적용
- 문서 추출 및 리스트 작업

## 전제 조건

사용자는 구성된 모델 제공자와 적절한 할당량을 갖춘 기존 Chatflow 필요.

## 노드 아키텍처

**Start 노드 구성**

초기 노드는 문서 업로드가 활성화된 파일 변수를 요구함. 시스템은 사용자가 업로드한 콘텐츠에 대한 기본 옵션으로 `sys.files` 제공.
커스텀 파일 변수는 업로드 동작 및 파일 타입 제한에 대한 더 많은 제어 제공.

**문서 추출기 노드 (Document Extractor Node)**

중요한 통찰: "LLM은 파일을 직접 읽을 수 없음." 문서 추출기는 파일 변수를 언어 모델이 분석할 수 있는
처리 가능한 텍스트로 변환함.

**LLM 처리 노드**

두 개의 순차적 LLM 노드가 workflow를 구조화함:

1. **구조 추출 (Structure Extraction)** - 기사 구성을 분석하여 마크다운 포맷을 사용하여
각 섹션의 콘텐츠와 목적을 상세히 설명함.

2. **질문 생성 (Question Generation)** - 구조 분석을 기반으로 독자의 이해를 안내하기 위한
사려 깊은 질문을 생성함.

## 고급 구현

**다중 파일 처리 (Multiple File Handling)**

Iteration 노드는 파일 배열을 순차적으로 처리함. 배치 처리를 활성화하려면
파일 변수가 배열 타입으로 구성되어야 함.

**선택적 파일 처리 (Selective File Processing)**

List operation 노드는 iteration 전에 파일 배열을 필터링하고 정렬하여,
전체 컬렉션이 아닌 특정 파일 타입 또는 정렬된 하위 집합만 처리하는 workflow 가능하게 함.
