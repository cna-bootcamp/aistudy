# AI 이미지 생성 앱 (AI Image Generation App)

## 개요

본 가이드는 개발자가 Dify를 사용하여 AI 이미지 생성 애플리케이션을 구축하는 방법을 설명하며,
에이전트 개발, 프롬프트 엔지니어링 및 도구 통합을 다룸.

## 학습 목표

- 에이전트 구축 방법론
- 기본 에이전트 개념
- 프롬프트 엔지니어링 기초
- 도구 활용
- 대규모 언어 모델 환각(hallucination) 개념

## 설정 단계

### 1. Stability API 키 구성

사용자는 Stability의 API 키 관리 포털로 이동하여 필요시 등록하고, API 키를 복사한 후,
Tools > Stability에 접근하여 Dify 내에서 자격증명을 저장함으로써 권한 부여.

### 2. 모델 제공자 설정

Dify의 무료 플랜에는 200 OpenAI 크레딧 포함. 추가 리소스가 필요한 경우, 무료 LLM 액세스를 제공하는 Groq과 같은
대체 제공자를 구성할 수 있음. 프로세스는 Groq 플랫폼에서 API 키를 생성하고 Dify의 모델 제공자 설정에 추가하는 것을 포함함.

### 3. 에이전트 생성

사용자는 Dify Studio에서 "Create from Blank"를 선택하고, Agent 타입을 선택하며, 프로젝트 이름을 지정함.
에이전트는 "인간 행동을 시뮬레이션하는 AI 시스템"을 나타내며 "다양한 외부 도구와 API를 호출하고 사용하여 작업을 완료"할 수 있음.

## 핵심 구성

**LLM 선택:** 사용자는 언어 모델을 선택함(예: Groq의 Llama-3.1-70B)

**도구 통합 (Tools Integration):** 이미지 생성을 활성화하기 위해 Stability 도구 추가

**프롬프트 작성 (Prompt Writing):** 시스템 지시사항은 에이전트의 동작을 안내함,
예: "stability_text2image를 사용하여 사용자의 프롬프트에 따라 지정된 콘텐츠를 그리세요."

## 프롬프트 엔지니어링 접근 방식

사용자는 시스템 프롬프트를 수동으로 작성하거나 요구사항을 입력하고 Generate를 클릭하여
Dify의 자동 프롬프트 생성 기능을 활용할 수 있음.

## 배포

구축 후, 사용자는 에이전트를 배포하고 생성된 웹 URL을 다른 사람과 공유함.

## 고급 응용

**스타일 지정 (Style Specification):** 시스템 프롬프트에 스타일 선호도 포함(예: "사진은 애니메이션 스타일임")

**요청 필터링 (Request Filtering):** 부적절한 요청을 거부하고 모델 환각 문제를 해결하기 위해
프롬프트에 제약 조건을 사용하거나 콘텐츠 조정 기능 구현
