# Variable Assigner (변수 할당기)

## 개요

Variable Assigner 노드는 대화 변수를 통해 지속적 데이터를 관리하는 Dify의 chatflow 애플리케이션 기능임.
실행 후 재설정되는 workflow 변수와 달리, 대화 변수는 전체 채팅 세션 동안 상태를 유지함.

## 주요 차이점

문서에서는 "Workflow 변수는 단일 workflow 실행 중에만 존재하며 workflow가 완료되면 재설정됨"이라고 설명하는 반면,
대화 변수는 동일한 채팅 내에서 여러 턴에 걸쳐 지속됨.

## 핵심 기능

노드는 세 가지 주요 구성 요소로 여러 변수를 동시에 구성할 수 있음:
- **변수 선택** - 수정할 대화 변수 선택
- **데이터 소스** - 업스트림 workflow 노드를 입력으로 지정
- **작업 모드** - 변수 업데이트 방법 선택

## 지원되는 작업 모드

다양한 데이터 타입이 서로 다른 작업을 지원함:

**String 변수**: 덮어쓰기, 지우기 또는 수동으로 값 설정

**Number 변수**: 덮어쓰기, 지우기, 설정 또는 산술 연산 수행 (덧셈, 뺄셈, 곱셈, 나눗셈)

**Boolean 변수**: 덮어쓰기, 지우기 또는 true/false 값 설정

**Object 변수**: 덮어쓰기, 지우기 또는 수동으로 구조 정의

**Array 변수**: 덮어쓰기, 지우기, 단일 항목 추가, 여러 항목으로 확장 또는 첫 번째/마지막 요소 제거

## 실용적인 응용

문서는 세 가지 구현 패턴을 강조함: 대화 사실을 추출하고 저장하는 지능형 메모리 시스템 구축,
세션 전반에 걸쳐 사용자 기본 설정 유지, 여러 대화 턴에 걸쳐 완료 상태를 추적하는 점진적 체크리스트 생성.
