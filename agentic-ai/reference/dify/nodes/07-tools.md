# Tools (도구)

## 핵심 개념

Tools node는 사전 구축된 커넥터를 통해 workflow와 외부 서비스 및 API의 통합을 가능하게 함.
기본 HTTP Request node와 달리, Tools는 "구조화된 인터페이스, 내장 오류 처리 및 간소화된 구성"을 인기 서비스에 제공함.

## 도구 카테고리

**내장 도구**: "Google Search, 날씨 API, 생산성 도구 및 AI 서비스를 포함한 인기 서비스를 위해
Dify가 관리하는 즉시 사용 가능한 통합."

**사용자 정의 도구**: 사용자는 표준 제공에 포함되지 않은 내부 또는 전문 API를 위해
"OpenAPI/Swagger 사양을 사용하여 자체 도구를 가져올 수" 있음.

**Workflow 도구**: 복잡한 workflow를 "재사용 가능한 도구로 게시"하여 애플리케이션 전반에 걸쳐 모듈식 구성요소를 생성함.

**MCP 도구**: "전문 기능을 제공하는 외부 MCP(Model Context Protocol) 서버의 도구."

## 주요 기능

구성에는 구조화된 인증, 양식 기반 인터페이스를 통한 입력 검증, node 간 데이터 호환성을 보장하는
사전 정의된 출력 스키마가 포함됨.

오류 관리는 구성 가능한 간격으로 자동 재시도(최대 10회 시도)를 지원하며,
외부 서비스 불가용에도 불구하고 workflow 연속성을 유지하면서 도구 실패 시 대체 workflow 경로를 제공함.

## 장점

HTTP 요청과 비교하여, Tools는 타입 안전성, 내장 검증, 자동 오류 처리,
사용 예제가 포함된 포괄적 문서화, workflow 변수를 사용한 간소화된 매개변수 구성을 제공함.

## 관리

도구 자격 증명 및 구성은 작업 공간 Tools 섹션을 통해 중앙에서 관리되며,
인증 설정, 사용자 정의 도구 가져오기, MCP 서버 구성 및 workflow 게시를 지원함.
