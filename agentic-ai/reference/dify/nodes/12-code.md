# Code (코드)

## 개요

Code 노드는 표준 노드로는 불충분할 때 "workflow 내에서 복잡한 데이터 변환, 계산 및 로직을 처리"하기 위한
사용자 정의 Python 또는 JavaScript 실행을 가능하게 함.

## 기본 구성

사용자는 다른 노드의 데이터에 액세스하기 위해 입력 변수를 정의한 다음 코드에서 이를 참조함.
함수는 선언된 출력 변수가 포함된 딕셔너리를 반환해야 함.

## 언어 옵션

Python과 JavaScript 모두 일반적인 라이브러리가 포함된 보안 샌드박스에서 실행됨:

- **Python**: `json`, `math`, `datetime`, `re`를 지원하며 "데이터 분석, 수학 연산 및 텍스트 처리"에 적합
- **JavaScript**: 표준 내장 객체 및 메서드를 제공하며 JSON 조작 및 문자열 작업에 이상적

## 오류 관리

시스템은 두 가지 보호 메커니즘을 제공함: 자동 재시도(최대 5000ms까지 구성 가능한 간격으로 최대 10회)와
코드 실패 시 대체 경로를 통해 오류에도 불구하고 workflow를 계속할 수 있음.

## 출력 제약

모든 출력은 엄격한 유효성 검사 제한을 받음: 문자열은 80,000자로 제한, 숫자는 -999999999에서 999999999 범위로 제한,
중첩 구조는 5레벨 깊이로 제한됨.

## 보안 프레임워크

코드는 파일 시스템 액세스, 네트워크 요청 및 시스템 명령을 차단하는 격리된 샌드박스에서 실행됨.
코드가 저장되지 않으면 문서에서 "보안 필터가 잠재적으로 위험한 작업을 차단하고 있을 수 있음"을 언급함.

## 종속성

두 언어 모두 샌드박스 환경에 사전 설치된 외부 패키지를 지원함
(Python의 경우 numpy, pandas, requests; JavaScript의 경우 lodash, moment).

## 자체 호스팅 배포

자체 호스팅 설치는 격리된 코드 실행을 위해 Docker Compose를 통해 샌드박스 서비스를 시작해야 함.
