# Question Classifier (질문 분류기)

## 개요

Question Classifier node는 LLM 기능을 활용하여 사용자 입력을 지능적으로 분류하고
대화를 다양한 workflow 경로로 안내하며, 복잡한 조건부 로직의 필요성을 제거함.

## 핵심 기능

"사용자 입력을 지능적으로 분류하여 대화를 다양한 workflow 경로로 라우팅함."
시스템은 의미적 이해를 사용하여 사용자 쿼리를 사전 정의된 카테고리에 매칭하며,
각 카테고리는 고유한 출력 경로로 기능함.

## 구성 요구사항

**입력 설정:** 분류할 텍스트 변수를 선택함, 일반적으로 사용자 질문의 경우 `sys.query`이지만
이전 node의 모든 텍스트 변수가 작동함.

**모델 선택:** 언어 모델의 선택은 분류 정확도에 영향을 미침—
더 간단한 모델은 직관적인 카테고리에 적합하며 고급 모델은 미묘한 구별을 더 잘 처리함.

**카테고리 생성:** 관리자는 각 그룹에 속하는 것을 정의하는 구체적인 설명과 함께
명확하고 설명적인 카테고리 레이블을 설정함. 카테고리 간의 정확한 경계 정의가 LLM 정확도를 향상시킴.

## 실제 적용

고객 서비스 예시는 세 가지 카테고리를 보여줌: "애프터 서비스" (보증, 반품, 수리),
"제품 사용" (설정, 문제 해결, 기능), "기타 질문" (일반 문의).
샘플 분류는 보증 질문을 애프터 서비스 리소스로 라우팅하고 설정 질문은 제품 지식 베이스로 전달함.

## 고급 기능

Instructions 필드는 엣지 케이스 처리, 모호한 시나리오 및 특정 비즈니스 요구사항을 위한
상세한 분류 가이드라인을 수용하여 LLM이 미묘한 카테고리 구별을 인식할 수 있도록 함.
