# User Input (사용자 입력)

## 개요

User Input node는 애플리케이션이 최종 사용자로부터 정보를 수집할 수 있도록 하며, workflow 및 chatflow 애플리케이션의 시작점으로 기능함.
이러한 애플리케이션은 온디맨드 방식으로 작동하며 직접적인 사용자 상호작용 또는 API 호출을 통해 실행 가능함.
독립형 웹 앱, MCP 서버, 백엔드 서비스 API 또는 다른 Dify 애플리케이션 내의 도구로 배포 지원.

## 주요 제약사항

"각 애플리케이션 캔버스는 하나의 User Input node만 포함 가능."

## 사전 정의 변수

두 개의 시스템 정의 변수가 자동으로 제공됨:

- **userinput.files**: 사용자가 업로드한 파일 캡처 (workflow용 레거시; 사용자 정의 파일 입력 권장)
- **userinput.query**: chatflow 애플리케이션에서 사용자의 최신 채팅 턴에서 텍스트를 자동 캡처

## 사용자 정의 입력 필드 유형

**텍스트 옵션:**
- 짧은 텍스트 (최대 256자)
- 단락 (무제한 멀티라인 텍스트)

**구조화된 데이터:**
- 선택 (드롭다운 메뉴)
- 숫자 (숫자 값만)
- 체크박스 (이진 true/false 값)
- JSON 코드 (선택적 스키마 검증을 포함한 복잡한 중첩 구조)

**파일 처리:**
- 단일 파일 업로드
- 파일 목록 (여러 파일 동시 업로드)

## 파일 처리 관련 중요 사항

"User Input node는 파일을 수집하기만 하며 내용을 읽거나 파싱하지 않음."
후속 node에서 처리를 담당해야 함: 문서의 경우 Doc Extractor, 이미지의 경우 LLM vision node, CSV/JSON 같은 구조화된 데이터의 경우 Code node.
