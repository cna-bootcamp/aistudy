# Knowledge Retrieval (지식 검색)

## 개요

Knowledge Retrieval node는 사용자 쿼리와 관련된 정보를 검색하고 결과를 LLM 같은 다운스트림 node로 전달하여
기존 지식 베이스를 Chatflow 또는 Workflow에 통합함.

## 기본 Workflow

일반적인 구현은 네 단계를 따름: 사용자 입력 수집, 지식 베이스 검색, 쿼리와 검색된 콘텐츠를 모두 사용한 LLM 응답 생성,
사용자에게 답변 전달.

## 전제조건

이 node를 사용하기 전에 최소 하나의 지식 베이스가 존재해야 함.
Dify Cloud 배포는 구독 플랜에 따른 속도 제한이 있음.

## 구성 요구사항

node는 세 가지 사양이 필요함:

**쿼리 정의**: 사용자 업로드의 텍스트 변수(`userinput.query` 등) 또는 이미지 변수를 선택함.
이미지 파일은 2 MB로 제한됨. 이미지 쿼리는 Vision 아이콘으로 표시된 "멀티모달 지식 베이스"에서만 작동함.

**지식 베이스 선택**: 하나 이상의 기존 지식 베이스를 추가함.
여러 베이스를 동시에 검색한 후 node 수준 설정에 따라 결합함.
Vision 표시 베이스는 텍스트와 이미지의 교차 모달 검색을 지원함.

**검색 처리**: Node 수준 설정 포함:
- 가중 점수 (의미적 유사성과 키워드 매칭의 균형)
- Rerank 모델 (관련성에 따른 결과 재점수화; 이미지가 있는 경우 멀티모달 모델 필요)
- Top K (최대 반환 결과 수)
- 점수 임계값 (포함을 위한 최소 유사도 점수)

## 고급 기능

**메타데이터 필터링**: 문서 메타데이터를 통해 전체 컬렉션을 검색하지 않고
대규모 지식 베이스 내 특정 문서 내에서 타겟팅된 검색 가능, 정밀도 향상.

## 출력 및 통합

node는 콘텐츠, 메타데이터 및 제목이 포함된 문서 청크 배열을 포함하는 `result` 변수를 출력함.
이미지 첨부 파일은 `files` 필드에 표시됨.

LLM 통합의 경우 Context 필드에서 `result` 변수를 참조하고 프롬프트에서 컨텍스트와 사용자 입력을 모두 언급함.
Vision 가능 LLM을 활성화하여 검색된 이미지를 자동으로 처리 가능.
