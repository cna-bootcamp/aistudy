# Template (템플릿)

## 개요

Template 노드는 Jinja2 템플릿을 활용하여 여러 소스의 데이터를 구조화된 텍스트로 변환하고 형식화함.
이 노드는 변수 결합, 출력 형식화 및 다운스트림 프로세스 또는 사용자 전달을 위한 데이터 준비를 가능하게 함.

## 핵심 기능

**변수 대체**: `{{ variable_name }}` 구문을 사용하여 workflow 변수에 액세스하며,
점 표기법 및 대괄호 액세스를 통한 중첩 속성 및 배열 요소 포함.

**조건부 로직**: if-else 문을 사용하여 데이터 조건에 따라 콘텐츠를 표시하는 분기 로직 구현.
예: 사용자 구독 상태를 확인하여 차별화된 메시징 표시.

**반복 처리**: for 루프를 사용하여 배열 및 객체를 처리하고 반복되는 콘텐츠 구조 생성.
시스템은 `loop.index`와 같은 루프 메타데이터에 대한 액세스를 제공함.

## 데이터 변환 기능

**필터링**: Jinja2 필터를 적용하여 데이터 수정—대문자 변환, 숫자 반올림, 문자열 대체, 날짜 형식화 및
데이터가 없을 때 기본값 할당.

**오류 관리**: 기본값 및 조건부 검사를 통해 누락되거나 잘못된 데이터를 우아하게 처리하여
불완전한 정보로 인한 workflow 실패 방지.

## 대화형 폼

템플릿은 채팅 인터페이스 데이터 수집을 위한 HTML 폼을 생성할 수 있음.
폼은 텍스트 입력, 선택 드롭다운, 텍스트 영역, 체크박스 및 버튼을 지원함.
사용자 제출은 다운스트림 노드 처리에 자동으로 사용 가능한 구조화된 JSON으로 변환됨.

## 제약

템플릿 출력은 **80,000자**로 제한되며, 메모리 문제 방지 및 처리 효율성 유지를 위해
환경 변수를 통한 구성이 가능함.
