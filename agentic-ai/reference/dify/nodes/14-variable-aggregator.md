# Variable Aggregator (변수 집계기)

## 개요

Variable Aggregator 노드는 Dify workflow에서 병합 지점 역할을 하며,
여러 실행 분기의 출력을 다운스트림 노드가 일관되게 참조할 수 있는 단일 통합 변수로 결합함.

## 해결되는 핵심 문제

조건부 workflow는 자연스럽게 한 번에 하나의 분기만 실행되는 병렬 실행 경로를 생성함.
"집계 없이는 각 가능한 분기 결과에 대해 중복 다운스트림 노드가 필요하여 복잡하고 유지 관리가 어려운 workflow가 생성됨."
집계기는 이러한 중복을 제거하여 분기 결과를 통합함.

## 주요 사용 사례

**분류 Workflow:** 사용자 입력이 분류되고 각 카테고리가 다른 지식 검색을 요구할 때,
집계기는 모든 분류 분기의 결과를 하나의 출력 변수로 결합하여 중복 처리 노드의 필요성을 줄임.

**조건부 분기:** 유사한 출력을 생성하는 If-Else 구조는 집계의 이점을 동일하게 받아
"각 분류 분기에 대해 중복하는 대신 하나의 LLM 노드"를 허용함.

## 구성 요구사항

**타입 일관성:** 모든 집계된 변수는 동일한 데이터 타입을 공유해야 함.
지원되는 타입에는 String, Number, Object, Boolean 및 Array가 포함됨.
첫 번째 변수를 연결하면 노드는 다른 분기에서 일치하는 타입만 허용함.

**실행 로직:** 집계기는 실행 중에 실제로 생성된 값을 출력함.
workflow 인스턴스당 하나의 분기만 실행되므로 런타임에 하나의 입력 변수만 값을 포함함.

## 고급 기능

버전 0.6.10 이상을 사용하는 workflow는 여러 집계 그룹을 동시에 지원하며,
각 그룹은 별도의 타입 제약을 유지하여 단일 노드 내에서 다양한 데이터 타입의 병렬 집계를 가능하게 함.
