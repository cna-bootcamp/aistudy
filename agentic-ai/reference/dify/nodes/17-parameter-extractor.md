# Parameter Extractor (파라미터 추출기)

## 개요

Parameter Extractor 노드는 LLM 기능을 활용하여 비구조화된 텍스트를 구조화된 데이터로 변환함.
이는 자연어 입력과 도구, API 및 workflow 구성 요소에 필요한 형식화된 파라미터 간의 다리 역할을 함.

## 주요 구성 단계

**입력 및 모델 설정**
처리할 텍스트가 포함된 입력 변수를 선택하며, 일반적으로 사용자 제출, LLM 출력 또는 업스트림 노드에서 가져옴.
강력한 구조화된 출력 능력을 보여주는 모델을 선택함.

**파라미터 사양**
다음을 설정하여 추출 대상을 정의함:
- 파라미터 식별자
- 데이터 분류 (string, number, boolean, array, object)
- LLM에 대한 설명 컨텍스트
- 필수 필드 지정

사용자는 파라미터를 수동으로 정의하거나 "기존 도구에서 빠르게 가져와" 다운스트림 노드 요구 사항에 맞출 수 있음.

**추출 지침**
정보 검색 및 형식화에 대한 자세한 지침을 제공함.
지침 내에 예제를 포함하면 복잡한 파라미터 처리에 대한 정확도가 강화됨.

## 고급 옵션

**처리 방법**
Function Call/Tool Call 접근 방식은 신뢰할 수 있는 추출을 위해 모델의 구조화된 출력 기능을 활용함.
Prompt 기반 방법은 함수 호출 지원이 부족하거나 기존 프롬프트로 더 나은 성능을 보이는 모델에 적합함.

**컨텍스트 메모리**
메모리 통합을 활성화하면 대화 기록이 통합되어 대화형 시나리오에서 LLM의 컨텍스트 이해가 향상됨.

## 출력 구조

추출된 파라미터는 다운스트림 사용을 위한 개별 변수가 됨.
내장 상태 표시기에는 `__is_success` (성공 확인) 및 `__reason` (실패 설명)이 포함됨.
