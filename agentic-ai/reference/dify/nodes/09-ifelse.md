# If-Else (조건 분기)

## 개요

If-Else node는 조건부 분기를 통해 workflow에 의사결정 기능을 활성화함.
변수를 평가하여 workflow가 따라야 할 실행 경로를 결정함.

## 분기 구조

node는 세 가지 주요 경로를 지원함: "IF 경로는 기본 조건이 true로 평가될 때 실행됨,"
초기 조건이 실패할 때 순차적 조건 확인을 위한 ELIF 경로,
그리고 조건이 일치하지 않을 때 기본 대체 경로인 ELSE 경로.

## 사용 가능한 조건

여러 조건 유형을 구성 가능함:

**텍스트 기반 작업**에는 값이 특정 구문을 포함하는지, 특정 텍스트로 시작하거나 끝나는지,
또는 정확히 일치하는지 확인하는 것이 포함됨.

**값 평가**는 비어 있음 테스트, 숫자 비교(보다 크거나 작음) 및 모든 데이터 유형에 걸친 동일성 매칭을 포함함.

## 고급 로직

조건은 AND/OR 연산자를 사용하여 결합 가능함.
"AND 로직은 모든 조건이 true여야 함"을 동시 기준이 필요한 경우에 요구하며,
OR 로직은 다양한 시나리오에 걸쳐 단일 조건이 충족될 때 트리거됨.

## 실제 구현

사용자 입력, LLM 출력 및 API 응답을 포함한 이전 workflow node의 변수를 조건에서 참조 가능함.
인터페이스는 변수 통합을 위해 변수 선택기 도구와 `{{variable_name}}` 형식을 사용한 직접 구문 지원을 모두 제공함.
