# List Operator (리스트 연산자)

## 목적 및 기능

List Operator 노드는 특정 요소를 필터링, 정렬 및 선택하여 배열을 처리함.
"대부분의 workflow 노드는 배열이 아닌 단일 값을 기대함" 상황을 처리하도록 설계됨.
이 도구는 `array[string]`, `array[number]`, `array[file]` 및 `array[boolean]` 입력 타입을 지원함.

## 해결하는 핵심 문제

workflow에 단일 변수에 이미지, PDF 및 오디오 파일과 같은 혼합 콘텐츠가 포함된 경우,
List Operator는 "혼합 배열을 분리하고 전문 처리를 위해 준비하는" 지능형 라우터 역할을 함.

## 주요 작업

**필터링** 기능에는 다음이 포함됨:
- 콘텐츠 분류 (이미지, 문서, 오디오, 비디오)
- MIME 타입 식별
- 파일 확장자 매칭
- 크기 제약 및 파일 이름 패턴
- 업로드와 URL 간의 전송 방법 구분

**정렬**은 모든 속성별로 오름차순 또는 내림차순으로 결과를 정렬함.

**선택** 옵션에는 다음이 포함됨:
- "Take First N" (1-20개 항목)
- First Record (단일 요소)
- Last Record (단일 요소)

## 출력 변수

노드는 세 가지 출력을 생성함: 완전히 필터링된 배열(`result`), 초기 요소(`first_record`) 및
최종 요소(`last_record`).

## 실용적인 응용

일반적인 사용 사례는 혼합 파일 업로드를 수락하고, 이미지를 비전 지원 LLM으로 라우팅하는 동시에
문서를 텍스트 추출 도구로 보낸 다음, 통합 응답을 위해 결과를 결합하는 것을 포함함.
