# Iteration (반복)

## 핵심 기능

Iteration node는 항목을 개별적으로 처리하는 대신 순차적 또는 병렬로 배열의 각 요소에
workflow 단계를 적용하여 일괄 처리를 가능하게 함.

## 주요 구성요소

- **입력 변수**: Parameter Extractor, Code node, Knowledge Retrieval 또는 HTTP 요청과 같은 업스트림 소스의 배열 데이터
- **내부 Workflow**: 각 요소에 실행되는 처리 단계
- **출력 변수**: 배열로 형식화된 수집된 결과

## 사용 가능한 내장 변수

처리 중에 각 반복은 다음에 대한 액세스를 제공함:
- `items[object]` - 현재 처리 중인 요소
- `index[number]` - 현재 반복 위치 (0부터 시작)

## 처리 모드

**순차 모드**: 항목이 순서대로 하나씩 처리됨, 점진적 스트리밍 출력 지원 및 메모리 소비 감소.
순서가 중요하거나 스트리밍이 필요할 때 이상적.

**병렬 모드**: 독립적인 작업의 더 빠른 실행을 위해 최대 10개 항목을 동시에 처리함.
순서가 중요하지 않은 대규모 배열에 권장.

## 오류 관리 옵션

- **종료**: 오류 발생 시 즉시 중지
- **오류 시 계속**: 실패 건너뛰기, 문제 항목에 대해 null 출력
- **실패 결과 제거**: 출력에서 실패를 완전히 제외

## 실제 적용

문서는 Iteration node를 통해 장 개요를 개별적으로 처리하는 장문 기사 생성 예제를 포함하며,
결과는 Answer node를 통해 "생성되는 대로 스트리밍됨."

## 출력 변환

배열 결과는 일반적으로 join 작업이 있는 Code node 또는
텍스트 생성을 위한 Jinja2 구문이 있는 Template node를 사용한 변환이 필요함.
