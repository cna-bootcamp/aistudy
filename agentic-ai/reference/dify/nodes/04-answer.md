# Answer (응답)

## 목적 및 가용성

Answer node는 Dify의 Chatflow 애플리케이션을 위한 응답 전달 메커니즘으로 기능함.
문서에 명시된 바와 같이 "Answer node는 Chatflow 애플리케이션에서만 사용 가능함.
Workflow 애플리케이션은 대신 End node를 사용함."
이 node는 응답 형식을 지정하고 텍스트와 동적 변수를 결합하여 개인화된 사용자 상호작용을 생성할 수 있도록 함.

## 콘텐츠 구성 기능

정적 텍스트, 동적 변수 및 하이브리드 콘텐츠를 수용하는 유연한 텍스트 편집기를 통해 응답을 구성함.
시스템은 `{{variable_name}}` 구문을 사용하여 이전 workflow node의 출력을 참조하며,
풍부한 형식 및 컨텍스트 개인화를 지원함.

## 멀티모달 콘텐츠 지원

Answer node는 통합 응답 스트림에서 다양한 콘텐츠 유형을 처리함:

- **텍스트 콘텐츠**: 변수 대체, 마크다운 형식 및 동적 생성 콘텐츠 지원
- **이미지 콘텐츠**: 도구 출력, 사용자 업로드 또는 처리된 workflow 결과의 이미지 표시
- **파일 콘텐츠**: workflow 실행 중 생성된 문서 및 처리된 파일 전달

## 스트리밍 메커니즘

콘텐츠 전달은 "node가 첫 번째 미해결 변수까지 모든 콘텐츠를 출력한 다음 해당 변수가 해결될 때까지 기다린 후 계속 진행하는"
점진적 모델을 따름.
Answer node 내의 변수 순서(업스트림 실행 순서가 아님)가 스트리밍 패턴을 결정하며,
콘텐츠 일관성을 유지하면서 반응형 상호작용을 가능하게 함.

## 여러 Node 및 변수 통합

Chatflow는 서로 다른 처리 단계에서 여러 Answer node를 수용함.
node는 LLM 응답, 지식 검색 시스템, 도구 통합 및 파일 처리 작업의 출력을 통합하며 타입 안전성을 유지함.
