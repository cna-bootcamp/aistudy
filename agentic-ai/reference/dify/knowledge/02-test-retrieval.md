# 검색 테스트 (Test Retrieval)

## 주요 내용

이 페이지는 Dify에서 지식 베이스 검색 기능을 테스트하는 방법을 설명함. 사용자는 왼쪽 사이드바의 **검색 테스트(Retrieval
Testing)** 아이콘을 클릭하여 테스트 기능에 액세스 가능.

## 주요 기능

**테스트 기능:** 테스트 페이지는 사용자가 "사용자 쿼리를 시뮬레이션하여 지식 베이스가 관련 정보를 얼마나 잘 검색하는지
테스트하고 최적의 성능을 위해 다양한 검색 설정을 실험"할 수 있도록 함.

**중요 참고 사항:** 테스트 세션 중에 수정된 검색 설정은 임시적이며 현재 테스트에만 영향을 미치고 영구 구성에는 영향을
미치지 않음.

## 기록 섹션

시스템은 지식 베이스와 관련된 모든 검색 활동에 대한 포괄적인 로그를 유지 관리하며, 다음을 포함:

* 테스트 페이지에서 직접 실행된 쿼리
* 테스트 실행 및 실제 프로덕션 사용 중에 연결된 애플리케이션에 의해 트리거된 검색 요청

## 기술 세부 사항

테스트 검색과 표준 검색은 동일한 API 엔드포인트를 통해 작동하여 테스트 및 프로덕션 환경 전반에 걸쳐 일관성을 보장함.

## 관련 리소스

이 페이지는 인덱싱 방법 가이드를 통한 검색 설정 구성에 대한 추가 문서를 참조하며, 사용 가능한 모든 리소스를 찾기 위해
https://docs.dify.ai/llms.txt에서 제공되는 전체 문서 색인으로 사용자를 안내함.
