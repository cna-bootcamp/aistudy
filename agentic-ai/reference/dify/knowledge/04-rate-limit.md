# 지식 요청 속도 제한 (Knowledge Request Rate Limit)

## 개요

Dify Cloud의 지식 요청 속도 제한은 워크스페이스가 분당 수행할 수 있는 최대 지식 베이스 작업 수를 제한하며, 데이터셋 생성,
문서 관리, 앱/워크플로 쿼리를 포함함.

## 구독 계층별 제한

속도 제한은 구독 수준에 따라 달라짐:
- **샌드박스(Sandbox)**: "10/분"
- **프로페셔널(Professional)**: "100/분"
- **팀(Team)**: "1,000/분"

제한에 도달한 사용자는 다음 1분 동안 임시 제한에 직면함. 예를 들어, 60초 이내에 10번의 히트 테스트를 실행한 샌드박스
사용자는 일시적으로 제한된 작업에 대한 차단된 액세스를 경험함.

## 제한 대상 작업

다음 18가지 활동이 속도 제한을 트리거함:

1. 빈 데이터셋 생성
2. 데이터셋 삭제
3. 데이터셋 설정 업데이트
4. 문서 업로드
5. 문서 삭제
6. 문서 업데이트
7. 문서 비활성화
8. 문서 활성화
9. 문서 아카이브
10. 아카이브된 문서 복원
11. 문서 처리 일시 중지
12. 문서 처리 재개
13. 세그먼트 추가
14. 세그먼트 삭제
15. 세그먼트 업데이트
16. 세그먼트 대량 가져오기
17. 히트 테스트 수행
18. 앱 또는 워크플로에서 지식 쿼리(다중 경로 리콜은 단일 요청으로 계산됨)
