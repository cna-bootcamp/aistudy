# 앱 관리 (Manage Apps)

## 개요

효과적인 애플리케이션 관리는 생산적인 AI 개발에 필수적임.
Dify는 애플리케이션의 전체 수명 주기에 걸쳐 구성, 공유, 유지 관리를 위한 도구 제공.

## 앱 구성 기능

플랫폼이 제공하는 네 가지 핵심 관리 기능:

1. **Edit & Customize**: 더 나은 구성을 위해 이름, 설명, 아이콘, 브랜딩 요소 수정
2. **Duplicate & Template**: 변형 생성 또는 기존 앱을 새 프로젝트의 템플릿으로 활용
3. **Import & Export**: Dify의 DSL 형식을 사용하여 워크스페이스 간 애플리케이션 공유
4. **Lifecycle Management**: 더 이상 필요하지 않은 앱 안전하게 제거

## 애플리케이션 정보 편집

앱 세부 정보 업데이트를 위해 왼쪽 상단의 설정 메뉴에 접근하여 "Edit info" 선택.
그런 다음 앱의 목적을 더 잘 전달하기 위해 아이콘, 이름 또는 설명 수정 가능.
문서는 상태를 나타내기 위해 "Draft-", "Test-", "Prod-" 같은 접두사를 사용하는
일관된 명명 규칙 사용 권장.

## 앱 변형 생성

앱 복제는 다음 용도에 적합:

- 다른 프롬프트 또는 모델을 사용한 A/B 테스트
- 다른 대상에 맞춘 애플리케이션 조정
- 검증된 패턴에서 새 프로젝트 시작
- 중대한 변경 전 백업 생성

복제 시 모든 설정, 프롬프트, 워크플로 복사되며,
원본은 변경되지 않고 두 앱은 독립적으로 작동함.

## 앱 내보내기 및 가져오기

### 내보내기

애플리케이션은 Studio 페이지 또는 오케스트레이션 인터페이스에서 DSL 파일로 내보내기 가능.
내보내기에는 설정, 워크플로 설정, 모델 매개변수, 지식 베이스 연결이 포함되지만,
API 키, 지식 베이스 콘텐츠, 분석 데이터는 제외됨.
시스템은 비밀 환경 변수 포함 여부에 대해 사용자에게 프롬프트 표시.

### 가져오기

사용자는 YAML 형식의 DSL 파일을 업로드하고, 시스템이 버전 호환성 검증.
SaaS 사용자는 최신 버전을 받으며,
커뮤니티 사용자는 호환성을 위해 업그레이드가 필요할 수 있음.

## 안전한 앱 삭제

삭제는 영구적이며 되돌릴 수 없음.
프로세스는 모든 설정, 워크플로, 사용 로그, 사용자 접근 권한 제거.
게시된 웹 앱은 즉시 작동 중지되고 API 호출은 오류 반환.
문서는 백업을 위한 복제 또는 삭제 대신 게시 취소와 같은 대안 고려 권장.
