# 플러그인 (Plugins)

## 개요

플러그인은 Dify 워크스페이스 기능을 확장하는 모듈형 컴포넌트로,
Dify와 모델 프로바이더, API, 커스텀 도구를 포함한 외부 시스템 간 연결 지점으로 기능함.
일단 설치되면 플러그인은 전체 워크스페이스에서 사용 가능함.

## 핵심 기능

플러그인은 Dify가 모든 것(모델 프로바이더, 외부 API, 커스텀 도구)에 연결되는 방법임.
시스템은 다양한 컴포넌트를 플러그인으로 취급하며,
모든 언어 모델 프로바이더(OpenAI, Anthropic 등), 도구 통합, API 엔드포인트 포함.

## 접근 권한

워크스페이스 범위에 따라 플러그인 사용 결정:

- **Owner/Admin**: 플러그인 설치, 설정, 제거
- **Editor/Member**: 이미 설치된 플러그인을 애플리케이션에서 사용

## 설치 방법

플러그인 추가를 위한 세 가지 접근 방식:

1. **Marketplace**: 공식 및 파트너 테스트 완료 플러그인
2. **GitHub**: URL 및 버전을 사용한 공개 저장소
3. **Local Upload**: 비공개 사용을 위한 커스텀 .zip 패키지

## 설정 요구사항

대부분의 플러그인은 설치 후 설정 필요.
워크스페이스 전체에 적용되는 API 키, 엔드포인트 또는 서비스 설정 포함.

## 워크스페이스 설정

관리자가 제어할 수 있는 항목:

- 설치 권한 (모든 사용자 vs. admin 전용)
- 디버그 접근 권한
- 포함/제외 옵션이 있는 자동 업데이트 전략

## 엔터프라이즈 제한사항

엔터프라이즈 워크스페이스는 승인된 소스 및 플러그인 유형에 관한
admin 정책에 따라 플러그인 설치 제한 경험 가능.

## 커스텀 플러그인 개발

개발자는 Dify SDK를 사용하여 플러그인 빌드 가능.
디버깅 키, 로컬 테스트, .zip 패키징, 선택적 마켓플레이스 게시 필요.
