# 개인 설정 (Personal Settings)

## 개요

개인 계정은 여러 워크스페이스에 걸쳐 존재하며 일관된 프로필 설정 유지.
각 워크스페이스는 자체 팀 역학 및 권한을 가지고 독립적으로 운영됨.

## 계정 설정

Dify Cloud는 GitHub, Google 또는 이메일 인증을 통한 첫 로그인 시 자동으로 계정 생성.
동일한 이메일을 공유하는 계정은 자동으로 통합됨.
Community Edition은 설치 중 수동 이메일 및 비밀번호 설정 필요하며,
초기 배포 시 관리자 계정 설정됨.

## 다중 워크스페이스 접근

사용자는 동시에 여러 워크스페이스에 속할 수 있음.
왼쪽 상단의 워크스페이스 선택기를 통해 접근 가능한 워크스페이스 간 전환 가능.
중요사항: 역할 및 권한은 워크스페이스별로 설정됨.
한 워크스페이스에서는 Owner이고 다른 워크스페이스에서는 Member일 수 있음.

## 프로필 관리

프로필 업데이트는 Settings → Account → Profile에서 발생하며 모든 워크스페이스에 적용됨.
사용자는 다음 작업 가능:

- 커스텀 아바타 업로드
- 팀 식별을 위한 표시 이름 설정
- 기본 이메일 로그인 자격 증명 관리

## 언어 및 인터페이스

시스템은 영어, 중국어 간체, 중국어 번체 지원.
언어 설정은 인터페이스 요소에 영향을 주지만 애플리케이션 콘텐츠에는 영향 없음.
사용자는 아바타 메뉴를 통해 조정 가능.

## 로그인 방법

- **Community Edition**: 이메일 및 비밀번호만 지원
- **Cloud Edition**: GitHub, Google, 인증 코드가 있는 이메일 제공

시스템은 일치하는 이메일 주소를 가진 Cloud 계정을 자동으로 연결.

## 보안 고려사항

Cloud 사용자는 소셜 로그인 프로바이더의 보안 기능 활용 권장.
Community Edition 사용자는 강력하고 고유한 비밀번호 유지 필요.
경고: 이메일 주소 변경은 모든 워크스페이스에 영향을 미치며,
워크스페이스별 변경을 위해서는 별도의 계정 초대 필요.
