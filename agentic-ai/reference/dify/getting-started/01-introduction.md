# 소개 (Introduction)

Dify는 에이전틱 워크플로우를 구축하기 위한 오픈소스 플랫폼임.
프로세스를 시각적으로 정의하고, 기존 도구 및 데이터 소스를 연결하며,
실제 문제를 해결하는 AI 애플리케이션을 배포할 수 있음.

## 주요 링크

| 항목 | 설명 |
|------|------|
| 빠른 시작 | 몇 분 만에 강력한 앱 배포 가능 |
| 핵심 개념 | Dify의 핵심 구성 요소 설명 |
| 셀프 호스팅 | 자체 노트북/서버에 Dify 배포 |
| 포럼 | 커뮤니티와 정보 교환 |
| 변경 이력 | 이전 릴리스의 변경 사항 |
| 튜토리얼 | Dify 사용 사례 안내 |

> Dify라는 이름은 "Do It For You"에서 유래함.
