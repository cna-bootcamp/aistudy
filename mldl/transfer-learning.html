🔧 Fine-tuning 전략

📊 데이터 양과 유사도에 따른 전략

데이터 양 도메인 유사도 권장 전략 조정 범위
적음 (<1000) 높음 출력층만 학습 마지막 분류 헤드만
적음 (<1000) 낮음 상위층 + 출력층 상위 2-3개 블록 + 헤드
보통 (1000-10000) 높음 상위 절반 미세조정 상위 50% 블록
보통 (1000-10000) 낮음 전체 미세조정 (작은 LR) 모든 블록 (1e-5 이하)
많음 (>10000) 높음/낮음 전체 미세조정 모든 블록

🎛️ 인터랙티브 조정 시뮬레이터

동결 레이어 수 6 / 12
학습률 (Learning Rate) 2e-5
배치 크기 16
📋 추천 설정

🔹 학습 가능 파라미터: ~55M (전체의 50%)

🔹 예상 VRAM: ~8GB

🔹 권장 에폭: 3-5

🔹 예상 학습 시간: ~2시간 (1만 샘플, V100 기준)

⚡ 파라미터 효율적 미세조정 (PEFT)

🔗 LoRA
Low-Rank Adaptation. 원본 가중치는 동결하고 작은 랭크의 행렬만 학습. 전체의 0.1-1%만 학습.
메모리 효율 빠른 학습
🔌 Adapter
각 레이어 사이에 작은 어댑터 모듈 삽입. 어댑터만 학습하고 원본은 동결.
모듈형 멀티태스크
📍 Prefix Tuning
학습 가능한 프리픽스 토큰을 입력에 추가. 모델 전체는 동결하고 프리픽스만 학습.
생성 태스크 경량
💬 Prompt Tuning
소프트 프롬프트를 입력 앞에 추가. 프롬프트 임베딩만 학습.
초경량 대규모 모델
⚠️ 주의사항
  • 학습률이 너무 크면 사전학습 지식이 손상됨 (Catastrophic Forgetting)
  • 데이터가 적을 때 전체 미세조정하면 과적합 위험
  • 배치 크기가 너무 작으면 학습이 불안정해질 수 있음

💻 실전 Fine-tuning 코드

🎯 인코더 모델 (BERT) Fine-tuning

from transformers import BertForSequenceClassification, BertTokenizer, Trainer, TrainingArguments

# 1. 모델 로드
model = BertForSequenceClassification.from_pretrained(
    "bert-base-uncased",
    num_labels=2
)
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

# 2. 하위 6개 레이어 동결
for name, param in model.named_parameters():
    if "encoder.layer" in name:
        layer_num = int(name.split(".")[3])
        if layer_num < 6:  # 0-5번 레이어 동결
            param.requires_grad = False

# 3. 동결된 파라미터 확인
trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
total = sum(p.numel() for p in model.parameters())
print(f"학습 가능: {trainable:,} / 전체: {total:,} ({trainable/total*100:.1f}%)")

# 4. 학습 설정
training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=16,
    learning_rate=2e-5,
    warmup_steps=500,
    weight_decay=0.01,
)

# 5. 학습 실행
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
)
trainer.train()

🚀 디코더 모델 (GPT-2) Fine-tuning

from transformers import GPT2LMHeadModel, GPT2Tokenizer

# 1. 모델 로드
model = GPT2LMHeadModel.from_pretrained("gpt2")
tokenizer = GPT2Tokenizer.from_pretrained("gpt2")

# 패딩 토큰 설정 (GPT2는 기본 패딩 토큰이 없음)
tokenizer.pad_token = tokenizer.eos_token

# 2. 하위 레이어 동결 (GPT2는 transformer.h가 디코더 블록)
for name, param in model.named_parameters():
    if "transformer.h" in name:
        layer_num = int(name.split(".")[2])
        if layer_num < 6:  # 0-5번 블록 동결
            param.requires_grad = False

# 3. 임베딩 레이어도 동결 (선택)
for param in model.transformer.wte.parameters():
    param.requires_grad = False
for param in model.transformer.wpe.parameters():
    param.requires_grad = False

# 4. 학습 실행
# (Trainer 설정은 BERT와 동일)

🌉 인코더-디코더 모델 (T5) Fine-tuning

from transformers import T5ForConditionalGeneration, T5Tokenizer

# 1. 모델 로드
model = T5ForConditionalGeneration.from_pretrained("t5-base")
tokenizer = T5Tokenizer.from_pretrained("t5-base")

# 2. 인코더 하위 레이어 동결
for name, param in model.named_parameters():
    if "encoder.block" in name:
        layer_num = int(name.split(".")[2])
        if layer_num < 3:  # 인코더 0-2번 동결
            param.requires_grad = False

# 3. 디코더는 전체 미세조정 (생성 품질 중요)
# 디코더 블록은 별도 동결 없이 모두 학습

# 4. 차등 학습률 적용 (선택)
optimizer_grouped_parameters = [
    {"params": [p for n, p in model.named_parameters() 
                if "encoder" in n and p.requires_grad],
     "lr": 1e-5},  # 인코더: 작은 학습률
    {"params": [p for n, p in model.named_parameters() 
                if "decoder" in n],
     "lr": 3e-5},  # 디코더: 큰 학습률
]

⚡ LoRA로 효율적 미세조정

# pip install peft
from peft import LoraConfig, get_peft_model, TaskType

# 1. 기본 모델 로드
from transformers import AutoModelForCausalLM
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")

# 2. LoRA 설정
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=8,              # LoRA 랭크 (작을수록 경량)
    lora_alpha=32,     # 스케일링 팩터
    lora_dropout=0.1,
    target_modules=["q_proj", "v_proj"]  # 어텐션 레이어만
)

# 3. LoRA 적용
model = get_peft_model(model, lora_config)

# 4. 학습 가능 파라미터 확인
model.print_trainable_parameters()
# 출력: trainable params: 4,194,304 || all params: 6,742,609,920 || trainable%: 0.0622
