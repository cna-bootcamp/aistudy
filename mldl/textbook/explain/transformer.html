개요

트랜스포머란?

2017년 구글이 발표한 혁신적인 신경망 구조로, RNN 없이 오직 Attention만으로 시퀀스를 처리합니다. 병렬 처리가 가능해 학습 속도가 획기적으로 빨라졌습니다.

특징 RNN Transformer
처리 방식 순차 처리 (하나씩) 병렬 처리 (동시에)
학습 속도 느림 빠름 (3-10배)
장거리 의존성 약함 강함
핵심 기술 Hidden State Self-Attention
1단계

입력 준비: 임베딩 + 위치 인코딩

예문: "나는 사과를 먹었다"

① 단어 임베딩
"나는"
→ 0.2 0.8 0.1 0.5
"사과를"
→ 0.5 0.3 0.7 0.2
"먹었다"
→ 0.1 0.9 0.4 0.6
② 위치 인코딩 추가
"나는"
+ [1번째] → 문맥 벡터
"사과를"
+ [2번째] → 문맥 벡터
"먹었다"
+ [3번째] → 문맥 벡터
💡 왜 위치 정보가 필요한가? 트랜스포머는 모든 단어를 동시에 보기 때문에 순서를 모릅니다. "사과를 나는 먹었다"와 "나는 사과를 먹었다"를 구분하려면 위치 정보가 필수입니다!
