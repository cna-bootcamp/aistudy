# 워밍업 예제 개발 프롬프트 (먹구름→비 미니 트랜스포머)

[목표]
`example/` 하위에 "하늘에 먹구름이 많아지면 뭐가 생각나?" 질문→답 생성을 학습·시연하는 독립 실행형 미니 트랜스포머 파이썬 프로그램 개발.

[역할]
당신은 파이토치 기반 트랜스포머 교육 콘텐츠를 다수 제작한 10년차 ML 엔지니어 겸 입문자 대상 강사입니다.

[맥락]
- 내 상황: Colab 한국어→영어 번역 미니 트랜스포머 과제를 배포하기 전, 어텐션·순차 생성 직관을 먼저 심어줄 워밍업 예제가 필요함.
- 결과물 독자: 파이썬 기초만 아는 트랜스포머 입문 교육생과, 이 예제를 수업에 활용하는 강사.

[입력]
- 검증된 아키텍처: `transformer_translate_colab_answers.ipynb` (E2E 통과한 인코더-디코더 구현, 재사용 근거)
- 학습 데이터: 프로그램 내 인라인 (질문→답 6쌍, 하늘 대상 키워드가 답을 결정하는 구조)
- 외부 데이터셋·URL: 해당 없음

[처리]
- 모델 모듈 작성: `mini_transformer.py` — 위치 인코딩·멀티헤드 어텐션·FFN·인코더/디코더 레이어·Transformer·마스크 구현(검증본과 동일 구조).
- 데모 작성: `demo.py` — Vocab·공백 토큰화·인라인 데이터·학습 루프·greedy 생성·크로스 어텐션 추출·히트맵 저장.
- 데이터 설계: "하늘에 {대상}이 … 뭐가 생각나" → 답. 대상(먹구름/별/해/무지개/눈송이/노을)이 답을 가르는 판별 토큰이 되게 구성.
- 교육 출력 4종: (1) 질문→답 생성 결과, (2) 한 단어씩 생성 과정(마스킹 시연), (3) 크로스 어텐션 히트맵(답이 '먹구름'에 집중), (4) 대조 예시(별→다른 답, 주목 이동).
- 의존성 정리: `requirements.txt` — `torch`·`matplotlib`, CPU 설치 기준 명시.
- 문서 작성: `README.md` — 목적·트랜스포머 개념 매핑·venv 실행법·기대 출력·교육용 한계(소량 데이터 암기 토이임) 명시.
- 출력파일: `mini_transformer.py`, `demo.py`, `requirements.txt`, `README.md`, `attention_heatmap.png`
- 톤앤매너: 코드 주석·README는 한국어, 비유·직관 위주. 학습 로그는 loss 하강이 눈에 보이게 출력.
- 작성 규칙:
  - 한글 그래프 라벨 렌더 처리(Windows `Malgun Gothic` 탐지·설정), `matplotlib.mathtext` 경고 억제
  - 고정 시드로 재현성 확보
  - PEP8 준수, 공개 함수·클래스에 1줄 이상 docstring

[출력]
- `start-here/hands-on/voc-translate/example/` 하위에 생성:
  - `mini_transformer.py` (모델 정의)
  - `demo.py` (실행 진입점)
  - `requirements.txt` (의존성)
  - `README.md` (설명서)
  - 실행 시 생성: `attention_heatmap.png` (크로스 어텐션 히트맵)

[제약조건]
- MUST:
  - reviewer(코드 정확성·품질)와 critic(교육 적합성·과설계 여부) 2개 역할이 각각 리뷰·비판을 수행하고 그 지적을 반영함
  - 가상환경(venv) 구성 후 `requirements.txt` 설치·`demo.py` 실행으로 실제 동작을 검증하고, 오류 발견 시 수정함
  - 학습이 수렴(loss 하강)하고 "먹구름" 질문에 의미 있는 답과 어텐션 집중이 관찰됨
- MUST NOT:
  - 정답본·빌더를 public repo에 노출하지 않음 (로컬 `example/`만 대상)
  - GPU를 필수화하지 않음 (CPU에서 수 초 내 실행)
- 완료조건:
  - venv에서 `python demo.py` 가 오류 없이 종료되고, 콘솔에 질문→답·생성 과정이 출력되며 `attention_heatmap.png` 가 생성됨
  - reviewer·critic 지적사항과 반영 내역이 응답에 요약됨

[예시]
```
질문: 하늘에 먹구름이 잔뜩 끼면 뭐가 생각나
생성: <sos> 비가 → 올 → 것 → 같아 <eos>
답  : 비가 올 것 같아      (어텐션: '비가'가 '먹구름이'에 집중)

질문: 하늘에 별이 잔뜩 뜨면 뭐가 생각나
답  : 밤이 깊었나 봐        (주목 이동: '먹구름' → '별')
```
