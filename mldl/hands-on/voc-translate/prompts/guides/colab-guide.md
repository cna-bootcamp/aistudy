# Colab 셀 디자인 가이드

`start-here/hands-on/llm` 예제를 `start-here/hands-on/voc-translate/` Colab 노트북으로
재배치할 때 적용하는 셀 디자인 원칙을 정리함. 대상 교육생은 트랜스포머 완전 초급자이며,
실습이 개인평가에 반영되고 3.5시간 내 완주해야 하는 제약을 전제로 함.

## 1. 노트북 구성

- 원본의 여러 스크립트(`train.py`, `attention_demo.py`, `translate.py`,
  `transformer_lab/*.py`)를 학습과정 6개 항목 순서(모델 학습 → 인코딩[토큰화·임베딩·위치인코딩 →
  Multi-Head Attention → 잔차+정규화+FFN] → 디코딩[순차 응답 생성 → 잔차+정규화+FFN])로
  재배치한 **단일 `.ipynb`**로 구성함
- 항목별로 마크다운 헤더로 구분하고, 각 코드 셀 앞에 개념을 비유로 설명하는 마크다운 셀을 먼저 배치함

## 2. 셀 디자인 패턴 3종

| 패턴 | 설명 | 정답 노출 |
|---|---|---|
| 완성 코드+주석 | 빈칸 없이 완성 코드와 상세 주석만 제공 | 해당 없음 |
| 빈칸-주관식형 | 학생이 코드를 직접 타이핑하여 채움 | 미노출(자기검증만 제공) |
| 빈칸-객관식형 | `#@param` 드롭다운으로 코드 후보 중 하나를 선택하면, 선택값이 이후 셀 실행에 그대로 반영됨 | 선택지에 포함(문법 실수 없이 로직 선택에 집중) |

## 3. 패턴 적용 기준

실행 데모 유무뿐 아니라, 해당 파트가 **트랜스포머 구조 이해와 직결되는지**를 함께 기준으로 사용함.

- 트랜스포머 핵심 개념(어텐션 메커니즘)과 직결되고 실행 데모가 있는 파트(Multi-Head Attention,
  순차 응답 생성): 빈칸-주관식형 또는 빈칸-객관식형 적용 가능
- 전용 실행 데모는 없지만 트랜스포머 구조 이해와 직결되는 파트(위치 인코딩, 인코딩/디코딩의
  잔차+정규화+FFN): 빈칸-객관식형만 적용. 독립적인 중간 출력이 없어 빈칸-주관식형의 assert
  검증은 어렵지만, 선택한 코드가 실제 `EncoderLayer`/`DecoderLayer` forward에 그대로
  반영되어 노트북 전체 파이프라인 실행에 영향을 주므로, 별도 데모 없이도 객관식 선택형은 적용 가능
- 실행 데모는 있으나 트랜스포머 구조 이해와는 별개 주제인 파트(모델 학습 방법 이해 — loss 최소화
  과정 자체는 트랜스포머 내부 구조와 무관): 빈칸 없이 완성 코드+주석만 제공하고, 학생은 셀을
  그대로 실행하며 epoch별 loss 출력 결과를 관찰만 함

## 4. 빈칸 개수와 난이도

- Multi-Head Attention, 순차 응답 생성: 항목당 빈칸 2~3개, 빈칸-주관식형과 빈칸-객관식형을
  혼합 배치하여 난이도를 낮춤(전부 주관식형으로만 채우지 않음)
- 위치 인코딩, 인코딩/디코딩의 잔차+정규화+FFN: 항목당 빈칸-객관식형 1개만 배치(구조 이해도
  확인 목적이므로 개수를 최소화)
- 모델 학습 방법 이해: 빈칸 없음(완성 코드+주석, 실행·관찰만)
- 빈칸-주관식형의 힌트 주석은 사용할 함수명·수식·예상 shape까지 구체적으로 제공함

```python
# TODO: attention score 계산
# 힌트: torch.matmul, torch.softmax, math.sqrt(d_k) 사용
# 예상 출력 shape: torch.Size([1, 4, 10, 10])
scores = ...  # 직접 작성
```

```python
#@markdown 다음 중 attention score 계산식으로 올바른 것을 선택하세요
선택 = "A) Q @ K.transpose(-2,-1) / sqrt(d_k)" #@param ["A) Q @ K.transpose(-2,-1) / sqrt(d_k)", "B) Q @ K / d_k", "C) Q + K.transpose(-2,-1)"]
```

전용 실행 데모가 없는 파트(위치 인코딩, 잔차+정규화+FFN)의 빈칸-객관식형 예시:

```python
#@markdown 다음 중 인코더 레이어의 잔차 연결 순서로 올바른 것을 선택하세요
선택 = "A) norm1(x + attn(x))" #@param ["A) norm1(x + attn(x))", "B) norm1(attn(x))", "C) x + norm1(attn(x))"]
```

## 5. 자기검증

- 빈칸-주관식형 셀 직후에는 `assert` 문을 배치하여 실행 즉시 정답 여부를 확인하게 함
- Colab은 셀 실행 시 에러(실행 자체가 막히는 경우)는 즉시 traceback으로 드러나지만,
  에러 없이 조용히 틀린 경우(예: reshape 순서 오류)는 이후 단계에서야 문제가 드러나
  원인 추적에 시간을 낭비하게 되므로, assert로 그 즉시 잡아냄
- 전용 실행 데모가 없는 파트의 빈칸-객관식형은 독립적인 중간 출력을 assert할 수 없으므로,
  선택 자체의 정오는 선택지 구성으로 이미 보장하고, 대신 선택한 코드가 반영된 노트북 전체
  파이프라인(인코더/디코더 forward)이 에러 없이 끝까지 실행되는지로 정상 반영 여부를 확인함

```python
assert scores.shape == torch.Size([1, 4, 10, 10]), "attention score shape 확인!"
```

## 6. 정답 비공개 원칙

- 학생용 노트북에는 빈칸-주관식형의 정답 셀을 제공하지 않음
- 강사(클로니·최아이)용 별도 비공개 정답 노트를 보관하여 채점·실습 중 순회 지도에 활용함

## 7. 시간 배분 가이드

- 항목별 마크다운 셀에 예상 소요 시간을 안내함(예: "이 섹션은 15분 이내 완료 목표")
- 6개 항목 전체가 3.5시간 내에 완주 가능하도록 항목별 시간을 배분함

## 8. 평가 기준

- 빈칸(주관식형·객관식형) 정답 여부와 노트북 전체 완주(6개 항목 실행 완료) 여부를 함께 평가함
