🧠 LSTM & GRU 쉽게 이해하기

책 읽기 예제로 배우는 순환 신경망의 기억 메커니즘

📦 LSTM이 책을 읽는 방법

📚

LSTM = 꼼꼼한 학생의 4단계 메모법

LSTM은 4개의 게이트로 정보를 세밀하게 관리합니다:

  • 망각 게이트 = "이건 시험에 안 나올 것 같아, 지우자" (불필요한 정보 삭제)
  • 입력 게이트 = "이걸 얼마나 자세히 적을까?" (저장할 양 결정)
  • 셀 게이트 = "이 내용이 중요해 보여" (새로운 정보 후보)
  • 출력 게이트 = "지금 이 문제에 뭘 써야 하지?" (출력할 정보 선택)

💡 LSTM의 4개 게이트 역할

  • 망각 게이트: 이전 기억 중 불필요한 부분을 선택적으로 삭제
  • 입력 게이트: 새 정보를 얼마나 저장할지 결정
  • 셀 게이트: 현재 입력에서 중요한 정보 추출
  • 출력 게이트: 장기 기억(C)에서 얼마나 읽어와서 새 단기기억에 반영할 지 결정

⚡ GRU가 책을 읽는 방법

📝

GRU = 효율적인 학생의 2단계 메모법

GRU는 2개의 게이트로 빠르고 효율적으로 정보를 관리합니다:

  • 리셋 게이트 = "이전 내용을 얼마나 참고할까?" (이전 기억 리셋 정도)
  • 업데이트 게이트 = "새 내용과 기존 내용을 어떤 비율로 섞을까?" (혼합 비율)

💡 핵심: LSTM의 4개 게이트를 2개로 단순화! 장기기억과 단기기억을 하나로 통합하여 더 빠르게 처리합니다.

💡 GRU의 2개 게이트 역할

  • 리셋 게이트: 이전 기억을 얼마나 무시할지 결정 (낮으면 이전 기억 무시)
  • 업데이트 게이트: 새 정보와 기존 정보의 혼합 비율 결정
  • 후보 생성: 리셋된 이전 기억과 현재 입력으로 새로운 기억 후보 생성

⚖️ LSTM vs GRU 비교

📦 LSTM

  • 🚪 게이트 4개 (망각, 입력, 셀, 출력)
  • 📊 장기기억 + 단기기억 분리
  • 🎛️ 세밀한 제어 가능
  • ⏱️ 학습 속도 느림
  • 📈 긴 문장에 강함
  • 💾 파라미터 더 많음

⚡ GRU

  • 🚪 게이트 2개 (리셋, 업데이트)
  • 📊 하나의 통합 기억 사용
  • 🎛️ 간단한 구조
  • ⏱️ 학습 속도 빠름
  • 📈 짧은 문장에 효율적
  • 💾 파라미터 25% 적음

🎯 언제 어떤 것을 선택할까?

  • 데이터가 적을 때: GRU (과적합 위험 낮음)
  • 아주 긴 문장: LSTM (장기 기억에 강함)
  • 빠른 학습 필요: GRU (파라미터 25% 적음)
  • 복잡한 패턴: LSTM (세밀한 제어)
