[목표]
Transformer Lab의 세 파이썬 예제(attention_demo.py·train.py·translate.py)가 실제로 만든 데이터를 서버·
인터넷 없이 브라우저로 열어 눈으로 확인하는 정적 시각화 웹 페이지를 `start-here/hands-on/llm/web/`에 개발

[역할]
당신은 비전공자 대상 인터랙티브 학습 콘텐츠를 다수 제작한 교육용 데이터 시각화 프론트엔드 전문가입니다.
빌드 도구·프레임워크 없이 바닐라 HTML/CSS/JS와 SVG만으로 개념을 애니메이션으로 풀어내는 데 능숙합니다.

[맥락]
- 내 상황: 생성형AI 부트캠프 "LLM과 Transformer 아키텍처" 과정의 종합실습에서 파이썬 예제
  (`transformer_lab/`·attention_demo.py·train.py·translate.py)를 이미 개발 완료함. 이 예제는 콘솔에
  숫자·로그만 출력해, 비전공 수강생이 Self-Attention·학습·번역의 동작을 체감하기 어려움. 앞선 실습
  작업(prompts/prompt.txt)에서 웹 시각화는 MUST NOT으로 분리했던 그 후속 작업임
- 결과물 독자: 비전공~초급 개발자 수강생, 그리고 이 페이지로 실습을 진행하는 담당 교수

[입력정보]
- 재현 대상 참고 구현: `start-here/hands-on/llm/web/`(index.html, style.css, app.js) — 이 페이지의 구성·
  동작·디자인을 기준 산출물로 삼음
- 데이터 원천 파이썬 소스: `start-here/hands-on/llm/`(attention_demo.py, train.py, translate.py,
  transformer_lab/, data/) — 시각화할 수치는 전부 이 코드의 실제 실행 결과에서 가져옴
- 데이터 원천 산출물: `start-here/hands-on/llm/checkpoint.pt`(train.py가 저장하는 가중치·loss 기록)
- 쉬운 설명 톤 참고: `start-here/hands-on/llm/prompts/prompt-easy.txt`의 비전공자용 개념 풀이 방식
- 디자인 토큰(색·타이포): `start-here/hands-on/llm/web/style.css`의 CSS 변수 팔레트

[작업방법]
1. 데이터 내보내기 스크립트 `generate_web_data.py`를 작성함 — 아래 세 묶음을 모아 `web/data.js`에
   `window.VIZ_DATA = {...}` 전역 할당(JS) 형태로 저장함
   - attention: attention_demo.py의 Self-Attention 4단계 중간값(임베딩·raw/scaled 점수·softmax 비율·
     value·context)과 Multi-Head 헤드별 비율
   - training: checkpoint.pt의 epoch별 loss 기록(loss_history)
   - translations: translate.py로 예문을 실제 추론해 얻은 생성 토큰과 Cross-Attention 가중치
     (생성단어×원문토큰, 헤드 평균)
   - 예문은 4종을 큐레이션함: 학습 문장(정확 재현)·held-out(정확 일반화)·held-out(오역)·글로서리 미사용
     조합(정확 생성) — 성공만 고르지 말고 알려진 오역 사례를 반드시 포함해 정직하게 보여줌
   - `fetch()`가 아니라 `<script src="data.js">` 태그로 로드되게 함 — 로컬 파일(`file://`)에서 fetch는
     CORS로 차단되므로, 서버 없이 index.html 더블클릭만으로 동작하게 하려는 의도임
2. `web/index.html`을 작성함 — 상단 헤더(제목·한 줄 설명), 화면 상단 고정(sticky) 섹션 내비게이션, 본문
   3개 섹션(`#attention`·`#training`·`#translate`) 순서로 구성함
3. 섹션① Self-/Multi-Head Attention을 작성함
   - 단어별 임베딩(숫자 나열) 표를 상단에 표시하고, 지금 살펴보는 단어(query)를 ★로 강조함
   - 4단계 워크스루를 재생/이전/다음 버튼으로 넘기며 봄: (1)관련도 점수(QK^T) → (2)점수 다듬기(Scaling)
     → (3)백분율로 바꾸기(Softmax %) → (4)집중한 만큼 정보 섞기(Weighted Sum). 4단계는 "비율 × 각 단어의
     정보"를 더해 새 벡터가 나오는 계산을 그대로 보여줌
   - Multi-Head는 4개 관점(head)을 그리드로 나란히 보여줌
   - 지금 값은 학습 전(무작위) 상태이며 관점 간 차이는 우연임을 명시함(과잉 의미 부여 방지)
4. 섹션② 학습 loss 곡선을 작성함
   - "학습·epoch·loss가 왜 중요한지"를 쉬운 말로 푼 개념 카드를 곡선 앞에 배치함
   - loss 곡선을 SVG 라인 차트로 그리고, 재생/처음으로 버튼과 로그 스케일(y축) 토글, 현재 epoch·loss
     리드아웃을 제공함
5. 섹션③ 번역 + Cross-Attention을 작성함
   - 예문 select와 번역 실행 버튼을 제공하고, 실행 시 출력 토큰을 한 단어씩 순차 생성(auto-regressive)
     하는 애니메이션으로 보여줌
   - 생성단어×원문토큰 Cross-Attention을 비율(%)과 색 농도로 표현한 히트맵으로 표시함
   - 예문마다 split 배지(학습/held-out 성공/held-out 실패/미사용)와 설명(note)을 함께 노출함
6. `web/style.css`를 작성함 — 기존 팔레트·타이포(Pretendard, teal 강조색)를 CSS 변수로 정의해 준수함
- 출력파일: `start-here/hands-on/llm/web/`(index.html, style.css, app.js), `start-here/hands-on/llm/generate_web_data.py`
- 톤앤매너: 전문용어는 쓰되 괄호로 바로 쉬운 말을 병기하고, 문서·주석은 명사체(~함/~임)로 작성함
- 작성 규칙:
  - 빌드 도구·번들러·외부 CDN·프레임워크 없이 바닐라 HTML/CSS/JS(+SVG)만 사용함
  - 화면 문구는 한국어로 작성함

[출력]
- `start-here/hands-on/llm/generate_web_data.py`
- `start-here/hands-on/llm/web/index.html`
- `start-here/hands-on/llm/web/style.css`
- `start-here/hands-on/llm/web/app.js`
- `start-here/hands-on/llm/web/data.js`(generate_web_data.py 실행으로 생성되는 산출물)

[제약조건]
- MUST:
  - 인터넷 연결·로컬 서버·빌드 도구 없이 `web/index.html`을 브라우저로 더블클릭(`file://`)하는 것만으로
    3개 섹션이 모두 렌더·동작해야 함
  - `web/data.js`는 실제 실행 산출물(checkpoint.pt·모델 추론)에서 생성함 — 수치 하드코딩 금지, 재학습 후
    generate_web_data.py 재실행으로 갱신 가능해야 함
  - 오역 예문 등 모델의 한계를 숨기지 않고 배지·설명으로 정직하게 표시함
  - 막대·바 등 초기 렌더를 requestAnimationFrame에 의존하지 않게 함 — 백그라운드/헤드리스 탭에서 rAF가
    멈춰도 폭이 0으로 남지 않도록 스타일을 동기적으로 설정함
- MUST NOT:
  - 파이썬 모델·학습·번역 코드(transformer_lab/·train.py·translate.py 등)를 이 작업에서 수정하지 않음
    (읽기 전용으로만 참조함)
  - 실제 서비스급 번역 품질을 낸다고 과장하지 않음 — 원리 확인용 교육 데모임을 화면에 명시함
- 완료조건:
  - `python generate_web_data.py`를 실제로 실행해 `web/data.js`가 생성됨을 확인함
  - `web/index.html`을 브라우저로 열어 ①Attention 4단계 재생 ②loss 곡선 재생 ③예문 번역+Cross-Attention
    히트맵이 실제로 화면에 표시됨을 확인함
