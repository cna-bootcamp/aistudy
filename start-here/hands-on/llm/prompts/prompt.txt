[목표]
텍스트 기반 언어모델(Self-Attention·Multi-Head Attention·인코더-디코더 Transformer)의 동작 원리를
직접 실행해 확인할 수 있는 파이썬 실습 샘플앱을 `start-here/hands-on/llm/`에 개발

[역할]
당신은 PyTorch 기반 NLP 강의 실습 자료를 다수 제작한 AI 교육 콘텐츠 전문가 겸 ML 엔지니어입니다.

[맥락]
- 내 상황: 생성형AI 부트캠프 "LLM과 Transformer 아키텍처" 과정의 "종합실습: 간단한 언어모델 구현
  (텍스트 기반, 3.5시간)" 세션에 쓸 실습 자료를 준비 중임. 이 세션은 이론 위주 Day 1~2 강의(Self-
  Attention, Multi-Head Attention, 인코더/디코더, Scaling Law, RLHF 등) 직후에 배치되어 있어, 추상적
  으로 배운 개념을 코드로 직접 조립해보며 확인시키는 것이 목적임
- 결과물 독자: 비전공자~초급 개발자 수강생, 그리고 실습을 운영하는 담당 교수

[작업방법]
1. `transformer_lab/` 패키지를 신규 작성해 아래 구성요소를 `nn.Transformer`·HuggingFace `transformers`
   등 고수준 라이브러리 없이 텐서 연산으로 직접 구현함
   - `tokenizer.py`: 공백 분리 word-level 토크나이저·Vocab(특수 토큰 `<pad>/<sos>/<eos>/<unk>` 포함)
   - `positional_encoding.py`: sin/cos 고정 함수 방식 위치 인코딩(원조 Transformer 방식)
   - `attention.py`: `scaled_dot_product_attention()`(Attention = softmax(QK^T/√d_k)×V)과
     `MultiHeadAttention` 클래스
   - `feed_forward.py`: `FFN(x) = ReLU(xW1+b1)W2+b2` (d_model → d_model×4 → d_model)
   - `masks.py`: padding mask, causal(미래 차단) mask
   - `layers.py`: EncoderLayer(Self-Attention→Add&Norm→FFN→Add&Norm), DecoderLayer(Masked
     Self-Attention→Add&Norm→Cross-Attention→Add&Norm→FFN→Add&Norm)
   - `transformer.py`: Encoder, Decoder, 전체 Transformer(디코더 입력 임베딩과 출력 projection 가중치
     공유 — Weight Tying 옵션 포함)
2. 학습 없이 즉시 실행 가능한 `attention_demo.py` 작성 — 임의의 3단어 문장으로 Self-Attention 4단계
   (QK^T → 스케일링 → softmax → weighted sum)를 실제 수치로 출력하고, 직접 계산한 값과 라이브러리
   함수 결과가 일치하는지 assert로 검증. Multi-Head Attention도 같은 방식으로 헤드별 결과를 출력함
3. 도메인 글로서리 기반 학습 데이터 자동 생성 체계를 만듦
   - `data/glossary.json`: 이커머스 상품 문의(고객 지원) 도메인의 주체·대상·술어를 KO/EN 쌍으로 정의
   - `data/build_dataset.py`: 글로서리를 "행위형(주체+대상+술어)"·"상태형(대상+상태술어)" 두 문형
     템플릿에 조합해 문장 쌍을 생성. 한국어 조사(이/가, 을/를)는 앞 글자의 받침(Hangul 종성) 유무를
     유니코드로 계산해 자동 선택. 조합 가능한 전체 문장 중 일부는 학습용(`ko_en_pairs.txt`), 일부는
     학습에 포함하지 않는 held-out(`ko_en_pairs_heldout.txt`)으로 무작위 분리(seed 고정, 재현 가능)
4. `train.py` 작성 — 생성된 데이터로 Transformer를 학습시키고 epoch별 loss를 콘솔에 출력, 최종
   가중치·vocab·loss 기록을 `checkpoint.pt`에 저장
5. `translate.py` 작성 — 학습된 모델로 한국어 문장을 입력받아 Greedy Decoding(매 스텝 확률이 가장
   높은 단어 하나만 선택, 후보군 유지·Beam Search 아님)으로 영어 문장을 생성하고, Cross-Attention
   가중치를 생성 단어×원문 토큰 표로 출력
6. `requirements.txt` 작성 — torch, numpy 등 필요한 의존성만 명시
7. `README.md` 작성
   - 출력파일: `start-here/hands-on/llm/README.md`
   - 톤앤매너: 명사체 종결(~함/~임), 실행 근거(실제 로그·결과) 위주의 간결한 기술 문서 스타일
   - 작성 규칙:
     - 참고자료·구현 대응 관계, 파일 구성, 한계(작은 데이터셋에 따른 일반화 실패 사례 등)를
       솔직하게 기록
     - 설치 안내는 `python -m venv venv`로 가상환경을 만든 뒤 활성화하는 방식으로 작성하고,
       Windows+Git Bash / Windows+PowerShell / macOS / Linux 4가지 활성화 명령을 모두 표로 제시
