| 디코딩 - 순차 응답 생성(Masked Self-Attention+Cross-Attention) | `translate.py` + 웹 `#translate` | 실행: `python translate.py --sentence "..."`로 단어별 생성 확인. 웹: 생성 과정 애니메이션 + Cross-Attention 히트맵 |
| 디코딩 - 잔차+정규화+FFN | `transformer_lab/layers.py`(`DecoderLayer`) | 전용 실행 데모 없음 → 코드 리딩(`norm1`→Cross-Attn→`norm2`→FFN→`norm3` 구조)으로 설명 필요 |
