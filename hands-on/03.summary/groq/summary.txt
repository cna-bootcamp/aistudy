# 텍스트 요약  

## 1. 회사 개요  
- **회사명**: 유니콘주식회사 (Unicorn Co., Ltd.)  
- **설립일**: 2022‑02‑28  
- **주요 사업**: 직원 역량 교육(AI, Agile, MSA, Cloud)· IT 컨설팅(CI/CD, Cloud)  
- **업종**: 시스템·소프트웨어 개발·공급, 직원 훈련기관

## 2. 핵심 가치와 행동 원칙  
- **Value‑Oriented** – “WHY First, Align”; 가치에 미치지 못하면 과감히 변경·폐기  
- **Interactive** – “Believe Crew, Yes And”; 동료 신뢰와 긍정적 소통으로 집단지성 극대화  
- **Iterative** – “Fast Fail, Learn & Pivot”; 빠른 실패·학습·전환을 통한 지속 개선

## 5. 교육 프로그램과 기대효과  
- **정량적 기대효과** (KTDS 기준)  
  - 애자일 협업 만족도 ≥ 85점, 클라우드 역량 향상 ≥ 85% (평균 87.2%)  
  - 실무 즉시 적용 기대도 ≥ 85점 (평균 86점)  
  - 교육 만족도 ≥ 90점 (평균 93점)  
- **정성적 기대효과**  
  - AI·애자일 기반 업무 방식 내재화·생산성 향상  
  - 사용자 중심 서비스 기획·DDD 기반 상위 설계 역량 강화  
  - 마이크로서비스·클린 아키텍처·CI/CD 자동화 역량 향상  
- **커리큘럼 흐름** (Think‑Design‑Develop‑Deploy)  
  - **Phase 1 (기획)**: WHY‑HOW‑WHAT 프레임, Design Thinking, Event Storming, Figma·Claude Code 활용 프로토타입  
  - **Phase 2 (설계)**: MSA·Cloud Design Pattern·AI‑지원 아키텍처·API·Data 설계  
  - **Phase 3 (개발)**: Spring Boot·React·AI API 연계·TDD·AI‑지원 코드 리뷰  
  - **Phase 4 (배포)**: Docker·Kubernetes 수동 배포 → Jenkins·GitHub Actions·ArgoCD CI/CD 자동화  
- **운영 방식**  
  - 스프린트 기반 학습 (1주 스프린트, DSU, Review, Retrospective)  
  - Human + AI 협업 모델 (Think Human‑AI, Design AI‑Human, Develop AI‑Human, Deploy AI‑Human)  
  - 학습 설계: 이론 30 % / 실습 70 % , 자기결정이론·인지부하 이론 적용, Daily Quiz·피드백·최종 프로젝트 발표  
- **도구·스택**: Claude·Claude Code·Cursor, Figma, Mermaid, Spring Boot, React/Vue, Docker, Kubernetes, Helm, Jenkins, GitHub Actions, ArgoCD, Azure·AWS, Trello 등  
- **예시 일정** (총 10일, 2‑5주 조정 가능)  
  - Think 3일, Design 2일, Develop 3일, Deploy 2일 – 각 단계 독립 교육 가능
