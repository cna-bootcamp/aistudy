# Query Rewriting (질문 재작성) RAG 예제

모호하거나 구어체인 질문을 명확한 법률 용어 중심 질문으로 재작성한 뒤 검색해 답변 정확도를 높이는 Query Transformation 기법 예제임.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 기법 | Query Rewriting (Query Transformation 계열) |
| 입력 | 공용 벡터 DB: `hands-on/10.rag/vectordb` (컬렉션 `patent_law`, 246개 벡터, 로드만 수행) |
| 임베딩 | OpenAI `text-embedding-3-small` (검색 시 쿼리 임베딩에만 사용) |
| LLM | Groq LPU `openai/gpt-oss-120b` (재작성 + 답변 생성) |
| 핵심 아이디어 | 원본 질문을 LLM으로 검색 친화적 질문으로 재작성 후 검색해 정확도 향상 |

## 2. 기법 설명

Query Rewriting은 사용자의 원본 질문을 검색에 더 적합한 형태로 LLM이 재작성하는 기법임.  
구어체·모호한 표현을 명확한 법률 용어와 검색 키워드 중심 문장으로 바꿔 벡터 검색의 정확도를 높임.  
검색 대상 문서가 격식 있는 법조문이므로, 질문 표현과 문서 표현의 어휘 차이를 줄이는 것이 핵심임.

변환 예시:

| 구분 | 질문 |
| --- | --- |
| 원본(모호·구어체) | 특허 어떻게 받어? |
| 재작성(명확·키워드) | 특허를 취득하기 위한 출원 절차·요건·심사 기준 및 등록 요령에 관한 최신 특허법 규정 및 관련 판례를 알려주세요. |

## 3. 처리 흐름

```
원본 질문
   │
   ▼
LLM 재작성 (query_rewriting)  ← 구어체 → 명확한 법률 용어 질문
   │
   ▼
유사도 검색 (retrieve_with_transformation, TOP_K=5)
   │
   ▼
컨텍스트 주입 (format_docs → SYSTEM_PROMPT)
   │
   ▼
답변 생성 (llm_chain.invoke)
```

## 4. 주요 함수

| 함수 | 역할 |
| --- | --- |
| `load_vectorstore` | 공용 벡터 DB를 재인덱싱 없이 로드함 (컬렉션 `patent_law` 지정) |
| `get_llm` | Groq LPU `openai/gpt-oss-120b` 기반 ChatGroq 인스턴스를 생성함 |
| `query_rewriting` | 원본 질문을 검색 친화적 법률 질문으로 재작성함 (이 예제의 핵심) |
| `retrieve_with_transformation` | 질문을 재작성한 뒤 그 질문으로 상위 청크를 검색함 |
| `answer_question` | 재작성 → 검색 → 컨텍스트 주입 → 답변 생성의 전체 흐름을 수행·출력함 |
| `create_llm_chain` | 프롬프트 → LLM → 문자열 추출로 이어지는 LCEL 답변 체인을 생성함 |

**쉬운 설명**  
특허를 받으려면 크게 다음 순서대로 진행합니다.

1. **특허출원서 제출**  
   - 발명에 대한 상세한 설명과 청구항(보호받고 싶은 내용)을 적은 출원서를 준비합니다.  
   - 전자문서로도 제출할 수 있는데, 이는 특허법 제28조의3에 따라 인터넷이나 전자 저장매체를 이용해 간편하게 할 수 있습니다.

2. **심사 요청·심사 진행**  
   - 출원서를 제출하면 특허청(지식재산처)에서 심사를 시작합니다.  
   - 심사 과정에서 선행기술(이미 공개된 기술)과 비교해 새롭고 진보성이 있는지 판단합니다.  
   - 심사 중에 문제가 있으면 보완을 요구받을 수 있습니다.

3. **특허료(등록료) 납부**  
   - 심사를 통과하면 “특허권 설정등록”이 필요합니다.  
   - 설정등록일(특허가 공식적으로 등록되는 날)부터 3년분의 특허료를 먼저 내고, 이후 매년 1년분씩 납부합니다(특허법 제79조).  
   - 이미 납부한 특허료가 있으면 그에 해당하는 경우에만 추가로 납부하면 됩니다(제87조 제2항).

4. **특허권 설정등록(등록) 및 공고**  
   - 특허료를 낸 뒤 지식재산처장이 “특허권을 설정하기 위한 등록”을 해야 합니다(특허법 제87조 제1항·제2항).  
   - 등록이 완료되면 특허공보에 다음 내용이 게재됩니다.  
     - 특허권자·발명자 이름·주소, 출원번호·출원일, 요약서, 특허번호·등록일, 등록공고일 등(특허법 제87조 제3항).  

5. **비밀취급이 필요한 경우**  
   - 발명이 국가 안보 등 특별히 비밀을 유지해야 할 경우, 비밀이 해제될 때까지 등록공고를 보류할 수 있습니다(특허법 제87조 제4항).

**근거 조문**  
- 특허권 설정등록 및 등록공고: **특허법 제87조 제1항·제2항·제3항**  
- 특허료 납부와 납부 시기: **특허법 제79조**  
- 전자문서 제출 가능 근거: **특허법 제28조의3**  
- 비밀취급 발명의 등록공고 보류: **특허법 제87조 제4항**

**참고사항**  
- **전자출원**을 하면 서류 제출이 빠르고, 제출된 전자문서는 종이 서류와 동일한 효력을 가집니다(제28조의3 제2항).  
- 특허료를 제때 납부하지 않으면 특허권이 소멸될 수 있으니, 납부 기한을 꼭 확인하세요.  
- 등록공고가 이루어지면 특허권이 공식적으로 발생하므로, 이후에는 타인이 해당 발명을 무단으로 사용할 경우 침해로 판단될 수 있습니다.  
- 비밀취급이 필요한 경우, 비밀이 해제된 뒤 즉시 등록공고를 해야 합니다(제87조 제4항).
