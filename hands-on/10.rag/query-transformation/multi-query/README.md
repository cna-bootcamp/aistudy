# Multi-Query (다중 질문 생성) RAG 예제

하나의 질문을 다양한 관점의 변형 질문 여러 개로 확장하고 각 질문의 검색 결과를 합쳐 검색 누락을 줄이는 Query Transformation 기법 예제임.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 기법 | Multi-Query (Query Transformation 계열) |
| 입력 | 공용 벡터 DB: `hands-on/10.rag/vectordb` (컬렉션 `patent_law`, 246개 벡터, 로드만 수행) |
| 임베딩 | OpenAI `text-embedding-3-small` (검색 시 쿼리 임베딩에만 사용) |
| LLM | Groq LPU `openai/gpt-oss-120b` (변형 질문 생성 + 답변 생성) |
| 핵심 아이디어 | 질문 1개를 변형 질문 여러 개로 확장·검색하고 결과를 병합·중복제거해 재현율 향상 |

## 2. 기법 설명

Multi-Query는 원본 질문 하나를 LLM으로 여러 관점의 변형 질문으로 확장하는 기법임.  
동의어·다른 문장 구조·구체/추상 수준이 다른 질문들로 각각 검색하면, 단일 질문이 놓치는 문서까지 폭넓게 확보함.  
이 예제는 원본 질문 + 변형 질문 3개(총 4개)로 검색한 뒤 결과를 합치고 중복을 제거해 상위 5개 청크를 사용함.

변형 예시:

| 구분 | 질문 |
| --- | --- |
| 원본 | 특허 어떻게 받어? |
| 변형 1 | 특허를 취득하려면 어떤 절차를 밟아야 하나요? |
| 변형 2 | 특허 신청 방법과 준비해야 할 서류는 무엇인가요? |
| 변형 3 | 특허를 받기 위한 단계별 가이드를 알려 주세요. |

## 3. 처리 흐름

```
원본 질문
   │
   ▼
LLM 변형 (multi_query)  ← 원본 + 변형 질문 3개 = 총 4개
   │
   ▼
각 질문으로 유사도 검색 (TOP_K=5)  ── 4회 검색
   │
   ▼
결과 병합 + 중복 제거 (deduplicate_docs) → 상위 5개
   │
   ▼
컨텍스트 주입 (format_docs → SYSTEM_PROMPT)
   │
   ▼
답변 생성 (llm_chain.invoke)
```

## 4. 주요 함수

| 함수 | 역할 |
| --- | --- |
| `load_vectorstore` | 공용 벡터 DB를 재인덱싱 없이 로드함 (컬렉션 `patent_law` 지정) |
| `get_llm` | Groq LPU `openai/gpt-oss-120b` 기반 ChatGroq 인스턴스를 생성함 |
| `multi_query` | 원본 질문을 변형 질문 3개로 확장해 총 4개를 반환함 (이 예제의 핵심) |
| `retrieve_with_transformation` | 변형 질문들로 각각 검색한 결과를 합치고 중복 제거 후 상위 청크를 반환함 |
| `deduplicate_docs` | 본문이 동일한 중복 문서를 제거해 고유 문서만 남김 |
| `answer_question` | 변형 → 검색 → 병합 → 컨텍스트 주입 → 답변 생성의 전체 흐름을 수행·출력함 |

### 환경변수

`hands-on/.env`에 아래 키가 필요함.  
- `OPENAI_API_KEY`: 쿼리 임베딩(`text-embedding-3-small`)에 사용  
- `GROQ_API_KEY`: LLM(`openai/gpt-oss-120b`) 변형 질문·답변 생성에 사용

### 실행 방법

```bash
python app.py                          # 대화형 챗봇 모드
python app.py --demo                   # 기본 테스트 질의어로 one-shot 실행
python app.py --query "특허 어떻게 받어?"  # 지정 질의어로 one-shot 실행
```

**쉬운 설명**  
특허를 받으려면 먼저 “산업적으로 이용할 수 있는 발명”이어야 합니다. 즉, 그 발명이 실제로 제품이나 공정 등에 쓰일 수 있어야 하고, 다음 두 가지 중 어느 하나라도 해당하면 특허를 받을 수 없습니다.  

1. **이미 공개된 발명** – 특허를 신청하기 전에 국내·외에서 이미 알려졌거나 공개적으로 사용된 경우.  
2. **이미 인쇄·전파된 발명** – 특허를 신청하기 전에 국내·외에서 책이나 논문 등으로 발표되었거나 전기통신을 통해 누구에게든 알려진 경우.  

이 두 가지에 해당하지 않는 새로운 발명이라면, 특허청에 **특허출원**을 해야 합니다. 출원 후 심사를 거쳐 특허가 인정되면 “특허”라는 표시와 특허번호를 제품 등에 붙일 수 있습니다.  

**근거 조문**  
- 특허법 제29조(특허요건) 제1항 및 제2호  
  > “산업상 이용할 수 있는 발명 … 다음 각 호의 어느 하나에 해당하는 것을 제외하고는 … 특허를 받을 수 있다.”  
  > 1. 특허출원 전에 국내·외에서 공지·공연히 실시된 발명  
  > 2. 특허출원 전에 국내·외에서 간행물에 게재되었거나 전기통신회선을 통해 공중이 이용할 수 있는 발명  

**참고사항**  
- 위 조문은 **특허를 받을 수 있는 요건**만을 규정하고 있으며, 실제 출원 절차(서류 작성, 제출, 심사 등)에 대한 구체적인 내용은 제공된 문서에 포함되어 있지 않습니다.  
- 특허를 받기 위해서는 발명이 위 요건을 충족한다는 것을 입증할 수 있는 충분한 설명서와 청구범위가 필요합니다.  
- 출원 후에는 심사관이 “특허거절결정”을 할 수 있는 사유(예: 제25조·제29조·제32조 등 위반)도 존재하니, 출원 전 충분히 검토하는 것이 좋습니다. (관련 규정은 제62조에 명시)
