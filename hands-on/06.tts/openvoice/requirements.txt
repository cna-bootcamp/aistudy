# ============================================================
# Install order (run BEFORE pip install -r requirements.txt)
# ============================================================
#
# Step 1. PyTorch (CUDA version depends on your GPU driver):
#   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
#   Guide: https://github.com/cna-bootcamp/aistudy/blob/main/agentic-ai/reference/install-pytorch.md
#
# Step 2. OpenVoice — MUST use --no-deps (avoids numpy==1.22.0 build failure on Python 3.12)
#   pip install git+https://github.com/myshell-ai/OpenVoice.git --no-deps
#
# Step 3. MeloTTS — MUST use --no-deps (avoids tokenizers Rust build failure on Python 3.12)
#   pip install git+https://github.com/myshell-ai/MeloTTS.git --no-deps
#
# Step 4. MeCab / Japanese tokenizer — MUST install separately (pre-built wheels only)
#   Use Python 3.12 on Windows. Python 3.13 has no mecab-python3==1.0.9 wheel.
#   pip install mecab-python3==1.0.9   # bundled MeCab DLL, no system install needed
#   pip install fugashi                 # latest version; pinned 1.3.0 fails on Python 3.12 Windows
#
# Step 5. Japanese dictionary:
#   Use unidic-lite only. Do NOT install full unidic unless you also run python -m unidic download.
#
# Step 6. pip install -r requirements.txt
# ============================================================
